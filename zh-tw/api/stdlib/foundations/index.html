foundations

本頁內容尚未翻譯。

isContr

Section titled “isContr”

A type is contractible when it has a center element to which every element is connected by a path.

fiber

Section titled “fiber”

The fiber of f over b: the elements of A that f maps to b, each paired with the path f a ≡ b.

isEquiv

Section titled “isEquiv”

A function is an equivalence when every fiber is contractible.

Equiv

Section titled “Equiv”

The type of equivalences from A to B: a function together with a proof that it is an equivalence.

funExt

Section titled “funExt”

Function extensionality: two functions are equal when they agree pointwise.

idEquiv

Section titled “idEquiv”

The identity function as an equivalence from A to itself.

subst

Section titled “subst”

Substitution: transport an element of P a along a path a ≡ b to get an element of P b.

equivFun

Section titled “equivFun”

The underlying function of an equivalence.

equivProof

Section titled “equivProof”

The proof that the underlying function of an equivalence is an equivalence.

pathToEquiv

Section titled “pathToEquiv”

Turn a path between types A ≡ B into a function A -> B by transport.

curryDep

Section titled “curryDep”

Curry a function on a dependent pair into a function of two arguments.

uncurryDep

Section titled “uncurryDep”

Uncurry a two-argument dependent function into a function on dependent pairs.

symP

Section titled “symP”

Path symmetry: reverse a path a ≡ b into b ≡ a (prelude-local copy).

congP

Section titled “congP”

Congruence: apply f to a path a ≡ b to get f a ≡ f b (prelude-local copy).

congSymP

Section titled “congSymP”

Applying f to a reversed path is the reverse of applying f to the path: congP f (symP p) ≡ symP (congP f p).

Path.refl

Section titled “Path.refl”

The constant path at a point; write refl where a path is expected.

sym

Section titled “sym”

Path inversion: a path from a to b reversed is a path from b to a.

cong

Section titled “cong”

Applies a function to a path, giving a path between the images of its endpoints.

congS

Section titled “congS”

Applies an endofunction to a path; cong specialised to A -> A.

cong2

Section titled “cong2”

Applies a two-argument function to a pair of paths, giving a path between the images.

symInv

Section titled “symInv”

Inverting a path twice gives back the same path.

transportRefl

Section titled “transportRefl”

Transport along a constant line is the identity, up to a path.

substRefl

Section titled “substRefl”

Transport in a family along a constant line at a point is the identity, up to a path.

transportConst

Section titled “transportConst”

Transport along the constant line at A returns its argument, up to a path; the given type path is unused.

isProp

Section titled “isProp”

A type is a proposition when any two of its elements are connected by a path.

isSet

Section titled “isSet”

A type is a set when any two parallel paths in it are connected by a path.

isPropToIsSet

Section titled “isPropToIsSet”

Every proposition is a set.

isContrToIsProp

Section titled “isContrToIsProp”

Every contractible type is a proposition.

isPropPi

Section titled “isPropPi”

A dependent function type into a family of propositions is a proposition.

trans

Section titled “trans”

Path composition: a path from a to b followed by a path from b to c gives a path from a to c.

transIdR

Section titled “transIdR”

Composing a path with the constant path on the right gives back the path.

transIdL

Section titled “transIdL”

Composing a path with the constant path on the left gives back the path.

reflAt

Section titled “reflAt”

The constant path at an explicitly given point.

rCancel

Section titled “rCancel”

A path composed with its inverse is the constant path at its start.

lCancel

Section titled “lCancel”

The inverse of a path composed with the path is the constant path at its end.

J

Section titled “J”

Based path induction: a property of paths out of a, proved for refl, holds for every path out of a.

transportUa

Section titled “transportUa”

Transport along the univalence path of an equivalence applies the equivalence’s function, up to a path.

sigmaMapSnd

Section titled “sigmaMapSnd”

Maps a fiberwise function over the second component of a dependent pair, keeping the first.

happly

Section titled “happly”

Turns a path between functions into a pointwise path between their values.

whiskerL

Section titled “whiskerL”

Composing a fixed path on the left preserves a path between paths.

whiskerR

Section titled “whiskerR”

Composing a fixed path on the right preserves a path between paths.

isDiscrete

Section titled “isDiscrete”

A type is discrete when paths between any two of its elements are decidable.

isGroupoid

Section titled “isGroupoid”

A type is a groupoid when any two parallel 2-paths in it are connected by a path.

Acc

Section titled “Acc”

The accessibility predicate: x is accessible under R when every R-predecessor of x is accessible.

WellFounded

Section titled “WellFounded”

A relation is well-founded when every element is accessible under it.

congId

Section titled “congId”

Applying the identity function to a path gives back the path.

congConst

Section titled “congConst”

Applying a constant function to a path gives the constant path.

pathSigmaNonDep

Section titled “pathSigmaNonDep”

Builds a path between pairs from paths between their components.

fstPath

Section titled “fstPath”

Projects a path between dependent pairs to a path between their first components.

singlContr

Section titled “singlContr”

The singleton type of elements with a path to x is contractible.

isPropContr

Section titled “isPropContr”

Every contractible type is a proposition.

isPropProd

Section titled “isPropProd”

The product of two propositions is a proposition.

funExtSym

Section titled “funExtSym”

Function extensionality with reversed pointwise paths: from g x ≡ f x for all x, get g ≡ f.

substConst

Section titled “substConst”

Substitution in a constant family returns the original value, up to a path.

isPropPi_explicit

Section titled “isPropPi_explicit”

A dependent function type into a family of propositions is a proposition, with explicit type arguments.

isPropFun

Section titled “isPropFun”

Functions into a proposition form a proposition.

isPropArrow

Section titled “isPropArrow”

Functions into a proposition form a proposition, proved pointwise.

congSym

Section titled “congSym”

Applying a function to an inverted path equals inverting the applied path.

congConst2

Section titled “congConst2”

Applying a constant function to a path gives the constant path.

transportConstPath

Section titled “transportConstPath”

Transport along a constant line is the identity, up to a path.

sndPath

The identity function at an explicit type.

The constant function returning its first argument.

Function composition: compose g f applies f and then g.

Composing with the identity on the left does not change a function’s value.

composeIdR

Section titled “composeIdR”

Composing with the identity on the right does not change a function’s value.

composeAssoc

Section titled “composeAssoc”
