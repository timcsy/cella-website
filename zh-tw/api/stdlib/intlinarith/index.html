ilNegLe

Section titled “ilNegLe”

Rewrites the order test between two negative integers into leNat y x.

ilNegLeBack

Section titled “ilNegLeBack”

Converts leNat y x back into the order test between two negative integers.

ilLtToLe

Section titled “ilLtToLe”

A strict Nat comparison a < b gives succ a <= b.

ilLeToLt

Section titled “ilLeToLt”

succ a <= b gives the strict Nat comparison a < b.

ilLtSuccToLe

Section titled “ilLtSuccToLe”

y < succ x on Nat gives y <= x.

ilLeToLtSucc

Section titled “ilLeToLtSucc”

y <= x on Nat gives y < succ x.

ilOrTrueR

Section titled “ilOrTrueR”

A boolean disjunction with true on the right is true.

ilLeZero

Section titled “ilLeZero”

Zero is at most every natural number.

ilNegPos

Section titled “ilNegPos”

Ring identity: -p + (p + y) = y.

ilNegNeg

Section titled “ilNegNeg”

Ring identity: -(p + k) + k = -p.

ilNegPosW

Section titled “ilNegPosW”

Adding pos (succ x + y) to negsucc x gives pos y.

ilNegNegW

Section titled “ilNegNegW”

Adding pos k to negsucc (y + k) gives negsucc y.

ileW

Section titled “ileW”

Turns a <= b on Int into a witness k with a + k = b.

ileRefl

Section titled “ileRefl”

The Int order is reflexive.

ileSucR

Section titled “ileSucR”

If a <= c then a <= c + 1 on Int.

ileSubst

Section titled “ileSubst”

Transports a <= b along an equality b = c.

ileAdd

Section titled “ileAdd”

Every integer is at most itself plus a natural number.

ileOf

Section titled “ileOf”

A witness a + k = b gives a <= b on Int.

ileOfEq

Section titled “ileOfEq”

An equality a = b gives the witness 0 for a <= b.

ileOfEqSym

Section titled “ileOfEqSym”

An equality a = b gives the witness 0 for b <= a.

iltToLe

Section titled “iltToLe”

A strict Int inequality a < b gives a + 1 <= b.

iltOfLe

Section titled “iltOfLe”

a + 1 <= b on Int gives the strict inequality a < b.

ILinHyp

Section titled “ILinHyp”

A hypothesis for the Int linarith certificate: two expressions with a witness that the first plus k equals the second, and its coefficient.

ilHolds

Section titled “ilHolds”

The proposition that every hypothesis in the list holds under the environment.

ilSum

Section titled “ilSum”

The expression for the weighted sum of hypothesis gaps, the sum of c * (b - a).

ilK

Section titled “ilK”

The natural number summing c * k over the hypotheses, the value of their weighted gap sum.

ilDiff

Section titled “ilDiff”

Ring identity: (a + k) - a = k.

ilDiffAt

Section titled “ilDiffAt”

A witness a + k = b gives b - a = k.

ilSumEval

Section titled “ilSumEval”

Under holding hypotheses, the weighted gap sum evaluates to the nonnegative integer ilK.

ilPosOfMul

Section titled “ilPosOfMul”

If a positive multiple of x is a nonnegative integer, x is nonnegative.

ilAddSub

Section titled “ilAddSub”

Ring identity: a + (b - a) = b.

intLinMul

Section titled “intLinMul”

Checked by the certificate, M times (b - a) equals the weighted hypothesis sum plus a constant, a nonnegative integer.

intLinW

Section titled “intLinW”

Under a valid certificate, b - a is a nonnegative integer.

ilLeOfDiff

Section titled “ilLeOfDiff”

A nonnegative difference y - x gives x <= y on Int.

intLinLe

Section titled “intLinLe”

Soundness of the Int linarith checker for a <= goal: a valid Farkas certificate over the hypotheses proves a <= b.

intLinLt

Section titled “intLinLt”

Soundness of the Int linarith checker for a strict goal: a certificate for a + 1 <= b proves a < b.

intLinTestTrans

Section titled “intLinTestTrans”

Example use of intLinLe: from x <= y and y <= z conclude x <= z.

ilCancel

Section titled “ilCancel”

Ring identity: p = (a + p) - a.

ilNatAddZero

Section titled “ilNatAddZero”

If a sum of two natural numbers is zero, the first is zero.

ilAntisymW

Section titled “ilAntisymW”

Antisymmetry of the Int order from explicit witnesses a + k1 = b and b + k2 = a.

ilUseLe

Section titled “ilUseLe”

Eliminates an Int order witness into an arbitrary type by passing its components to a continuation.

ileAntisym

Section titled “ileAntisym”

The Int order is antisymmetric: a <= b and b <= a imply a = b.

intLinFalse

Section titled “intLinFalse”

Soundness of the Int linarith contradiction checker: hypotheses whose weighted sum plus a positive constant is identically zero are inconsistent.

intLinAbsurd

Section titled “intLinAbsurd”

Proves any goal from inconsistent hypotheses certified by intLinFalse.
