ArrayTree

Section titled “ArrayTree”

A binary trie of a fixed depth: vacant is a whole subtree without values, single one cell.

ArrayTree.left

Section titled “ArrayTree.left”

The left subtree (a vacant tree has vacant subtrees).

ArrayTree.right

Section titled “ArrayTree.right”

The right subtree (a vacant tree has vacant subtrees).

ArrayTree.value

Section titled “ArrayTree.value”

The value of a one-cell tree (none for a vacant one).

ArrayTree.cells

Section titled “ArrayTree.cells”

The cells of a trie of depth d, left to right (2^d of them): the specification of reads and writes.

ArrayTree.get

Section titled “ArrayTree.get”

Reads cell i of a trie of depth d: the high bit picks the subtree.

ArrayTree.getAt

Section titled “ArrayTree.getAt”

Reads below a branch: the left half when b, else the right half.

ArrayTree.set

Section titled “ArrayTree.set”

Writes cell i of a trie of depth d.

ArrayTree.setAt

Section titled “ArrayTree.setAt”

Writes below a branch: the left half when b, else the right half.

ArrayTree.lengthCells

Section titled “ArrayTree.lengthCells”

A trie of depth d has 2^d cells.

ArrayTree.getSpec

Section titled “ArrayTree.getSpec”

Reading cell i of the cell list gives the trie read, for i below 2^d.

ArrayTree.getSpecAt

Section titled “ArrayTree.getSpecAt”

The read specification below a branch, with the half decided by b.

ArrayTree.setSpec

Section titled “ArrayTree.setSpec”

Writing cell i replaces cell i of the cell list, for i below 2^d.

ArrayTree.setSpecAt

Section titled “ArrayTree.setSpecAt”

The write specification below a branch, with the half decided by b.

ArrayTree.getFast

Section titled “ArrayTree.getFast”

The read that runs: each level halves the previous half instead of recomputing 2^k (equal to get, see getFastSpec).

ArrayTree.getFastAt

Section titled “ArrayTree.getFastAt”

The fast read below a branch: matches the subtree directly.

ArrayTree.setFast

Section titled “ArrayTree.setFast”

The write that runs: each level halves the previous half (equal to set, see setFastSpec).

ArrayTree.setFastAt

Section titled “ArrayTree.setFastAt”

The fast write below a branch: matches the subtree directly.

ArrayTree.getFastSpec

Section titled “ArrayTree.getFastSpec”

The fast read equals the specified read.

ArrayTree.getFastSpecAt

Section titled “ArrayTree.getFastSpecAt”

The fast read below a branch equals the specified one.

ArrayTree.setFastSpec

Section titled “ArrayTree.setFastSpec”

The fast write equals the specified write.

ArrayTree.setFastSpecAt

Section titled “ArrayTree.setFastSpecAt”

The fast write below a branch equals the specified one.

Array.firstCells

Section titled “Array.firstCells”

The first n cells of a trie of depth d.

ArrayTree.store

Section titled “ArrayTree.store”

Writes cell i with the fast write at the trie’s full width.

Array.isFilled

Section titled “Array.isFilled”

Whether a trie of the given depth holds an array of the given size: the size fits and every cell below it holds a value.

Array

Section titled “Array”

A persistent array: reads and writes take time logarithmic in the size, writing gives a new array.

Array.cells

Section titled “Array.cells”

The cells below the size (each holds a value).

Array.writtenTree

Section titled “Array.writtenTree”

The trie after writing x at index i.

Array.toList

Section titled “Array.toList”

The elements in order: the specification every operation is stated against.

Array.empty

Section titled “Array.empty”

The array with no elements.

Array.sizeFits

Section titled “Array.sizeFits”

The size fits the depth.

Array.cellsFull

Section titled “Array.cellsFull”

Every cell below the size holds a value.

Array.lengthCells

Section titled “Array.lengthCells”

There are as many cells below the size as the size.

Array.lengthToList

Section titled “Array.lengthToList”

The array has as many elements as its size.

Array.get

Section titled “Array.get”

Reads element i; none past the end.

Array.getInside

Section titled “Array.getInside”

Reading the trie inside the size reads the elements.

Array.getSpecAt

Section titled “Array.getSpecAt”

Reading by the outcome of the bounds check: the read specification in each case.

Array.getSpec

Section titled “Array.getSpec”

Reading an element reads the list of elements.

Array.cellsAfterSet

Section titled “Array.cellsAfterSet”

The cells of a trie after a write inside its width.

Array.cellsSet

Section titled “Array.cellsSet”

The cells below the size after writing a value inside the size.

Array.filledSet

Section titled “Array.filledSet”

Writing a value inside the size keeps the array well formed. Irreducible, as the other proofs of the invariant (Array.filledPush, Array.filledPop): evaluating an array never computes its filled field (the proof walks the cells, so computing it made each write linear and n writes quadratic).

Array.setAt

Section titled “Array.setAt”

Writing by the outcome of the bounds check.

Array.set

Section titled “Array.set”

Writes element i; an index past the end leaves the array unchanged.

Array.setSpecAt

Section titled “Array.setSpecAt”

The write specification in each case of the bounds check.

Array.setSpec

Section titled “Array.setSpec”

Writing an element writes the list of elements.

Array.cellsPush

Section titled “Array.cellsPush”

The cells up to a newly written last index: the old prefix followed by the value.

Array.filledPush

Section titled “Array.filledPush”

Appending a value at index n (below the width) of a trie whose first n cells hold values keeps it well formed. Irreducible (see Array.filledSet).

Array.pushInto

Section titled “Array.pushInto”

Appends x at index n of a trie whose first n cells hold values (n below the width).

Array.pushIntoSpec

Section titled “Array.pushIntoSpec”

The elements after appending: the old prefix’s values followed by x.

Array.fitsGrown

Section titled “Array.fitsGrown”

A full array fits below the next width: size <= 2^d < 2^(d+1).

Array.grownTree

Section titled “Array.grownTree”

The trie grown by a level: the old tree is the left half.

Array.cellsGrown

Section titled “Array.cellsGrown”

Growing a level keeps the cells below the size.

Array.fullGrown

Section titled “Array.fullGrown”

The grown tree’s first cells hold values.

Array.pushAt

Section titled “Array.pushAt”

Appending by the outcome of the room check: write in place, or grow a level first.

Array.push

Section titled “Array.push”

Appends x at the end, growing a level when full.

Array.pushSpecAt

Section titled “Array.pushSpecAt”

The append specification in each case of the room check.

Array.pushSpec

Section titled “Array.pushSpec”

Appending an element appends to the list of elements.

Array.filledPop

Section titled “Array.filledPop”

Dropping the last element (the size is succ m) keeps the array well formed. Irreducible (see Array.filledSet).

Array.popAt

Section titled “Array.popAt”

Dropping the last element by the size: unchanged when empty.

Array.pop

Section titled “Array.pop”

Removes the last element; the empty array stays empty.

Array.popSpecAt

Section titled “Array.popSpecAt”

The remove specification for each size.

Array.popSpec

Section titled “Array.popSpec”

Removing the last element keeps all but the last of the elements.

Array.pushAll

Section titled “Array.pushAll”

Appends every element of xs in order.

Array.ofList

Section titled “Array.ofList”

The array holding the elements of xs in order.

Array.pushAllSpec

Section titled “Array.pushAllSpec”

Appending a list appends it to the elements.

Array.ofListSpec

Section titled “Array.ofListSpec”

An array built from a list holds exactly that list.
