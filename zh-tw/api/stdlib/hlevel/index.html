constPath

Section titled “constPath”

Turns a decision on x ≡ y into an endofunction on x ≡ y that returns the decided path whenever one exists.

constPathConst

Section titled “constPathConst”

The endofunction constPath is constant: it sends any two paths to the same path.

decPathFn

Section titled “decPathFn”

For a discrete type, the constant endofunction on paths from x to z obtained from deciding x ≡ z.

hedbergMotive

Section titled “hedbergMotive”

Motive for Hedberg’s theorem: a path r equals its image under decPathFn, corrected by the image of refl.

hedbergKey

Section titled “hedbergKey”

Every path from x is recovered from its decPathFn image, the key step of Hedberg’s theorem.
