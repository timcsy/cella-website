A parameter’s declaration and name.

Section titled “cfamily.Item.declarationNames”

The declarations of an item: a global, or a function’s parameters and body.

cfamily.Dialect.names

Section titled “cfamily.Dialect.names”

The names of a program’s declarations (declaration node to source name), after the dialect’s passes; not those of the library’s C functions it uses (the host shows their calls without variables).

cfamily.View

Section titled “cfamily.View”

What writing values needs: the names, the declarations of the blocks, the memory, how types are written, and the platform.

cfamily.View.nameOf

Section titled “cfamily.View.nameOf”

The source name of a declaration (its node when it has none).

cfamily.View.hasName

Section titled “cfamily.View.hasName”

Whether a declaration has a source name (temporaries the checker made have none and are not shown).

cfamily.View.declarationOf

Section titled “cfamily.View.declarationOf”

The declaration a block belongs to, if any.

cfamily.View.blockType

Section titled “cfamily.View.blockType”

The type of a block’s object (int when the block is gone).

cfamily.View.path

Section titled “cfamily.View.path”

A path written by the types along it: [k] in arrays, .f in structs and unions.

cfamily.View.fieldPath

Section titled “cfamily.View.fieldPath”

The k-th member’s part of a path, then the rest.

cfamily.View.escape

Section titled “cfamily.View.escape”

A string written as a C string literal’s contents (newline, double quote and backslash escaped).

cfamily.View.pointer

Section titled “cfamily.View.pointer”

A pointer written as C: NULL, the stream, a literal, &x, &a[2], &s.f, &x + 1, (heap b)…, (dangling).

cfamily.View.value

Section titled “cfamily.View.value”

A scalar value written as C.

cfamily.View.activeBits

Section titled “cfamily.View.activeBits”

A union kept as bits: its k-th member as .name = value.

cfamily.View.designated

Section titled “cfamily.View.designated”

What a variable of a type that designates an object (a reference) shows: the object its address points to, of the type’s child; none when the address is not an object’s.

cfamily.View.memberNamed

Section titled “cfamily.View.memberNamed”

A member’s object of an aggregate by its name, with its type.

cfamily.View.elementsAt

Section titled “cfamily.View.elementsAt”

The elements of type u from where a pointer value points in an array block: count of them (none for any other value).

cfamily.View.countOf

Section titled “cfamily.View.countOf”

The count an integer member holds (0 when it holds none).

cfamily.View.pointedElements

Section titled “cfamily.View.pointedElements”

The elements a pointer member points to, count of them.

cfamily.View.sequenceElements

Section titled “cfamily.View.sequenceElements”

The elements a sequence’s members say it has: size_ of them from where data_ points (none when they cannot be read), with their type.

cfamily.View.shallow

Section titled “cfamily.View.shallow”

An element of a sequence as a debugger shows it: a scalar’s value (? if indeterminate), an aggregate as {...} (the elements come from the memory, not from inside the object: they are not shown deeper).

cfamily.View.sequence

Section titled “cfamily.View.sequence”

A sequence as a debugger’s pretty printer shows it: characters as a string literal, elements as {a, b}; {...} when its elements cannot be read.

cfamily.View.variable

Section titled “cfamily.View.variable”

A variable as JSON: {id, name, type, value, declNode}; the value is null for an uninitialized scalar, and a reference’s is what it refers to.

cfamily.View.variables

Section titled “cfamily.View.variables”

The named variables of scopes, innermost first.

cfamily.Activation

Section titled “cfamily.Activation”

A level of the call stack: its function, the node it is at, its scopes.

cfamily.Frame.activations

Section titled “cfamily.Frame.activations”

The levels of the call stack from the frames out, innermost first: each call frame ends a level (the callee) and the next one is at the call’s node with the saved scopes; the last is the run’s entry (of the name given).

cfamily.Configuration.activations

Section titled “cfamily.Configuration.activations”

The levels of a configuration stopped at a node (the outermost is the run’s entry, of the name given).

cfamily.Dialect.platform

Section titled “cfamily.Dialect.platform”

The dialect’s platform.

cfamily.Dialect.view

Section titled “cfamily.Dialect.view”

The view of a stopped configuration’s state.

cfamily.Activation.frame

Section titled “cfamily.Activation.frame”

A level as the host shows it, its variables without the global scope.

cfamily.Dialect.frames

Section titled “cfamily.Dialect.frames”

The call stack as JSON, innermost first; each level’s variables without the global scope.

cfamily.Dialect.globals

Section titled “cfamily.Dialect.globals”

The global variables as JSON.

cfamily.State.feed

Section titled “cfamily.State.feed”

The state with more standard input (the host’s text, as the bytes the program reads).

cfamily.Configuration.feed

Section titled “cfamily.Configuration.feed”

More standard input for a paused run.

cfamily.View.decimal

Section titled “cfamily.View.decimal”

An integer written in decimal with an optional sign, if the text is one.

cfamily.View.character

Section titled “cfamily.View.character”

A character constant ‘c’ as a character type’s value (a signed char’s above 127 is negative).

cfamily.View.integerOf

Section titled “cfamily.View.integerOf”

An integer of the type from the text a user writes: decimal with an optional sign; true or false for bool; ‘c’ for a character type.

cfamily.Activation.scopesAt

Section titled “cfamily.Activation.scopesAt”

The scopes of the n-th level (0 is the innermost).

cfamily.Configuration.setVariable

Section titled “cfamily.Configuration.setVariable”

Sets an integer variable of the n-th level from its source text: the error says why when it cannot.
