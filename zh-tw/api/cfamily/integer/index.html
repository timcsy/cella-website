cfamily.Rank

Section titled “cfamily.Rank”

The integer conversion rank (C11 6.3.1.1p1): bool < char < short < int < long < long long.

cfamily.Rank.order

Section titled “cfamily.Rank.order”

The order of a rank, from 0 for bool.

cfamily.Rank.belowNormal

Section titled “cfamily.Rank.belowNormal”

Whether a rank is below int’s: such types are promoted.

cfamily.Rank.width

Section titled “cfamily.Rank.width”

The width of a rank’s type on a platform (bool’s is 1).

cfamily.IntegerType

Section titled “cfamily.IntegerType”

An integer type: signedness, rank, width in bits, and whether it is plain char.

cfamily.Platform

Section titled “cfamily.Platform”

A platform’s integer and pointer widths, whether plain char is signed, and the greatest alignment a scalar has in bytes (a scalar is aligned to its size up to it).

cfamily.Platform.aligned

Section titled “cfamily.Platform.aligned”

The alignment of a scalar of a size in bytes on a platform.

cfamily.Platform.lp64

Section titled “cfamily.Platform.lp64”

LP64, the usual desktop and server platform (Linux and macOS; char signed as on x86-64).

cfamily.Platform.avr

Section titled “cfamily.Platform.avr”

AVR, the Arduino Uno’s platform: 16-bit int and pointers, 32-bit long; every type aligned to 1 byte (avr-gcc’s ABI: no padding).

cfamily.Platform.esp

Section titled “cfamily.Platform.esp”

ESP32 and ESP8266 (the Xtensa and RISC-V GCC): 32-bit int, long and pointers, plain char unsigned.

cfamily.IntegerType.boolean

Section titled “cfamily.IntegerType.boolean”

bool.

cfamily.IntegerType.signedChar

Section titled “cfamily.IntegerType.signedChar”

signed char.

cfamily.IntegerType.unsignedChar

Section titled “cfamily.IntegerType.unsignedChar”

unsigned char.

cfamily.IntegerType.char

Section titled “cfamily.IntegerType.char”

Plain char: signed or not as the platform says.

cfamily.IntegerType.short

Section titled “cfamily.IntegerType.short”

short.

cfamily.IntegerType.unsignedShort

Section titled “cfamily.IntegerType.unsignedShort”

unsigned short.

cfamily.IntegerType.int

Section titled “cfamily.IntegerType.int”

int.

cfamily.IntegerType.unsignedInt

Section titled “cfamily.IntegerType.unsignedInt”

unsigned int.

cfamily.IntegerType.long

Section titled “cfamily.IntegerType.long”

long.

cfamily.IntegerType.unsignedLong

Section titled “cfamily.IntegerType.unsignedLong”

unsigned long.

cfamily.IntegerType.longLong

Section titled “cfamily.IntegerType.longLong”

long long.

cfamily.IntegerType.unsignedLongLong

Section titled “cfamily.IntegerType.unsignedLongLong”

unsigned long long.

cfamily.IntegerType.sameType

Section titled “cfamily.IntegerType.sameType”

Whether two types are the same type (plain char differs from both signed and unsigned char).

cfamily.IntegerType.minimum

Section titled “cfamily.IntegerType.minimum”

The least value of a type.

cfamily.IntegerType.maximum

Section titled “cfamily.IntegerType.maximum”

The greatest value of a type.

cfamily.IntegerType.inRange

Section titled “cfamily.IntegerType.inRange”

Whether a value is in a type’s range.

cfamily.IntegerType.covers

Section titled “cfamily.IntegerType.covers”

Whether u can represent every value of t; compares widths and signedness only, so no 2^width is built.

cfamily.IntegerType.promote

Section titled “cfamily.IntegerType.promote”

The integer promotions: a type ranked below int, or a bit-field narrower than its type that fits in int’s width, becomes int if int covers it, else unsigned int (C11 6.3.1.1p2).

cfamily.IntegerType.unsignedVersion

Section titled “cfamily.IntegerType.unsignedVersion”

The unsigned type of the same rank and width.

cfamily.IntegerType.firstOfWidth

Section titled “cfamily.IntegerType.firstOfWidth”

The first of some types that is w bits wide, if any.

cfamily.IntegerType.difference

Section titled “cfamily.IntegerType.difference”

ptrdiff_t and intptr_t: the first of int, long and long long as wide as a pointer (long on LP64’s glibc, int in AVR libc and in the ESP chips’ newlib).

cfamily.IntegerType.size

Section titled “cfamily.IntegerType.size”

size_t and uintptr_t: the unsigned type of ptrdiff_t’s rank.

cfamily.IntegerType.maximal

Section titled “cfamily.IntegerType.maximal”

intmax_t: long when it is as wide as long long (glibc), else long long.

cfamily.IntegerType.unsignedMaximal

Section titled “cfamily.IntegerType.unsignedMaximal”

uintmax_t: the unsigned type of intmax_t’s rank.

cfamily.IntegerType.exactly

Section titled “cfamily.IntegerType.exactly”

intN_t (and int_leastN_t): the first of signed char, int, short, long and long long that is w bits wide (short for 16 bits and long for 64 on LP64’s glibc; int for 16 bits and long for 32 in AVR libc).

cfamily.IntegerType.commonMixed

Section titled “cfamily.IntegerType.commonMixed”

The common type of a signed and an unsigned promoted type.

cfamily.IntegerType.commonPromoted

Section titled “cfamily.IntegerType.commonPromoted”

The common type of two promoted types: the higher rank if their signedness agrees, else by commonMixed.

cfamily.IntegerType.common

Section titled “cfamily.IntegerType.common”

The usual arithmetic conversions on two integer types: promote both, then take the common type.

cfamily.IntegerType.convert

Section titled “cfamily.IntegerType.convert”

Any integer converted to the type: whether it is nonzero for bool, else modulo 2^width (two’s complement if signed).
