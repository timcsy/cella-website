cfamily.Pointer

Section titled “cfamily.Pointer”

A pointer: null, into a block (path, index, whether to the object at the path itself), to a byte of an object (a character pointer made from a pointer to an object of another type, C11 6.3.2.3p7: the block, the path to the object whose bytes it ranges over, the byte, the object’s shape and bits), into a string literal, to a file stream (0 is stdin), or made from an integer (numbered, C11 6.3.2.3p5: GCC keeps the integer as the address; nothing the model has is there).

cfamily.Block

Section titled “cfamily.Block”

A block: the type of its object, the object, and how it came to exist.

cfamily.Memory

Section titled “cfamily.Memory”

The memory: blocks by number, none once a block’s lifetime has ended.

cfamily.Memory.empty

Section titled “cfamily.Memory.empty”

No blocks.

cfamily.Memory.block

Section titled “cfamily.Memory.block”

The block with the number, if it is alive.

cfamily.Memory.allocate

Section titled “cfamily.Memory.allocate”

A new block at the end; its number is the memory’s size before.

cfamily.Memory.next

Section titled “cfamily.Memory.next”

The number the next block will have.

cfamily.Memory.write

Section titled “cfamily.Memory.write”

The block replaced.

cfamily.Memory.release

Section titled “cfamily.Memory.release”

The block’s lifetime ended.

cfamily.Pointer.samePath

Section titled “cfamily.Pointer.samePath”

Whether two paths are the same.

cfamily.ObjectBit.ofNumber

Section titled “cfamily.ObjectBit.ofNumber”

The bits of a number, the low bit first.

cfamily.ObjectBit.number

Section titled “cfamily.ObjectBit.number”

The number bits stand for, low bit first, if every bit is 0 or 1.

cfamily.ObjectBit.unknownOnto

Section titled “cfamily.ObjectBit.unknownOnto”

Indeterminate bits in front of others, in a loop (an object’s bits may be millions: a recursion that deep runs out of the browser’s stack).

cfamily.ObjectBit.unknown

Section titled “cfamily.ObjectBit.unknown”

Indeterminate bits.

cfamily.ObjectBit.fitted

Section titled “cfamily.ObjectBit.fitted”

Bits padded with indeterminate ones, or cut, to a count.

cfamily.ObjectBit.splice

Section titled “cfamily.ObjectBit.splice”

Bits with the ones from an offset on replaced by others (as many as there are).

cfamily.ObjectBit.pointerFrom

Section titled “cfamily.ObjectBit.pointerFrom”

The bits of a pointer from the k-th on.

cfamily.Pointer.identical

Section titled “cfamily.Pointer.identical”

Whether two pointers are the same pointer, part by part (what its bits keep).

cfamily.Value.identicalPointer

Section titled “cfamily.Value.identicalPointer”

Whether two values are the same pointer or the same function.

cfamily.ObjectBit.pointerRest

Section titled “cfamily.ObjectBit.pointerRest”

Whether bits are the k-th bit of a pointer on, in order.

cfamily.ObjectBit.pointer

Section titled “cfamily.ObjectBit.pointer”

The pointer bits stand for: null if every bit is 0, a pointer if they are all of its bits in order.

cfamily.Pointer.isNull

Section titled “cfamily.Pointer.isNull”

Whether a pointer is null.

cfamily.Shape.ofValue

Section titled “cfamily.Shape.ofValue”

The bits of a scalar value of a shape: an integer’s bits by its width, a floating value’s encoding, a pointer’s own bits (null is all 0); a value not of the shape is indeterminate.

cfamily.Shape.valueOf

Section titled “cfamily.Shape.valueOf”

The value of a scalar shape bits stand for, if they stand for one: an integer whose bits past its width are 0 (a bool is 0 or 1), a floating value, a pointer.

cfamily.Shape.elementsBelow

Section titled “cfamily.Shape.elementsBelow”

The places of an array’s first k elements in front of others, in a loop (from the last one down).

cfamily.Shape.children

Section titled “cfamily.Shape.children”

The places of a shape’s children (an array’s elements, the members); a scalar has none.

cfamily.Shape.child

Section titled “cfamily.Shape.child”

The place of a shape’s k-th child, if it has one (an array’s element directly: listing a large array’s places for each access was linear).

cfamily.Placed.locate

Section titled “cfamily.Placed.locate”

Where the subobject at a path below a place is.

cfamily.Placed.encode

Section titled “cfamily.Placed.encode”

The bits of an object at a place (its own bits only).

cfamily.Placed.decode

Section titled “cfamily.Placed.decode”

The object at a place in bits.

cfamily.Placed.count

Section titled “cfamily.Placed.count”

How many bits a place takes.

cfamily.Shape.keptIn

Section titled “cfamily.Shape.keptIn”

The object of a shape bits stand for, keeping a scalar’s bits that stand for no value when some are known (written through a character pointer, a pointer’s bits copied one byte at a time).

cfamily.Placed.holds

Section titled “cfamily.Placed.holds”

Whether a place holds the bits from b up to (not including) e.

cfamily.Object.unionWith

Section titled “cfamily.Object.unionWith”

A union kept as bits with a member active: its members’ places, and the member’s bits (the rest indeterminate).

cfamily.Object.children

Section titled “cfamily.Object.children”

The children of an object (the elements or members), if it has any.

cfamily.Object.child

Section titled “cfamily.Object.child”

The k-th child of an object (of a union kept as bits, the member its bits stand for).

cfamily.Object.at

Section titled “cfamily.Object.at”

The object at a path down the tree.

cfamily.Object.inWrittenUnion

Section titled “cfamily.Object.inWrittenUnion”

Whether the path goes into a union kept as bits that has had a member written: a scalar there whose bits stand for no value has an unspecified one (the bytes of another member, C11 6.2.6.1p7; a pointer’s bits read as an integer), not an indeterminate one.

cfamily.Object.readsInactive

Section titled “cfamily.Object.readsInactive”

Whether the path reads a member of a union kept as bits other than the one last written (the reinterpretation C defines and C++ leaves undefined).

cfamily.Memory.objectIn

Section titled “cfamily.Memory.objectIn”

The object at a path in a block, if the block is alive and the path is in its object.

cfamily.Object.eraseAll

Section titled “cfamily.Object.eraseAll”

Every object erased.

cfamily.Object.replaceAt

Section titled “cfamily.Object.replaceAt”

The children with the k-th’s object at the path replaced.

cfamily.Object.span

Section titled “cfamily.Object.span”

The length a pointer may range over in an object: an array’s, else 1.

cfamily.Object.ofValue

Section titled “cfamily.Object.ofValue”

The object a value is stored as: a whole object as itself, a scalar value in a scalar.

cfamily.Address

Section titled “cfamily.Address”

An address: a block and the path to an object in it, a byte of the object at a path (its shape and bits), or a byte of a string literal.

cfamily.Object.ofByte

Section titled “cfamily.Object.ofByte”

A byte as an object of a character type: its number when its bits are all known, else its bits as they are (a pointer’s, indeterminate ones).

cfamily.Object.byteOf

Section titled “cfamily.Object.byteOf”

The bits of a byte an object of a character type holds (its value’s low eight bits).

cfamily.Placed.shape

Section titled “cfamily.Placed.shape”

The shape at a place.

cfamily.Placed.bytes

Section titled “cfamily.Placed.bytes”

How many bytes an object at a place takes.

cfamily.Placed.align

Section titled “cfamily.Placed.align”

The alignment of the object at a place.

cfamily.Pointer.literalLength

Section titled “cfamily.Pointer.literalLength”

The length of a string literal’s array, with the null.

cfamily.Pointer.below

Section titled “cfamily.Pointer.below”

Whether i is in [0, n).

cfamily.Pointer.upTo

Section titled “cfamily.Pointer.upTo”

Whether i is in [0, n].

cfamily.Pointer.fullPath

Section titled “cfamily.Pointer.fullPath”

The full path of the object a pointer into a block designates.

cfamily.Followed

Section titled “cfamily.Followed”

Following a pointer: the address it designates, or why it designates none.

cfamily.Pointer.dereference

Section titled “cfamily.Pointer.dereference”

Following a pointer: null (C11 6.5.3.2p4), a file stream (an incomplete type), a block whose lifetime has ended (6.2.4p2), a path that is not in the object, one past the end (6.5.6p8).

cfamily.Pointer.splitLast

Section titled “cfamily.Pointer.splitLast”

The last of a list and the ones before it.

cfamily.Pointer.ofAddress

Section titled “cfamily.Pointer.ofAddress”

The pointer &lvalue gives for an address: an element of the array above it, else the object itself.

cfamily.Pointer.first

Section titled “cfamily.Pointer.first”

The pointer to the first element of the array at an address (an array’s value decays to it).

cfamily.Moved

Section titled “cfamily.Moved”

Moving a pointer: where it moved to, or why it cannot.

cfamily.Pointer.add

Section titled “cfamily.Pointer.add”

p + k: within the same array or one past its end (C11 6.5.6p8); null and streams have no arithmetic, and a block whose lifetime has ended has no array left.

cfamily.Pointer.sameArray

Section titled “cfamily.Pointer.sameArray”

Whether two pointers point into the same array (or object), so that their difference and order are defined.

cfamily.Pointer.index

Section titled “cfamily.Pointer.index”

The index of a pointer within its array.

cfamily.Pointer.same

Section titled “cfamily.Pointer.same”

Whether two pointers are equal: both null, or the same place (C11 6.5.9p6).

cfamily.Pointer.isLive

Section titled “cfamily.Pointer.isLive”

Whether a pointer’s block is alive (a pointer to a dead block is indeterminate, C11 6.2.4p2).

cfamily.Memory.objectAt

Section titled “cfamily.Memory.objectAt”

The object at an address in the memory.

cfamily.Memory.store

Section titled “cfamily.Memory.store”

The memory with the object at an address replaced (a literal cannot be written, C11 6.4.5p7).
