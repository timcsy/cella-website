Whether an access is public.

cpp.Objects.releaseOne

Section titled “cpp.Objects.releaseOne”

The internal function a delete calls to release an object new made.

cpp.Objects.releaseArray

Section titled “cpp.Objects.releaseArray”

The internal function delete[] calls to release an array new[] made.

cpp.Objects.construct

Section titled “cpp.Objects.construct”

A class’s constructor called on an object new made (its pointer): chosen for the arguments, accessible here, each argument converted to its parameter.

cpp.Objects.store

Section titled “cpp.Objects.store”

A value stored in an object new made: the argument converted to its type; without one, zero (new T(); an object of a class without constructors zero-initialized member by member, [dcl.init]p8, as a vector’s elements are).

cpp.Objects.initialized

Section titled “cpp.Objects.initialized”

An object of the class cls (of type u) initialized at pointer, as new T, new T() and new T(args) at the node n initialize theirs (args none, empty, or given; checked by k with the globals g and the scope env): default-initialized by its default constructor, if it has one, else left indeterminate ([dcl.init]p7); value-initialized, when the class declares no constructor (none is user-provided), by zeroing it and then running its implicit default constructor, if it has one (a default member initializer, a dynamic type to keep; [dcl.init]p8, p6); one object of the class (or of a class derived from it) without a copy constructor copied bit for bit (its implicit copy constructor is trivial, [class.copy.ctor]p12, as a declaration’s, Construction.trivialCopy); else constructed by the constructor chosen for the arguments.

cpp.Objects.newObject

Section titled “cpp.Objects.newObject”

new T(args) at the node n, T written t (args none for new T; checked by k with the globals g and the scope env): the block allocated, its pointer in the temporary, the object initialized (Objects.initialized).

cpp.Objects.newPointer

Section titled “cpp.Objects.newPointer”

The temporary holding the pointer new T (at n, of an object of type u) makes.

cpp.Objects.allocated

Section titled “cpp.Objects.allocated”

new T at n of an object of type u (in the globals g): the block allocated (byNew), its pointer in the temporary (Objects.newPointer), then the object initialized there by making; the expression is the pointer.

cpp.Objects.listedValue

Section titled “cpp.Objects.listedValue”

The value of a braced list’s element e for an object of type t (at n): e checked by k (with the globals g and the scope env) against t and converted as by assignment, not narrowed ([dcl.init.list]p7, Narrowing.of, as a declaration’s element is).

cpp.Objects.slots

Section titled “cpp.Objects.slots”

The subobjects a braced list initializes in order in lv, an object of the (complete) type t, each with its type (lvalues at the node n; an index’s type from the globals g): a struct’s named members (a base subobject first), an array’s elements, a union’s first member.

cpp.Objects.constructedType

Section titled “cpp.Objects.constructedType”

Whether an object of type t is constructed or destroyed by functions (of a class of the globals g with constructors or a destructor): a braced list’s item is not simply stored into it.

cpp.Objects.grouped

Section titled “cpp.Objects.grouped”

The items xs of a braced list with the braces they elide put back, for the subobjects of the types slots in order ([dcl.init.aggr]p15, as a declaration’s Init.regroup; checked by k with the globals g and the scope env, the lists made at the node n): an item that is a list, a string for a character array, or an expression of the subobject’s own class initializes it whole, as does any item of a scalar or of a class with constructors or a destructor; otherwise the aggregate subobject takes as many items as it needs (Ty.elidedCount) as a list. Items past the slots stay as they are (too many); a list among the ones taken (braces inside an elided subobject) is not modeled.

cpp.Objects.listStores

Section titled “cpp.Objects.listStores”

The stores of a braced list’s items xs (at most depth braces deep) into the subobjects of lv, an object of type t (at n) already zeroed and given its default member initializers: the items regrouped for the subobjects (Objects.grouped, braces elided put back), then each subobject in order from its item (Objects.itemStore, checked by k with the globals g and the scope env), an item past the last subobject an error.

cpp.Objects.slotStores

Section titled “cpp.Objects.slotStores”

The stores of the items xs into the subobjects slots in order (Objects.listStores: k, g, env, depth and n are its).

cpp.Objects.itemStore

Section titled “cpp.Objects.itemStore”

The store of one item x into the subobject lv of type t ([dcl.init.aggr]p4; k, g, env, depth and n as Objects.listStores’s): an expression’s value (not narrowed), a nested list’s items into the subobject’s own (a scalar’s one element, {} zero). A subobject of a class with constructors or a destructor, an array from an expression, and a designator are not modeled here.

cpp.Objects.elided

Section titled “cpp.Objects.elided”

What initializes an object of the class cls from the expression e in place of a prvalue of the class: C(args) alone is constructed from args (C++17’s guaranteed elision, [dcl.init]p17.6.1); any other is the one argument.

cpp.Objects.memberGuard

Section titled “cpp.Objects.memberGuard”

The guard of a subobject just made (the lvalue l, of type t, at the node n): a pointer to it named #guard: and key, which destroys it when an exception leaves the block it is declared in ([except.ctor]p3); nothing for one whose class has no destructor (in the globals g).

cpp.Objects.Slot

Section titled “cpp.Objects.Slot”

A member’s slot in an aggregate: the member’s name, its lvalue and its type.

cpp.Objects.membersFrom

Section titled “cpp.Objects.membersFrom”

The members of an object (the lvalue object) of the aggregate cls with constructors initialized from a braced list’s items xs ([dcl.init.aggr]p4, p5; at most depth braces deep, at the node n; checked by k with the globals g and the scope env), the object already zeroed: each member in declaration order (a base subobject first) from its item, else its default member initializer, else from an empty list (Objects.memberFrom); key names their guards (the path to the members). An item past the last member is an error.

cpp.Objects.slotsFrom

Section titled “cpp.Objects.slotsFrom”

The members slots (each named, with its lvalue and type) initialized from the items xs in order (Objects.membersFrom: k, g, env, depth, n, key and cls are its).

cpp.Objects.memberFrom

Section titled “cpp.Objects.memberFrom”

One member (the lvalue lv of type t) of an aggregate initialized from its item x, if any (Objects.membersFrom: k, g, env, depth, n and key are its). A member of a class with constructors: from an expression copy-initialized (by the constructor chosen for it, not an explicit one, [over.match.copy]p1; C(args) constructs it in place), from a list member by member when the class is an aggregate (Objects.membersFrom), else with the list’s expressions as the constructor’s arguments, without an item value-initialized ([dcl.init.aggr]p5.2); then guarded when its class has a destructor. Any other member is stored from its item (Objects.itemStore), or left zero. An initializer-list constructor’s list for a member is not modeled here.

cpp.Objects.aggregateInto

Section titled “cpp.Objects.aggregateInto”

An object (the lvalue object, of type u, at the node n) of the aggregate cls with constructors initialized from a braced list’s items xs ([dcl.init.list]p3.3; checked by k with the globals g and the scope env): zeroed (a member without an item or a default member initializer is value-initialized), then its members from the items (Objects.membersFrom), in a block of their own, where the guards of the members made destroy them, the last first, when a later one throws.

cpp.Objects.aggregateDeclaration

Section titled “cpp.Objects.aggregateDeclaration”

C x = {xs} and C x{xs} of an aggregate cls with constructors (its items xs, Construction.aggregateItems; the declaration n of x, shown as name, written t; checked by k in the context c and the scope env): x reserved, its members initialized (Objects.aggregateInto; not const while they are, [class.ctor]p5), then an object.

cpp.Objects.zeroed

Section titled “cpp.Objects.zeroed”

The zero-initialization of the object of type u (an lvalue, at n; [dcl.init]p6): a struct as a whole (Objects.store), an array element by element (at most depth dimensions deep), a scalar zero; checked by k with the globals g in the scope env.

cpp.Objects.fromList

Section titled “cpp.Objects.fromList”

An object of the class cls constructed at pointer by its initializer-list constructor taking list (the instance of std::initializer_list<E> and E) from a braced list’s items xs at the node n, inside an expression ([dcl.init.list]p3.6, p5; checked by k with the globals g and the scope env): the backing array const E[count] (named for n, as Construction.fromList names a declaration’s) declared, zeroed and list-initialized from the items (Objects.listStores: each item copy-initialized, not narrowed), then the constructor called with std::initializer_list<E>(array, count). The array stays until the enclosing block ends, past the full expression the standard gives it ([class.temporary]p6); only an element type the list stores into without constructors gets here (Objects.itemStore), so nothing reads the difference.

cpp.Objects.listInitialized

Section titled “cpp.Objects.listInitialized”

An object of the class cls (of type u) list-initialized at pointer by a braced list’s items xs at the node n ([dcl.init.list]p3; checked by k with the globals g and the scope env): an aggregate (a class that declares no constructor and has no virtual function or virtual base) from one object of its class (or of a derived one) is copied, from {} value-initialized (Objects.initialized), else zeroed, given its default member initializers (its implicit default constructor, if it has one) and its subobjects stored from the items in order (Objects.listStores; the rest keep their default member initializer’s value or zero, [dcl.init.aggr]p5); any other class is constructed by the constructor chosen for the items ({} value-initializes). An initializer-list constructor that takes the items comes first ([over.match.list]p1, Objects.fromList); a nested list among a constructor’s arguments is not modeled here.

cpp.Objects.listInto

Section titled “cpp.Objects.listInto”

An object of type u (the lvalue object, its address pointer) list-initialized by a braced list’s items xs at the node n ([dcl.init.list]p3; checked by k with the globals g and the scope env): an object of a class by Objects.listInitialized, a scalar from its one element (not narrowed; {} zero), an array or a struct zeroed and its subobjects stored from the items (Objects.listStores).

cpp.Objects.newList

Section titled “cpp.Objects.newList”

new T{xs} at the node n, T written t ([expr.new]p24, [dcl.init.list]p3; checked by k with the globals g and the scope env): the block allocated as new T’s, the object list-initialized there (Objects.listInto).

cpp.Objects.memberList

Section titled “cpp.Objects.memberList”

A member initialized by a braced list in a constructor (c{1, 2, 3}: direct-list-initialization, [class.base.init]p7, [dcl.init.list]p3; checked by k and statements in the context c and the scope env, at the node n): a member of a class with constructors constructed as a declaration T y{xs} is (from an initializer-list constructor’s list, Construction.fromList, else by the constructor chosen for the items, Construction.member); any other (an aggregate, an array, a scalar) list-initialized in place as new T{xs}’s object is (Objects.listInto). A member of a class with a destructor is guarded once it is made (destroyed if a later member throws, [except.ctor]p3).

cpp.Objects.listed

Section titled “cpp.Objects.listed”

The arguments of new T(args) as the brace list a declaration would be initialized with.

cpp.Objects.plainArray

Section titled “cpp.Objects.plainArray”

new T[count] of elements without constructors: the block allocated (zero-filled for new T[count]()), its pointer in the temporary.

cpp.Objects.classArray

Section titled “cpp.Objects.classArray”

new T[count] of a class: the block allocated, then in a block of their own the elements constructed in order by the default constructor, with a guard (the pointer, and the count constructed beside it) that destroys the constructed ones when a constructor throws ([expr.new]p26: the array is not made).

cpp.Objects.newArray

Section titled “cpp.Objects.newArray”

new T[n]: the array allocated (zero-filled for new T[n]()), its pointer (to the first element) in the temporary.

cpp.Objects.copiesTrivially

Section titled “cpp.Objects.copiesTrivially”

Whether the arguments are one object of the class (or of a class derived from it: its base subobject) and the class has no copy constructor and declares no move (whose constructor then takes an rvalue, and an lvalue’s copy is deleted, [class.copy.ctor]p6): the copy is trivial ([class.copy.ctor]p12), the object stored bit for bit.

cpp.Objects.aggregate

Section titled “cpp.Objects.aggregate”

T(args) of an aggregate (a class without constructors; T{args} from a braced list): a temporary named for the node, its members initialized from the arguments in order and the rest zero ([dcl.init.aggr]p4, p5; C++20 allows parentheses too), each argument converted at its own node.

cpp.Objects.temporaryClass

Section titled “cpp.Objects.temporaryClass”

The class of T(args)’s T: a class written by its name, or a typedef’s name of one.

cpp.Objects.temporary

Section titled “cpp.Objects.temporary”

T(args) ([expr.type.conv]): an object of a class with constructors made in a temporary named for the node (the full expression’s end destroys it; passed by value or initializing an object, it is that object), reserved until its constructor has run (one that throws leaves no object to destroy), constructed with the arguments (one object of the class without a copy constructor copied bit for bit; T() of a class without constructors value-initialized, its members zero, [dcl.init]p8); for any other type with one argument, the argument converted (a cast). A typedef’s name of a class (reverse_iterator(end()) in a class whose member type names a template’s instance) is that class.

cpp.Objects.scalarList

Section titled “cpp.Objects.scalarList”

A scalar’s T{xs} at the node n, of the type u (written t; [dcl.init.list]p3.9, p3.11; checked by k with the globals g and the scope env): its one item converted to u, not narrowed (Objects.listedValue, as a declaration’s element), {} zero; more items are excess elements in scalar initializer, a nested list too many braces around scalar initializer (clang’s words, as Objects.itemStore says them).

cpp.Objects.temporaryList

Section titled “cpp.Objects.temporaryList”

T{xs} at the node n, T written t ([expr.type.conv]p2: a prvalue list-initialized from the braced list’s items, [dcl.init.list]p3; checked by k with the globals g and the scope env): a scalar’s value from its one item (Objects.scalarList); any other object (a class, an array) made in a temporary named for the node as T(args)’s is (Objects.temporary), reserved until it is list-initialized there as new T{xs}’s object is (Objects.listInto: an aggregate member by member, an initializer-list constructor first, else the constructor chosen for the items). An abstract class makes none.

cpp.Objects.expression

Section titled “cpp.Objects.expression”

C++’s expressions of objects: new, new[], T(args), T{…}, nullptr (a null pointer).

cpp.Objects.arrayLength

Section titled “cpp.Objects.arrayLength”

The internal function a new T[count]’s count goes through: the count, unless it is negative (or too large for a long: negative there too), when std::bad_array_new_length is thrown ([expr.new]p8).

cpp.Objects.arrayLengthFunction

Section titled “cpp.Objects.arrayLengthFunction”

long #arrayLength(long n) { if (n < 0) throw std::bad_array_new_length(); return n; }.

cpp.Objects.prepare

Section titled “cpp.Objects.prepare”

A program whose own new T[count]s take their counts through #arrayLength (with it first), as it is if it has none. The library’s (lib: nodes) are not: their counts are sizes, never negative; nor a count written as a number.

cpp.Objects.nullptrType

Section titled “cpp.Objects.nullptrType”

The type of nullptr, std::nullptr_t ([lex.nullptr]p1): a null pointer constant that converts to every pointer type, but not to an integer, nor to bool by copy-initialization ([conv.bool]); a condition takes it as false.

cpp.Objects.lvalue

Section titled “cpp.Objects.lvalue”

C++’s lvalues of objects: a temporary object of a class, T(args) or T{…} (materialized, [class.temporary]p2: a member function can be called on it).

cpp.Objects.deleting

Section titled “cpp.Objects.deleting”

What delete does to a non-null pointer to an object of a class (or no class): the dispatch of its virtual destructor (which destroys and releases the complete object), else its destructor (if it has one) and the release; for delete[], the release of the array.

cpp.Objects.delete

Section titled “cpp.Objects.delete”

delete p and delete[] p: the pointer kept in a variable, and if it is not null, the object destroyed and its block released.

cpp.Objects.element

Section titled “cpp.Objects.element”

The internal statements a container’s elements are handled by (Construction.rawArray): an object constructed at a pointer (a class’s constructor chosen for the arguments; one without constructors copied or left as it is), destroyed there (its class’s destructor, if it has one), moved there as a whole. None for any other call.

cpp.Objects.staticOnce

Section titled “cpp.Objects.staticOnce”

A static declaration of a function initialized when first reached ([stmt.dcl]p4): its declaration under its global’s name (f::x), run once, its object then in the global scope (it ends after main, the latest made first, [basic.start.term]). An exception from its initialization leaves it unmade, to be tried again.

cpp.Objects.madeStatic

Section titled “cpp.Objects.madeStatic”

Whether the global scope has a function’s static object already.

cpp.Objects.promoted

Section titled “cpp.Objects.promoted”

A static object just made moved from the scope it was declared in to the global scope.

cpp.Objects.statement

Section titled “cpp.Objects.statement”

C++’s statements of objects: delete, a static declaration initialized when first reached, and the internal releases.

cpp.Objects.run

Section titled “cpp.Objects.run”

Running a statement of objects: allocating (one object, or an array of count elements) and setting the variable to its pointer; releasing a block new (or new[]) allocated, given by its start (a null pointer does nothing); marking a guard; destroying the elements of a block new[] allocated, the last first (as many as the block has).

cpp.Objects.releasable

Section titled “cpp.Objects.releasable”

Whether a pointer is to the start of a block new (or new[], or the library’s raw allocation) made, so delete (or delete[]) can release it.

cpp.Objects.release

Section titled “cpp.Objects.release”

Releasing a block delete (or delete[]) was given, by its start (a null pointer does nothing); with a choice, the library released it only because of an implementation’s choice (a later stop at it depends on the choice).

cpp.Objects.keep

Section titled “cpp.Objects.keep”

Keeping the block a pointer (an lvalue, such as a vector’s) is to under a new number because of an implementation’s choice: the object moves to the new number, the pointer is set to it, and the old number goes on to the new one (a pointer to it still reaches the object, assuming the choice). A null pointer does nothing.

cpp.Objects.runWith

Section titled “cpp.Objects.runWith”

Running a statement of objects with its statements: a function’s static object made once and moved into the global scope; any other as Objects.run runs it.
