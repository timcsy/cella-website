cpp.Bindings

Section titled “cpp.Bindings”

What the parameters are bound to (a parameter’s name, its argument).

cpp.ClassTemplates

Section titled “cpp.ClassTemplates”

The class templates of a program: each one’s name, parameters and definition.

cpp.Templates.parameterName

Section titled “cpp.Templates.parameterName”

A template parameter’s name.

cpp.Templates.parameterDefault

Section titled “cpp.Templates.parameterDefault”

A template parameter’s default argument, if it has one.

cpp.TemplateDefinition

Section titled “cpp.TemplateDefinition”

A function template: its parameters and its definition.

cpp.FunctionTemplate

Section titled “cpp.FunctionTemplate”

A function template by its name.

cpp.Templates.functions

Section titled “cpp.Templates.functions”

The function templates of the items: name, parameters and definition.

cpp.Templates.valueOf

Section titled “cpp.Templates.valueOf”

The value a parameter is bound to, as an integer, when it is one (a non-type parameter’s argument).

cpp.Templates.collapsed

Section titled “cpp.Templates.collapsed”

A reference to a reference collapsed ([dcl.ref]p6): an lvalue reference if either is one, else an rvalue reference; any other type as it is.

cpp.Templates.substitution

Section titled “cpp.Templates.substitution”

Putting the template’s arguments in place of its parameters: a type parameter by its type (a reference to a reference so made collapsed), a non-type parameter’s uses and the array lengths written with it by its value.

cpp.Templates.bindings

Section titled “cpp.Templates.bindings”

The parameters bound to the arguments, in order.

cpp.Templates.packOf

Section titled “cpp.Templates.packOf”

The type parameter pack a template ends with, if it has one.

cpp.Templates.element

Section titled “cpp.Templates.element”

A function parameter pack’s element (args#i), a declaration of the instance.

cpp.Templates.numberedFrom

Section titled “cpp.Templates.numberedFrom”

The element types of a pack with their positions.

cpp.Templates.elementOf

Section titled “cpp.Templates.elementOf”

A pack expansion’s pattern for one element: the function parameter pack’s uses its element, the type parameter pack its type.

cpp.Templates.expansion

Section titled “cpp.Templates.expansion”

Expanding a function parameter pack x (of the type pack pk) for its element types: each pattern expansion in a call’s arguments one argument per element ([temp.variadic]p8), sizeof...(x) the number of elements.

cpp.Templates.expandedParameters

Section titled “cpp.Templates.expandedParameters”

The parameters with a function parameter pack (P... args) as one parameter per element, args#i.

cpp.Templates.packParameter

Section titled “cpp.Templates.packParameter”

The function parameter pack of the parameters, if there is one.

cpp.Templates.instanceOf

Section titled “cpp.Templates.instanceOf”

A function template’s instance for the arguments: an ordinary function named for them. A variadic one’s last arguments are its pack’s elements: its function parameter pack and the expansions of it are expanded for them.

cpp.Templates.integerSyntax

Section titled “cpp.Templates.integerSyntax”

An integer type as written.

cpp.Templates.named

Section titled “cpp.Templates.named”

A class’s type by its name.

cpp.Templates.unqualified

Section titled “cpp.Templates.unqualified”

A type without its top-level const.

cpp.Templates.argumentName

Section titled “cpp.Templates.argumentName”

The k-th template argument of a class instance, from the hidden typedef the instance comes with.

cpp.Templates.argumentsOf

Section titled “cpp.Templates.argumentsOf”

A class instance’s template arguments (count of them), from its hidden typedefs.

cpp.Templates.lvalueTypeOf

Section titled “cpp.Templates.lvalueTypeOf”

An argument’s type as an lvalue, without its top-level const.

cpp.Templates.valueTypeOf

Section titled “cpp.Templates.valueTypeOf”

An argument’s type as a value (an array or function decayed), without its top-level const.

cpp.Templates.fromArgument

Section titled “cpp.Templates.fromArgument”

Deduces from one argument: a reference parameter against the lvalue’s type, another against the value’s; a forwarding reference (T && of a parameter T) takes an lvalue as U & and an rvalue as U ([temp.deduct.call]p3).

cpp.Templates.bare

Section titled “cpp.Templates.bare”

A written type without its references and top-level const (std::remove_cvref_t).

cpp.Templates.decayed

Section titled “cpp.Templates.decayed”

A written type decayed (std::decay_t, [meta.trans.other]): references and top-level const taken away, an array the pointer to its element.

cpp.Templates.truth

Section titled “cpp.Templates.truth”

A constant template argument as a truth value (an integer, nonzero is true), if it is one.

cpp.Templates.fromTruth

Section titled “cpp.Templates.fromTruth”

A truth value as a constant template argument.

cpp.Templates.traitsDone

Section titled “cpp.Templates.traitsDone”

A substituted default template argument with the standard type traits it uses worked out ([meta]): decay_t, remove_reference_t, remove_cv_t, remove_const_t, is_same_v, !; enable_if_t<c, T> is T (void without it) when c is true and fails when it is false (substitution failure, [temp.deduct]p8: none). Anything else as it is.

cpp.Templates.traitsDoneAll

Section titled “cpp.Templates.traitsDoneAll”

Each argument with its traits worked out, unless one fails.

cpp.Templates.trait

Section titled “cpp.Templates.trait”

A standard trait applied to worked-out arguments (Templates.traitsDone); a template that is not one as it is.

cpp.Templates.completed

Section titled “cpp.Templates.completed”

Every parameter’s argument, in order: the bound one, else its default (which may use the ones before it), with the standard traits it uses worked out; a default whose substitution fails (std::enable_if_t of false) fails the deduction, so the template is not a candidate ([temp.deduct]p8).

cpp.Templates.scalarSpellings

Section titled “cpp.Templates.scalarSpellings”

The scalar types a template argument is spelled as (Templates.spelled), each with its spelling.

cpp.Templates.unspelled

Section titled “cpp.Templates.unspelled”

A template argument back from its spelling, when it is a scalar type or one with const, * or & on it (a class’s spelling does not say whether it is a class, a struct or a typedef: none).

cpp.Templates.splitArguments

Section titled “cpp.Templates.splitArguments”

Text split at its top-level commas (not inside angle brackets), each part as written after the comma.

cpp.Templates.argumentText

Section titled “cpp.Templates.argumentText”

A template argument’s text without the space Templates.spelledAll writes after a comma.

cpp.Templates.overloads

Section titled “cpp.Templates.overloads”

The function templates of a name (overloads of one name, [temp.over]).

cpp.Templates.overloadFor

Section titled “cpp.Templates.overloadFor”

Among the function templates of a name, the one an instance with a number of template arguments is of: the only one, or the one with as many parameters (or with a pack, which takes the rest); overloads that deduce the same number of arguments are not chosen between (Templates.chosen).

cpp.Templates.madeInPlace

Section titled “cpp.Templates.madeInPlace”

Whether an instance’s definition can be made from the template as the program is checked: its body has no lambda (the program’s passes make a class for each) and every class template’s instance it writes is a class the program has (they are made when the program is prepared).

cpp.Templates.instantiated

Section titled “cpp.Templates.instantiated”

A function template’s instance by its name (twice<int>): the template’s definition with the arguments in place, when the name is the template’s with scalar arguments spelled as Templates.instanceName spells them and the body can be made in place; none otherwise (the call asks for it: the program is prepared and checked again).

cpp.Templates.packElements

Section titled “cpp.Templates.packElements”

A pack’s element types from the arguments after the other parameters: each one deduced alone against the pattern ([temp.deduct.call]p1).

cpp.Templates.deduceVariadic

Section titled “cpp.Templates.deduceVariadic”

The template arguments a variadic template’s call deduces: the parameters before the pack as any template’s, then the pack’s elements from the remaining arguments.

cpp.Templates.deduce

Section titled “cpp.Templates.deduce”

The template arguments a call deduces: the written ones first, then from the arguments.

cpp.Templates.deduceFixed

Section titled “cpp.Templates.deduceFixed”

The template arguments a call of a template without a pack deduces.

cpp.Templates.hasOrdinary

Section titled “cpp.Templates.hasOrdinary”

Whether ordinary functions have the name too (one, or overloads f#k): a call without template arguments then chooses among them and the template’s instance (Overloading.withTemplate).

cpp.Templates.chosen

Section titled “cpp.Templates.chosen”

The function a call of a function template’s name calls: its instance for the deduced arguments, or that instance asked for.

cpp.Templates.takes

Section titled “cpp.Templates.takes”

Whether a function takes a number of arguments: no fewer than its parameters without defaults, no more than its parameters; a function parameter pack takes any number, none too ([temp.variadic]p3).

cpp.Templates.leftover

Section titled “cpp.Templates.leftover”

A pack expansion or sizeof... left after instantiation: an expansion somewhere other than a call’s arguments is not supported yet; sizeof... of a name that is not a function parameter pack is not C++ ([expr.sizeof]p5).

cpp.Templates.expression

Section titled “cpp.Templates.expression”

A call of a function template as an expression: its instance’s call.

cpp.Templates.autoAsParameter

Section titled “cpp.Templates.autoAsParameter”

A declared type with auto in it, auto as the template parameter #auto (deduced as a function template’s parameter is, [dcl.type.auto.deduct]p4).

cpp.Templates.hasAuto

Section titled “cpp.Templates.hasAuto”

Whether a written type has auto in it.

cpp.Templates.autoDeclaration

Section titled “cpp.Templates.autoDeclaration”

A declaration whose type has auto in it ([dcl.spec.auto]) made concrete: the type deduced from the initializer as a function template’s parameter of that type from its argument (auto drops references and top-level const, auto & binds the lvalue, const auto & reads it). Without an initializer there is nothing to deduce from.

cpp.Templates.boundArray

Section titled “cpp.Templates.boundArray”

The object a structured binding copies when it is an array (auto [a, b] = arr): an array of the same type, each element copy-initialized from the array’s ([dcl.struct.bind]p1; auto alone would decay it to a pointer); none for any other declaration. An array that is not a variable is not done (its elements would be evaluated again for each).

cpp.Templates.statement

Section titled “cpp.Templates.statement”

A call of a function template as a statement: its instance’s call.

cpp.Templates.answer

Section titled “cpp.Templates.answer”

The answer to C++’s request: the items with the function template’s instance for the arguments added (the template found among the items as checking saw them: a namespace’s with its full name, a generated one).

cpp.Templates.classes

Section titled “cpp.Templates.classes”

The class templates of the items: name, parameters and definition.

cpp.Templates.classNode

Section titled “cpp.Templates.classNode”

A class template’s node, by its name.

cpp.Templates.specializations

Section titled “cpp.Templates.specializations”

The full specializations of class templates (template <> class C<int>): the instance’s name and definition.

cpp.Partial

Section titled “cpp.Partial”

A partial specialization of a class template: the template’s name, its parameters, the arguments it is for (a pattern in its parameters) and its definition.

cpp.Templates.partials

Section titled “cpp.Templates.partials”

The partial specializations of the items.

cpp.Templates.same

Section titled “cpp.Templates.same”

Whether two template arguments are the same.

cpp.Partial.atLeastAs

Section titled “cpp.Partial.atLeastAs”

Whether a partial specialization is at least as specialized as another ([temp.class.order]): the other’s pattern matches this one’s (its parameters taken as types of their own).

cpp.Partial.mostSpecialized

Section titled “cpp.Partial.mostSpecialized”

The one more specialized than every other of the candidates, if there is one.

cpp.Instance

Section titled “cpp.Instance”

An instance of a class template: the template’s name, its arguments and its definition (the arguments in place).

cpp.Instance.name

Section titled “cpp.Instance.name”

An instance’s name.

cpp.Templates.definitionFor

Section titled “cpp.Templates.definitionFor”

What a class template’s definition is for these arguments, with its parameters bound: a full specialization, else the one most specialized partial specialization the arguments match, else the template itself; two or more matching with none most specialized is an error ([temp.class.spec.match]p2).

cpp.Templates.classInstance

Section titled “cpp.Templates.classInstance”

A class template’s instance: its definition with the arguments in place, the template’s own name in it the instance ([temp.local]p1).

cpp.Templates.filled

Section titled “cpp.Templates.filled”

A use’s default template arguments filled in ([temp.param]p10: C<int> of template <class T, int N = 4> is C<int, 4>; a default may use the parameters before it).

cpp.Templates.fillArguments

Section titled “cpp.Templates.fillArguments”

Arguments with the parameters’ defaults after them.

cpp.Templates.usesIn

Section titled “cpp.Templates.usesIn”

The class template instances some types use (the arguments without parameters).

cpp.Templates.instanceLimit

Section titled “cpp.Templates.instanceLimit”

The most instances a program’s class templates may have.

cpp.Templates.closure

Section titled “cpp.Templates.closure”

The instances the uses need, and the ones those need, in the order found.

cpp.Templates.memberType

Section titled “cpp.Templates.memberType”

A member type of a class written by the name of its typedef (C::name, which the class’s lowering declares, cpp.classes), once the class is known (a template’s instance written as its class first).

cpp.Templates.asClass

Section titled “cpp.Templates.asClass”

A use’s instance written as the class it is (after the defaults are filled).

cpp.Instance.items

Section titled “cpp.Instance.items”

An instance’s items: its class and the hidden typedefs that keep its template arguments (deduction reads them).

cpp.Templates.placed

Section titled “cpp.Templates.placed”

The items with each instance placed before the first item that uses it (and what it uses before it).

cpp.Templates.specialized

Section titled “cpp.Templates.specialized”

A function template’s explicit specialization (template <> int f<int>(int)) as the instance it is.

cpp.Templates.prepare

Section titled “cpp.Templates.prepare”

A program with its class templates instantiated: each instance a class placed before its first use, the uses naming it; the function templates kept for checking to instantiate.
