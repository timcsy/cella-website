The name of a class’s destructor’s function.

cpp.Classes.named

Section titled “cpp.Classes.named”

The class a written type names, among the known ones; a const class is still that class ([basic.type.qualifier]p1), so a const object is constructed and destroyed as any other.

Section titled “cpp.TypeSyntax.dimensions”

The lengths of a written array type’s dimensions, outermost first, and its element type (no lengths for a type that is not an array).

How many elements an array of the lengths has.

The class a written type is, or the class of its elements when it is an array (of arrays) of one.

Whether a written type is an array.

The j-th element (row by row; j a surface expression) of an array of the given lengths: a[j / d1][j % d1].

A loop over the indices of count elements (the first first, or the last first), with a statement for each.

Whether a member function is virtual as declared (virtual, override or pure).

Section titled “cpp.Member.isHidden”

Whether a data member is one of a class’s hidden parts that a copy keeps its own of: the dynamic type, the pointers to its virtual bases, and their storage (a copy’s virtual bases are made by the complete object).

Whether a class needs a constructor it does not declare: a default member initializer, a member of a class with constructors ([class.default.ctor]p4), or a dynamic type to keep (a polymorphic class).
