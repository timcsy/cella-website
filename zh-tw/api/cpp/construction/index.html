cpp.Construction.rawArray

Section titled “cpp.Construction.rawArray”

The internal functions a container’s generated code calls for its elements (as std::allocator and std::allocator_traits do): a block of elements allocated without constructing them (#rawArray(new T[n])), an object constructed at a pointer with arguments (placement new, #construct(p, args)), one destroyed there (#destroy(p), nothing for an element without a destructor), a block released without destroying its elements (#releaseRaw(p)), an object moved to a pointer as a whole (#relocate(to, from): the source is not destroyed afterwards, as a moved-from vector or string owns nothing).

cpp.Construction.constructAt

Section titled “cpp.Construction.constructAt”

Placement new (see Construction.rawArray).

cpp.Construction.destroyAt

Section titled “cpp.Construction.destroyAt”

An object’s destruction at a pointer (see Construction.rawArray).

cpp.Construction.releaseRaw

Section titled “cpp.Construction.releaseRaw”

A block’s release without destroying its elements (see Construction.rawArray).

cpp.Construction.valueConstructAt

Section titled “cpp.Construction.valueConstructAt”

The internal function value-initializing an object at a pointer (::new (p) T(), [dcl.init]p9): a scalar zero, an object of a class by its default constructor.

cpp.Construction.relocate

Section titled “cpp.Construction.relocate”

An object moved as a whole (see Construction.rawArray).

cpp.TypedCpp

Section titled “cpp.TypedCpp”

A typed statement of C++.

cpp.Assigning

Section titled “cpp.Assigning”

How a value is converted for storing into an object of a type (the dialect’s assignment conversion).

cpp.Choosing

Section titled “cpp.Choosing”

What choosing a constructor uses: the types, the assignment conversion, and the checker of expressions.

cpp.Constructing

Section titled “cpp.Constructing”

What checking a construction as a statement uses: what choosing uses, and the checker of statements.

cpp.Construction.resolve

Section titled “cpp.Construction.resolve”

A written type resolved and completed (a class’s struct with its members).

cpp.Construction.promotes

Section titled “cpp.Construction.promotes”

Whether a type converts to another by a promotion ([conv.prom], [conv.fpprom]): an integer type to its promoted type, float to double.

cpp.Construction.rank

Section titled “cpp.Construction.rank”

How well an argument matches a parameter ([over.ics.rank]), if it can be passed at all: by the conversion, 0 the same type (or a reference bound to it), 1 a promotion, 2 any other standard conversion, 3 a pointer converted to void * or bool, 4 a user-defined conversion; four times that, and two more for const added to a pointer’s pointee. Which of two reference bindings is better is told apart by the parameter types (Construction.betterBinding).

cpp.Construction.lessQualifiedBinding

Section titled “cpp.Construction.lessQualifiedBinding”

Whether binding an argument to a reference of the parameter type a is a better conversion than to one of b ([over.ics.rank]p3.2.6): both references to the same type but for top-level cv-qualifiers (compared with k’s types), b’s referent const and a’s not (int & against const int &). A parameter that is no reference never is.

cpp.Construction.betterBinding

Section titled “cpp.Construction.betterBinding”

Whether binding an argument to a reference of the parameter type a is a better conversion than to one of b, both viable for it ([over.ics.rank]p3.2.3 then p3.2.6): a an rvalue reference and b an lvalue reference (both viable, the argument is an rvalue, or a temporary made from it), or else the less cv-qualified (Construction.lessQualifiedBinding). A parameter that is no reference never is: by value against by reference is as good. The types are compared with k’s.

cpp.Construction.compared

Section titled “cpp.Construction.compared”

For each argument, whether one candidate’s conversion (its rank in a, its parameter in pa) is no worse than another’s (b, pb), and whether it is better ([over.ics.rank]): a lower rank, or the same rank and the better reference binding (Construction.betterBinding, which tells apart only two reference bindings). The ranks are the arguments’ (and a member function’s object’s first, its parameter this); the parameters run at least as far, their types compared with k’s.

cpp.Construction.noWorse

Section titled “cpp.Construction.noWorse”

Whether one candidate’s conversions (ranks a, parameters pa) are no worse than another’s (b, pb) for every argument (Construction.compared, with k).

cpp.Construction.better

Section titled “cpp.Construction.better”

Whether one candidate’s conversions (ranks a, parameters pa) are no worse than another’s (b, pb) for every argument and better for one ([over.match.best]p2, Construction.compared with k).

cpp.Construction.parametersOf

Section titled “cpp.Construction.parametersOf”

The constructor f’s parameter types after this, from the lowered function’s signature in the globals g.

cpp.Construction.ranks

Section titled “cpp.Construction.ranks”

The ranks of a constructor’s parameters for the arguments, if every argument can be passed (the parameters after this, from the lowered function’s signature).

cpp.Viable

Section titled “cpp.Viable”

A viable constructor for a construction’s arguments: the constructor (a constructor template’s with its instance as the function), its parameters’ ranks and types (after this), and for a constructor template the template and the arguments deduced (its instance is asked for when the program does not have it yet).

cpp.Construction.templateViable

Section titled “cpp.Construction.templateViable”

The constructor template f’s instance for the arguments args, if viable ([temp.deduct.call], [over.match.funcs]p7; k checks, in the globals g, at the node n): the template arguments deduced from the arguments’ types (the function template f.function is the constructor lowered, this first, Classes.constructorTemplateItems; a default template argument whose substitution fails is no candidate), each argument ranked against its parameter with the deduced arguments in place.

cpp.Viable.beats

Section titled “cpp.Viable.beats”

Whether the viable constructor c is better than d ([over.match.best]p2, the conversions compared with k’s types): no worse for every argument, and better for one, or c is not a template’s instance and d is (p2.4).

cpp.Viable.chosen

Section titled “cpp.Viable.chosen”

The chosen constructor v, its function the program’s (in the globals g): a constructor template’s instance the program does not have yet is asked for (the program is prepared and checked again with it, as a function template’s).

cpp.Construction.choose

Section titled “cpp.Construction.choose”

The constructor for the arguments: among those taking as many (or more, with defaults), the ones every argument can be passed to, and of those the one better than every other ([over.match.best]); a constructor template is a candidate by the instance its deduction gives (Construction.templateViable); none is no match, several are ambiguous. For a library class neither is an error of the program: the library models a standard class without every overload, so the standard’s may have one (not provided, as Overloading.pick says of a member function).

cpp.Construction.trivialCopy

Section titled “cpp.Construction.trivialCopy”

A copy of an object of a class without a copy constructor (its implicit one is trivial, [class.copy.ctor]p12): the other object (of the class, or of one derived from it: its base subobject) stored bit for bit. None unless the one argument is such an object.

cpp.Construction.constructorCall

Section titled “cpp.Construction.constructorCall”

The call of a class’s constructor on an object (its address and the arguments), checked as a statement: the constructor chosen for the arguments, accessible here.

cpp.TypedExpr.isTemporary

Section titled “cpp.TypedExpr.isTemporary”

Whether an expression is a temporary the full expression ends (a call’s result, kept in a variable named for it).

cpp.Construction.fromTemporary

Section titled “cpp.Construction.fromTemporary”

An object initialized by a temporary of its class (a call’s result): the temporary becomes the object, without a copy ([dcl.init]p17.6.1, C++17’s guaranteed elision); it is handed over, so the full expression’s end does not destroy it. None when the initializer is anything else.

cpp.Construction.declareOf

Section titled “cpp.Construction.declareOf”

A declaration of an object of a class with constructors (its type resolved): initialized by a temporary of its class, else reserved, constructed with the arguments, and only then an object (a constructor that throws leaves none to destroy, [except.ctor]p3). A const object is not const while it is constructed ([class.ctor]p5).

cpp.Construction.declareObject

Section titled “cpp.Construction.declareObject”

A declaration of an object of a class with constructors, by its written type.

cpp.Construction.arguments

Section titled “cpp.Construction.arguments”

The arguments of an initializer for a constructor: none, the expression, or the braced list’s expressions.

cpp.Construction.classOf

Section titled “cpp.Construction.classOf”

The class with constructors a declaration’s type names, if any.

cpp.Construction.isAggregate

Section titled “cpp.Construction.isAggregate”

Whether a class is an aggregate ([dcl.init.aggr]p1): it declares no constructor (the ones it has are implicit), has no virtual function and no virtual base, and its direct bases and data members (by the globals g) are public.

cpp.Construction.oneOfClass

Section titled “cpp.Construction.oneOfClass”

Whether args are one object of the class cls or of a class derived from it (its base subobject), checked by k with the globals g and the scope env.

cpp.Construction.aggregateItems

Section titled “cpp.Construction.aggregateItems”

The items of a braced list xs that initialize an object of the aggregate cls member by member ([dcl.init.list]p3.3, [dcl.init.aggr]p4), when the class has constructors (all implicit: a member of a class with constructors, a default member initializer; the core initializes an aggregate without any): a list that is not empty ({} value-initializes it, by its implicit default constructor) and not one object of the class (copied, [dcl.init.list]p3.2; checked by k with the globals g in the scope env).

cpp.Construction.scalar

Section titled “cpp.Construction.scalar”

A member that is not of a class with constructors initialized in a constructor: the value (zero for x()) converted to the member’s type and stored, even into a const member (an initialization, not an assignment).

cpp.Construction.guarded

Section titled “cpp.Construction.guarded”

A constructed member’s guard after its construction: a pointer to it, declared in the constructor’s scope (named, so it is no temporary of the full expression and lasts to the scope’s end), which destroys it when an exception leaves the constructor ([except.ctor]p3: the constructed members and bases, in reverse order).

cpp.Construction.member

Section titled “cpp.Construction.member”

A member initialized in a constructor: one of a class with constructors is constructed (this->y with the arguments), any other initialized by its value; guarded when its class has a destructor.

cpp.Construction.defaulted

Section titled “cpp.Construction.defaulted”

A member of a class without constructors default-initialized in a constructor: nothing stored, but guarded (the member’s class has a destructor, so it is destroyed if a later member throws, [except.ctor]p3).

cpp.Construction.declaredObject

Section titled “cpp.Construction.declaredObject”

A declaration of an object of a class with constructors (no initializer-list constructor taking its list).

cpp.Construction.listTaken

Section titled “cpp.Construction.listTaken”

The std::initializer_list<E> instance a member function of the signature s takes as its one parameter after this (by value or by reference, [dcl.init.list]p2), with E, if that is what it takes. g holds the declarations of the program.

cpp.Construction.listParameter

Section titled “cpp.Construction.listParameter”

The std::initializer_list<E> instance a class’s initializer-list constructor takes, with E, if it has one. g holds the declarations of the program, cls is the class.

cpp.Construction.itemFits

Section titled “cpp.Construction.itemFits”

Whether one item of a braced list can initialize an element of type t ([over.ics.list]p6: an initializer-list function is viable only when every item converts to the element type; narrowing is not part of that, it is an error once the function is chosen). An item that does not check is left to the declaration of the list, which reports it. k checks the item and ranks its conversion, g and env are the declarations and the scope it is checked in, n is the node of the list, i the item.

cpp.Construction.listFits

Section titled “cpp.Construction.listFits”

Whether every item of the braced list xs can initialize an element of the written type element. k checks the items and ranks their conversions, g and env are the declarations and the scope they are checked in, n is the node of the list.

cpp.Construction.fromList

Section titled “cpp.Construction.fromList”

An object of the class cls (with an initializer-list constructor taking list) constructed at place from the braced list’s items xs ([dcl.init.list]p3.6, p5): in a block of its own, the backing array const E[n] initialized from them (each copy-initialized), then the constructor called with std::initializer_list<E>(array, n), then after; the block’s end destroys the array. The array and the list object are named for n, the list’s node; k checks the statements in the context c and the scope env.

cpp.Construction.listFor

Section titled “cpp.Construction.listFor”

The initializer-list constructor’s list type a braced list with items xs initializes an object of the class cls by (in the globals g), if any: none for an empty list when the class has a default constructor, which value-initializes it ([dcl.init.list]p3.4, before p3.6: vector<vector<int>> d = {{4, 1}, {}}’s second element is empty, not built from a list of none).

cpp.Construction.listAt

Section titled “cpp.Construction.listAt”

Construction.listFor, the list also viable for the items as checked in the scope env ([over.match.list]p1: when no initializer-list constructor is viable, the other constructors are tried with the items as arguments: vector<string> v{2, "x"}, string s{name}). k chooses, g holds the declarations of the program, n is the node of the list, cls the class, xs the items.

cpp.Construction.listed

Section titled “cpp.Construction.listed”

C x = {a, b…} (the declaration n of x, shown as name, of type u, items xs) for a class cls with an initializer-list constructor taking list: x reserved, then constructed from the list (Construction.fromList, with k, c and env) and marked constructed in the list’s block.

cpp.Construction.directScalar

Section titled “cpp.Construction.directScalar”

T x(args); of a type that is not a class: a scalar’s is its initialization by the one argument (int z(7);, [dcl.init]p17.8), none is default initialization (as T x;), more is excess elements in scalar initializer (clang’s words); any other type takes no constructor’s arguments.

cpp.Construction.statement

Section titled “cpp.Construction.statement”

C++’s statements that construct objects.

cpp.Construction.defaultDeleted

Section titled “cpp.Construction.defaultDeleted”

Whether a declaration default-initializes an object (or an array of them) of a class that cannot be ([class.default.ctor]p2: its implicit default constructor deleted, or no constructor callable without arguments).

cpp.Construction.noDefault

Section titled “cpp.Construction.noDefault”

Why an object of a class cannot be default-initialized.

cpp.Construction.declared

Section titled “cpp.Construction.declared”

What a statement of C++ declares: C x(args); declares x.

cpp.Construction.destroying

Section titled “cpp.Construction.destroying”

The call of an object’s class’s destructor (given a pointer to it), if the program has one.

cpp.Construction.ending

Section titled “cpp.Construction.ending”

What runs before an object ends: its class’s destructor, if the program has one; for a member’s guard, the member’s destructor when an exception leaves the scope, else nothing.
