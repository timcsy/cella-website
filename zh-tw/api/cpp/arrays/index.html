cpp.Ty.dimensions

Section titled “cpp.Ty.dimensions”

The lengths of an array type’s dimensions, outermost first, and its element type.

cpp.Ty.withoutConstElements

Section titled “cpp.Ty.withoutConstElements”

An array type with its elements’ const taken away (as an object under construction is, [class.ctor]p5).

cpp.TypeSyntax.withoutConstElements

Section titled “cpp.TypeSyntax.withoutConstElements”

A written array type with its elements’ const taken away, if they are const.

cpp.Arrays.ofClass

Section titled “cpp.Arrays.ofClass”

The class of an array’s elements, when the written type is an array of a class with constructors or a destructor.

cpp.Arrays.constructedClass

Section titled “cpp.Arrays.constructedClass”

The class of an element type (after its dimensions) when its objects are constructed or destroyed.

cpp.Arrays.elementOf

Section titled “cpp.Arrays.elementOf”

The k-th element of an array (an lvalue): *(a + k) with the array decayed.

cpp.Arrays.leafLvalue

Section titled “cpp.Arrays.leafLvalue”

The j-th element (row by row) of an array (an lvalue) of a type.

cpp.Arrays.lastFirst

Section titled “cpp.Arrays.lastFirst”

The statements for the elements j, j + 1, … (left of them) put before acc, each in front of the earlier ones: the last element’s first. A loop (the call is the last thing done): an array of ten thousand elements made the list functions’ recursion overflow the browser’s stack.

cpp.Arrays.destroyingLeaves

Section titled “cpp.Arrays.destroyingLeaves”

The destruction of an array’s first count elements (row by row), the last first.

cpp.Arrays.destroyingThrough

Section titled “cpp.Arrays.destroyingThrough”

The destruction of the first count elements a pointer points to (new[]’s), the last first.

cpp.Arrays.givenWithin

Section titled “cpp.Arrays.givenWithin”

The elements an initializer list gives, by their index (row by row) and their arguments: a nested list gives a row, an expression the next element (a list in a list is the next row’s).

cpp.Arrays.given

Section titled “cpp.Arrays.given”

The elements an initializer gives (none for no initializer).

cpp.Arrays.guardName

Section titled “cpp.Arrays.guardName”

The guard of an array’s construction, by a key the scope has once (the declaration’s or the member’s name).

cpp.Arrays.countName

Section titled “cpp.Arrays.countName”

The count of the elements a guard’s array has constructed (a variable beside the guard).

cpp.Arrays.sourceElement

Section titled “cpp.Arrays.sourceElement”

The element of a source array (of the given lengths) an element is constructed from: an xvalue array’s elements are xvalues ([expr.sub]p2), each moved from.

cpp.Arrays.elided

Section titled “cpp.Arrays.elided”

An element’s arguments, a prvalue of its class (C(args)) given alone being that object, constructed in place from args (C++17’s guaranteed elision, [dcl.init]p17.6.1). Not provided: a call’s result likewise.

cpp.Arrays.building

Section titled “cpp.Arrays.building”

The construction of an array (the target, of type t) of a class, element by element: a guard with the count beside it, the elements given (with their arguments), then a loop over the rest, each by the default constructor or from the source array’s element of the same index; the count follows each element.

cpp.Arrays.declaration

Section titled “cpp.Arrays.declaration”

A declaration of an array of a class: reserved, its elements constructed in a block (whose guard ends with it), then an object. Designators are not done (an array’s are clang’s extension in C++, and each element is constructed).

cpp.Arrays.member

Section titled “cpp.Arrays.member”

A member that is an array, initialized in a constructor: an array of a class element by element (its guard in the constructor’s scope, destroying the constructed elements when an exception leaves the constructor), from the source array’s elements for a copy; any other copied from the source as a whole. None for a member that is no array.

cpp.Arrays.statement

Section titled “cpp.Arrays.statement”

C++’s statements of arrays of objects: a declaration of one, a member that is an array initialized in a constructor, a variable length array of them (not done).

cpp.Arrays.constructedCount

Section titled “cpp.Arrays.constructedCount”

The count a guard’s array has constructed (the variable beside the guard; none counted is 0).

cpp.Arrays.destroys

Section titled “cpp.Arrays.destroys”

Whether an array’s elements are of a class with a destructor the program has.

cpp.Arrays.ending

Section titled “cpp.Arrays.ending”

What runs before an object ends, with arrays of a class: an array’s elements destroyed, the last first; an array’s guard (or new[]’s, with a count beside it), when an exception leaves the scope, the elements constructed so far; anything else as Construction.ending says.
