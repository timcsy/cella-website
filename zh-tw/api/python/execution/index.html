python.Run

Section titled “python.Run”

A run’s state: the heap, the global and local variables by slot, the console, the random generator, the exception the last expression raised, and the exceptions being handled (innermost first); between preparing a call and entering it, the bound arguments, the function’s position in the table, the instance a class call makes (its __init__ is the function called), and the locals a resumed generator’s continuation starts with.

python.Signal

Section titled “python.Signal”

What a statement returns: a function’s value, or an exception unwinding.

python.Stop

Section titled “python.Stop”

Why a run stops: something the model cannot do, or waiting for input.

python.Code

Section titled “python.Code”

Python’s statements.

python.Evaluation

Section titled “python.Evaluation”

What evaluating an expression gives: the state after it and a value, or the state after it and an exception.

python.Expression

Section titled “python.Expression”

Python’s expressions.

python.Run.start

Section titled “python.Run.start”

A run that is about to start: an empty heap, a number of global slots, no locals, a console with the input.

python.Heap.chosenOrder

Section titled “python.Heap.chosenOrder”

The implementation’s choices the order of the heap’s sets depends on, each named once.

python.Run.assumptions

Section titled “python.Run.assumptions”

The implementation’s choices a run assumes, each named once: str.hash (a set ordered by a str’s hash, taken as under PYTHONHASHSEED=0), object.address (a set ordered by objects’ hashes, or an object’s address shown as text, from the model’s addresses) and random.seed (a draw before any seed, taken as after seed(0)).

python.Run.shown

Section titled “python.Run.shown”

Values about to be shown as text (repr or str of each): the run noting object.address when the text shows an object’s address (the model’s allocation rule, not CPython’s memory); showing a user’s function is what the model cannot do (CPython shows the function’s address, and a function value of the model has none).

python.Run.afterShown

Section titled “python.Run.afterShown”

What follows showing values as text (Run.shown): the evaluation on the run that noted it, or what the model cannot do.

python.Run.withHeap

Section titled “python.Run.withHeap”

The run with another heap.

python.Run.withConsole

Section titled “python.Run.withConsole”

The run with another console.

python.Run.withPending

Section titled “python.Run.withPending”

The run with an exception pending (or none).

python.Expr.constant

Section titled “python.Expr.constant”

A constant.

python.Expr.bind

Section titled “python.Expr.bind”

An expression’s value given to what follows, or its exception passed on.

python.Expr.all

Section titled “python.Expr.all”

Expressions in order, their values to what follows (Python evaluates operands left to right).

python.Expr.outcome

Section titled “python.Expr.outcome”

An outcome of the data layer on the current heap.

python.Expr.changed

Section titled “python.Expr.changed”

A change of the heap by the data layer.

python.Place

Section titled “python.Place”

Where a variable lives: a global slot, a local slot, or a cell (captured by a nested function) whose reference is in a local slot; with its name for the messages.

python.Run.slot

Section titled “python.Run.slot”

A slot’s value.

python.Expr.read

Section titled “python.Expr.read”

Reading a variable: NameError for a global without a value, UnboundLocalError for a local, a cell’s errors for a captured one.

python.Run.store

Section titled “python.Run.store”

A variable given a value.

python.Run.localValue

Section titled “python.Run.localValue”

A local slot’s value (None when it has none).

python.Run.placeValue

Section titled “python.Run.placeValue”

The value in a variable’s slot (None when it has none; a cell’s slot holds its reference).

python.Exec.keep

Section titled “python.Exec.keep”

Keeping the state as it is (an expression statement’s value is dropped).

python.Exec.storing

Section titled “python.Exec.storing”

Storing a value into a variable.

python.Raised.ofBuiltin

Section titled “python.Raised.ofBuiltin”

A built-in exception raised with its type and message.

python.Run.cannot

Section titled “python.Run.cannot”

The exception a stop reports: what the model cannot do.

python.Exec.evaluate

Section titled “python.Exec.evaluate”

Evaluating an expression, then changing the state with its value; an exception becomes pending (what the model cannot do stops the run).

python.Exec.check

Section titled “python.Exec.check”

Raising the pending exception, if there is one.

python.Exec.checkAt

Section titled “python.Exec.checkAt”

Raising the pending exception, if there is one, marked as raised at a node when it has no node yet (the innermost one, as a traceback’s last line; not the model’s own nodes, builtin ... and model ...).

python.Exec.at

Section titled “python.Exec.at”

A source statement: its node for the debugger, the work, the check.

python.Exec.assign

Section titled “python.Exec.assign”

x = e (one target).

python.Exec.expression

Section titled “python.Exec.expression”

An expression statement: its value is dropped.

python.Expr.print

Section titled “python.Expr.print”

print(*values, sep=' ', end='\n'): the str of each value (an int too long is ValueError), sep between, end after (sep and end must be None or a str).

python.Expr.truth

Section titled “python.Expr.truth”

The truth of a value for if and while (a user’s __bool__ or __len__ is the lowering’s to run first).

python.Exec.holds

Section titled “python.Exec.holds”

A truth already evaluated into a slot, as the machine’s condition.

python.Exec.ifThen

Section titled “python.Exec.ifThen”

if c: yes else: no: the condition’s truth evaluated into a slot first (it may raise).

python.Exec.whileLoop

Section titled “python.Exec.whileLoop”

while c: body: each round the condition’s truth into a slot, leaving when it is false.

python.Exec.breakOut

Section titled “python.Exec.breakOut”

break and continue.

python.Exec.continueOn

Section titled “python.Exec.continueOn”

continue.

python.Exec.returnWith

Section titled “python.Exec.returnWith”

return e: the value evaluated into a slot, then returned.

python.Raised.ofInstance

Section titled “python.Raised.ofInstance”

An instance of a user’s exception class, raised: its classes, its text, its object.

python.Raised.ofClass

Section titled “python.Raised.ofClass”

A user’s exception class raised as a class: a new instance with no arguments, raised.

python.Raised.ofValue

Section titled “python.Raised.ofValue”

The exception a raised value is: an exception instance (built-in or a user’s), or a class instantiated with no arguments; TypeError for anything else.

python.Exec.raise

Section titled “python.Exec.raise”

raise e: the exception pending (a value that is not an exception is TypeError).

python.Exec.reraise

Section titled “python.Exec.reraise”

A bare raise: the exception being handled again; RuntimeError when none is.

python.Exec.run

Section titled “python.Exec.run”

Running a statement on a state with a budget of moves.

python.Exec.change

Section titled “python.Exec.change”

A change of the state that cannot fail.

python.Exec.only

Section titled “python.Exec.only”

A switch block that does not fall through to the next (the machine’s switch is C’s).

python.Exec.caseAt

Section titled “python.Exec.caseAt”

The switch label of block k.

python.Raised.value

Section titled “python.Raised.value”

The exception a value is when it is caught: the object of a user’s exception, else a built-in exception’s value.

python.Raised.isInstance

Section titled “python.Raised.isInstance”

Whether an except clause’s class catches an exception: a built-in class by the exception’s chain (a built-in exception’s chain from its type), a user’s class by isinstance of the exception’s object.

python.Raised.isAny

Section titled “python.Raised.isAny”

Whether any of the classes catches an exception.

python.Clause

Section titled “python.Clause”

An except clause: the classes it catches (read from the state when an exception arrives; none: a bare except), where as binds the exception, and its body.

python.Clause.first

Section titled “python.Clause.first”

The first clause that catches an exception.

python.Run.catching

Section titled “python.Run.catching”

The state when a clause catches an exception: nothing pending, the exception handled, bound with as.

python.Run.handled

Section titled “python.Run.handled”

The state after a clause: the exception no longer handled.

python.Exec.tryExcept

Section titled “python.Exec.tryExcept”

try: body except ...: clauses else: otherwise: a clause that catches the exception runs with it handled (its end, by any way out, stops handling it); no clause catching passes the exception on; else runs when the body raised nothing (a slot of the lowering’s marks that).

python.Exec.clauseBody

Section titled “python.Exec.clauseBody”

The body of the clause that caught an exception (looked up again from the state the catch left), chosen by tests one after another: not a switch, whose blocks a break in the clause would leave instead of the loop.

python.Exec.clauseFrom

Section titled “python.Exec.clauseFrom”

The clauses from position k: the body of the one at the caught position.

python.Clause.index

Section titled “python.Clause.index”

Where the first clause catching an exception is.

python.Exec.tryFinally

Section titled “python.Exec.tryFinally”

finally: the cleanup runs on every way out of the body (an exception’s pending mark cleared first).

python.Function

Section titled “python.Function”

A user’s function as the program’s table has it: its function value’s name, its parameters, and how many local slots its body uses.

python.Run.construct

Section titled “python.Run.construct”

Calling a user’s class: a new instance, then its __init__ (a user’s function, bound to the instance) prepared with the arguments and the instance kept for when it returns; without one, TypeError for arguments the class does not take (Objects.withoutInit), else the instance.

python.Run.showsArguments

Section titled “python.Run.showsArguments”

Whether a built-in shows its arguments as text, and how (repr is true): repr and ascii by repr; str, format, print and input (its prompt) by str.

python.Run.native

Section titled “python.Run.native”

A built-in’s call, after what it shows of its arguments is noted (Run.shown).

python.Run.raisedForKeys

Section titled “python.Run.raisedForKeys”

An exception raised while looking up keys: a KeyError’s message is the key’s repr, so the run goes on after Run.shown on the keys (or with what the model cannot do); any other exception as it is.

python.Run.builtinClass

Section titled “python.Run.builtinClass”

Calling a built-in class: an exception class makes an instance with the arguments as its args (TypeError for keyword arguments), any other is the built-in function of its name (int, str, list and so on).

python.Run.prepare

Section titled “python.Run.prepare”

Preparing a call: a user’s class makes an instance (Run.construct), a built-in class is called (Run.builtinClass), anything else is a function’s call.

python.Function.index

Section titled “python.Function.index”

Where a function is in the table, by its value’s name.

python.Exec.recursionLimit

Section titled “python.Exec.recursionLimit”

The most frames of the user’s functions there are at once (CPython’s recursion limit of 1000, the module’s frame being one).

python.Function.internal

Section titled “python.Function.internal”

Whether a function in the table is the model’s own (a built-in generator’s continuation, builtin map.<resume>, or a helper such as model sort; a user’s name has no space): CPython runs those in C, so their frames do not count toward the recursion limit.

python.Exec.builtinName

Section titled “python.Exec.builtinName”

A built-in function’s name from its value (builtin len).

python.Run.prepareFunction

Section titled “python.Run.prepareFunction”

Preparing a call once the callee and the arguments are known: a user’s function’s parameters bound, the cells its value captured after them (its position in the table is the call’s target), a built-in one called right away (its result stored, no target; the random module’s draw from the run’s generator); TypeError for a value that cannot be called.

python.Exec.indexIn

Section titled “python.Exec.indexIn”

Where a function is in the table, by its value’s name.

python.Value.functionName

Section titled “python.Value.functionName”

A function value’s name, if a value is a user’s function.

python.Exec.noSignature

Section titled “python.Exec.noSignature”

A signature for nothing (the table is never asked past its end).

python.Run.enter

Section titled “python.Run.enter”

Entering a function: its locals are the bound parameters and empty slots after them (or, resuming a generator, the locals it kept), one frame deeper unless the function is the model’s own (Function.internal).

python.Run.leave

Section titled “python.Run.leave”

Back in the caller: its locals and depth again, and the returned value (None when the body ended) stored; when a user’s class was called, the instance instead, TypeError (pending) when __init__ returned anything but None.

python.Run.unwound

Section titled “python.Run.unwound”

Back in the caller while an exception unwinds through the call.

python.Signal.unwinds

Section titled “python.Signal.unwinds”

Whether a signal passes through a call: an exception does.

python.Exec.callAt

Section titled “python.Exec.callAt”

The call of the function at position k of the table, its body built when the call is reached.

python.Exec.dispatch

Section titled “python.Exec.dispatch”

A source statement that may call a user’s function: the expression prepares the call (or finishes without one), then the function at the prepared position runs, its result into the place; the checks raise what is pending.

python.Exec.call

Section titled “python.Exec.call”

result = callee(*positional, **keywords) where the callee may be a user’s function or class: the callee and the arguments evaluated left to right, the parameters bound, then the function’s body run.

python.Run.access

Section titled “python.Run.access”

An attribute access as an evaluation: its value into the place, its exception, or the call of the getter or setter it needs (a user’s code).

python.Exec.getAttribute

Section titled “python.Exec.getAttribute”

result = object.name: a property’s getter runs as a call.

python.Exec.setAttribute

Section titled “python.Exec.setAttribute”

object.name = value (the value first, then the object, as CPython evaluates them): a property’s setter runs as a call, its result into the scratch place.

python.Exec.pairs

Section titled “python.Exec.pairs”

Names paired with values in order.

python.Expr.function

Section titled “python.Expr.function”

A function value made by def: its name with the cells it captures and its defaults evaluated now.

python.Unpack.valueError

Section titled “python.Unpack.valueError”

Unpacking failed with a ValueError (its message in parts).

python.Unpack.cannot

Section titled “python.Unpack.cannot”

An iterable’s exception while unpacking it: a TypeError says the value cannot be unpacked.

python.Unpack.taking

Section titled “python.Unpack.taking”

The values of an iterable for unpacking into a count of targets, taking one item at a time (an iterator gives at most one item more than the count, as CPython takes it): ValueError for too few, or for one too many.

python.Unpack.exactly

Section titled “python.Unpack.exactly”

a, b = v with a count of targets and no star (CPython’s unpack_iterable): a list or tuple by its length (the messages say how many it had), anything else one item at a time; TypeError for what cannot be iterated.

python.Unpack.split

Section titled “python.Unpack.split”

a, *b, c = v from all the items: before items, the rest as a new list, after items.

python.Unpack.starred

Section titled “python.Unpack.starred”

a, *b, c = v: before items, the rest as a new list, after items; ValueError when there are fewer than before and after together.

python.Exec.nextItem

Section titled “python.Exec.nextItem”

The next item of a for loop’s iterator into its slot, or the end marked in its flag.

python.Exec.forLoop

Section titled “python.Exec.forLoop”

for target in iterable: body else: otherwise: an iterator over the iterable into a slot, then each round the next item into a slot (the end marked in a flag, which else reads: a break leaves it unmarked), the target assigned from it, the body.

python.Expr.taken

Section titled “python.Expr.taken”

The items a Taken holds as a tuple (the targets are stored from it), or its exception.

python.Value.tupleItems

Section titled “python.Value.tupleItems”

A tuple’s items (none for anything else).

python.Run.storeAll

Section titled “python.Run.storeAll”

Values into places, in order.

python.Run.items

Section titled “python.Run.items”

The items of a tuple held in a place.

python.Run.itemAt

Section titled “python.Run.itemAt”

The k-th item of a tuple held in a place (None past the end).

python.Exec.unpack

Section titled “python.Exec.unpack”

a, b = source: the source’s items into the targets, as many as there are targets.

python.Exec.unpackStarred

Section titled “python.Exec.unpackStarred”

a, *rest, c = source: the first and last items into the targets before and after, the rest as a new list.
