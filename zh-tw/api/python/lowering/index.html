python.Context

Section titled “python.Context”

What the translation knows: each module name’s slot, the current function’s names and their places (none at the module level), the first temporary slot (a local slot in a function, a global one at the module level), the program’s symbol table, its functions and their bodies; in a class body, the names it binds and their places; which class each method’s node belongs to, and the class of the current method; in a comprehension run in place, its variables’ temporaries (they hide the names around it); the names import binds anywhere in the program (a module there is read only as module.member); whether the run notes the types it sees (Lowering.watching), and the node of the function being translated, whose own expressions in its body are not the program’s (a comprehension or generator expression made a function: its .0, .acc, append and yield at its node).

python.Lowering

Section titled “python.Lowering”

A translation step: from the context and the next free temporary, its result and the next free temporary, or the construct it cannot take.

python.Lowering.run

Section titled “python.Lowering.run”

Running a translation step.

python.Lowering.give

Section titled “python.Lowering.give”

A step that gives a value.

python.Lowering.then

Section titled “python.Lowering.then”

A step after another.

python.Lowering.fail

Section titled “python.Lowering.fail”

The translation stops: a construct it cannot take.

python.Lowering.context

Section titled “python.Lowering.context”

The context.

python.Lowering.within

Section titled “python.Lowering.within”

A translation step under a changed context (a class body’s names, for one).

python.Lowering.fresh

Section titled “python.Lowering.fresh”

A new temporary slot.

python.Lowering.each

Section titled “python.Lowering.each”

Steps in order, their results in a list.

python.Lowering.paired

Section titled “python.Lowering.paired”

Two lists paired item by item (as long as the shorter).

python.Lowered

Section titled “python.Lowered”

An expression’s translation: the statements to run first, and the expression reading its value.

python.Lowered.plain

Section titled “python.Lowered.plain”

A translation that needs nothing first.

python.Lowering.watching

Section titled “python.Lowering.watching”

The expression e, its value’s type noted at the node n when the context c observes types (not at the node of the function being translated).

python.Context.place

Section titled “python.Context.place”

The place of a module name.

python.Lowering.functionNames

Section titled “python.Lowering.functionNames”

The built-in functions a name refers to when the module does not bind it.

python.Lowering.classNames

Section titled “python.Lowering.classNames”

The built-in classes a name refers to when the module does not bind it (the exception classes too).

python.Lowering.unprovided

Section titled “python.Lowering.unprovided”

CPython’s built-in names the model does not provide yet: reading one stops the translation (it is unsupported, not a NameError).

python.Lowering.isBuiltin

Section titled “python.Lowering.isBuiltin”

Whether a name is built-in.

python.Lowering.builtin

Section titled “python.Lowering.builtin”

The value of a built-in name.

python.Lowering.builtinRead

Section titled “python.Lowering.builtinRead”

Reading a built-in name.

python.Lowering.mathFunctions

Section titled “python.Lowering.mathFunctions”

The math functions the model provides.

python.Lowering.mathConstants

Section titled “python.Lowering.mathConstants”

The math constants, as CPython’s repr writes them (the nearest binary64).

python.Lowering.randomFunctions

Section titled “python.Lowering.randomFunctions”

The random module’s functions the model provides (python.random).

python.Lowering.member

Section titled “python.Lowering.member”

A member of math or random: a function (the built-in function named by the module) or a constant.

python.Lowering.moduleValue

Section titled “python.Lowering.moduleValue”

A module bound by import (its class name starts with module , which no class has).

python.Lowering.moduleOf

Section titled “python.Lowering.moduleOf”

The module a value is, if it is one.

python.Lowering.holdsModule

Section titled “python.Lowering.holdsModule”

Whether the place holds a module.

python.Lowering.memberOf

Section titled “python.Lowering.memberOf”

module.attr for the module in a place: its member, or unsupported when the model does not have it.

python.Lowering.nameValue

Section titled “python.Lowering.nameValue”

A name’s value from its place: a module there is not taken as a value (only as module.member).

python.Lowering.importedPlace

Section titled “python.Lowering.importedPlace”

The place of a name import binds, when the expression is that name.

python.Lowering.moduleOr

Section titled “python.Lowering.moduleOr”

module.attr into result when the place (of a name import binds) holds a module, the general statement otherwise (the name was bound to something else); reading the name first (NameError before the import), through watch (Lowering.watching at the name’s node).

python.Lowering.undefined

Section titled “python.Lowering.undefined”

Raising NameError for the name no scope binds and no built-in provides, when it is read.

python.Lowering.name

Section titled “python.Lowering.name”

A name read: its slot, or the built-in it refers to (a CPython built-in the model does not provide stops the translation); a name neither binds raises NameError when it is read (only then: a branch not taken reads nothing).

python.Lowering.isPlainBuiltin

Section titled “python.Lowering.isPlainBuiltin”

Whether a name is read as the built-in (the module does not bind it).

python.Lowering.constant

Section titled “python.Lowering.constant”

A constant’s value.

python.Lowering.operator

Section titled “python.Lowering.operator”

An operator’s symbol, its method and its reflected method.

python.Lowering.arithmetic

Section titled “python.Lowering.arithmetic”

The built-in operation of an operator (the data layer’s).

python.Lowering.powersByLibrary

Section titled “python.Lowering.powersByLibrary”

Whether x ** y is computed by the platform’s math library: both are numbers and one is a float (ints are exact).

python.Lowering.formatsOperands

Section titled “python.Lowering.formatsOperands”

a op b on built-in values: printf-style formatting (str % b) shows b (its items) as text, noted by Run.shown (by repr, which %s of an object without a __str__ shows too); a float power is the math library’s (libm:math.correctlyRounded, as Builtins.inexactMath).

python.Lowering.binary

Section titled “python.Lowering.binary”

result = a op b with the operands in places.

python.Lowering.containing

Section titled “python.Lowering.containing”

a in b (Exec.containsBy: a list’s or tuple’s items compared with the user’s __eq__ when they define it).

python.Lowering.identical

Section titled “python.Lowering.identical”

x is y: the same object (an object or a user’s function), None, NotImplemented, a bool, a built-in class or function (each one object), a bound method not another value; unsupported for numbers and strings (their identity is the implementation’s) and two bound methods (CPython makes a new one each time it reads the attribute, which the model’s value does not keep).

python.Lowering.comparison

Section titled “python.Lowering.comparison”

result = a op b for one comparison, the operands in places.

python.Lowering.prompt

Section titled “python.Lowering.prompt”

The prompt of input(prompt) (the str at the place p, already made) written to standard output, its value kept: a step of its own before the read, so a debugger that waits for input there has shown the prompt (CPython writes it first).
