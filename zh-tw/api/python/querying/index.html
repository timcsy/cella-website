python.Querying.heap

Section titled “python.Querying.heap”

The heap the representative values are on: an empty list at 0, an empty dict at 1, an empty set at 2.

python.Querying.representative

Section titled “python.Querying.representative”

A value of the type t to try operations on (none for a type that has none).

python.Tried

Section titled “python.Tried”

What trying an operation gave: the result’s type, a TypeError’s message, or something else (an exception that depends on the values).

python.Querying.outcome

Section titled “python.Querying.outcome”

What the outcome o on the representatives’ heap h tried.

python.Querying.evaluated

Section titled “python.Querying.evaluated”

What the expression e on the representatives tried.

python.Querying.changed

Section titled “python.Querying.changed”

What the change of the heap c tried.

python.HolePlace

Section titled “python.HolePlace”

Where a hole is: an operand (the operation decides whether a type fits), a place any type fits, or elsewhere (it depends on values at run time).

python.Seen

Section titled “python.Seen”

What walking a scope knows: the names’ types it sees, the built-in names there, the holes’ assumed types, the module’s types and built-in names, the enclosing functions’ locals (free names inside, of unknown type), the names some function changes with nonlocal.

python.Findings

Section titled “python.Findings”

What walking finds: the nodes’ types, the type errors, the operations whose operands’ types are unknown, and the holes’ places (each list newest first).

python.Findings.empty

Section titled “python.Findings.empty”

Nothing found.

python.Findings.node

Section titled “python.Findings.node”

The findings a with the type t of the node n added, when it is known.

python.Findings.error

Section titled “python.Findings.error”

The findings a with a type error at the node n, with its message, added.

python.Findings.undecided

Section titled “python.Findings.undecided”

The findings a with the operation at the node n, whose operands’ types are not known, added.

python.Findings.hole

Section titled “python.Findings.hole”

The findings a with the place p of the hole labelled label added.

python.Querying.lookup

Section titled “python.Querying.lookup”

The type of the name x in the list of names’ types.

python.Querying.without

Section titled “python.Querying.without”

The names without those in xs.

python.Seen.forget

Section titled “python.Seen.forget”

The scope c without the names xs (they are its own, of unknown type).

python.Querying.builtinResults

Section titled “python.Querying.builtinResults”

The built-ins’ result types (whatever the arguments; a call that raises has no result).

python.Querying.same

Section titled “python.Querying.same”

The types x and y when they are the same.

python.Querying.both

Section titled “python.Querying.both”

The representatives of the types left and right, when both have one.

python.Querying.binary

Section titled “python.Querying.binary”

x op y (or x op= y when augmented) at the node n, with its operands’ types left and right, added to the findings a: str % x formats (whether it fails depends on the format); else the operation tried on representatives.

python.Querying.unary

Section titled “python.Querying.unary”

op x at the node n, with its operand’s type t, added to the findings a (not is always a bool).

python.Querying.comparison

Section titled “python.Querying.comparison”

One comparison x op y tried on representatives.

python.Querying.compare

Section titled “python.Querying.compare”

x < y < z at the node n, its operators ops and its operands’ types, added to the findings a (first while at the first pair): only the first pair is always compared (the rest may be cut short); the result is a bool when all of them can be compared.

python.Querying.constant

Section titled “python.Querying.constant”

The type of the constant v.

python.Querying.allSame

Section titled “python.Querying.allSame”

The type of all of some values, from their types ts, when they have the same.

python.Querying.builtin

Section titled “python.Querying.builtin”

Whether the callee f is the name x and, in the scope c, a built-in’s.

python.Querying.called

Section titled “python.Querying.called”

The type of a call of f in the scope c: a built-in’s result.

python.Querying.typed

Section titled “python.Querying.typed”

An expression at the node n whose type t is known, added to what walking found.

python.Querying.expression

Section titled “python.Querying.expression”

The type of the expression e in the scope c, with what walking it adds to the findings a (a hole directly here has the place p): names, constants, displays and comprehensions here, operations and the rest in Querying.compound.

python.Querying.compound

Section titled “python.Querying.compound”

The type of e, an operation, a call, a subscript, a dict, a lambda, a conditional or an assignment expression (c, p and a as for Querying.expression).

python.Querying.expressions

Section titled “python.Querying.expressions”

The types of the expressions es, in order (c, p and a as for Querying.expression).

python.Querying.optional

Section titled “python.Querying.optional”

The optional expression m walked in the scope c, added to the findings a.

python.Querying.optionals

Section titled “python.Querying.optionals”

The optional expressions ms walked in the scope c, added to the findings a.

python.Querying.keywords

Section titled “python.Querying.keywords”

The keyword arguments ks walked in the scope c, added to the findings a.

python.Querying.comprehension

Section titled “python.Querying.comprehension”

A comprehension of elt over the generators gs walked in the scope c, added to the findings a: its loop variables are its own (of unknown type); its first iterable is evaluated outside.

python.Querying.generators

Section titled “python.Querying.generators”

A comprehension’s fors and ifs, gs, walked in its inner scope, added to the findings a (the first iterable outside, in c).

python.Querying.defaults

Section titled “python.Querying.defaults”

The defaults of a function’s arguments walked in the scope c, added to the findings a.

python.Binding

Section titled “python.Binding”

A plain binding of a name: x = e (and x: T = e), or x op= e.

python.Querying.named

Section titled “python.Querying.named”

A plain binding of the value v to the target t, when it is a name.

python.Querying.plainIn

Section titled “python.Querying.plainIn”

The plain bindings of the block ss (not going into functions and classes).

python.Querying.plainOf

Section titled “python.Querying.plainOf”

The plain bindings of the statement st and its blocks’.

python.Querying.handlerPlain

Section titled “python.Querying.handlerPlain”

The plain bindings in the bodies of the handlers hs.

python.Querying.walrus

Section titled “python.Querying.walrus”

The names the expression e binds with :=.

python.Querying.walrusOf

Section titled “python.Querying.walrusOf”

The names the optional expression m binds with :=.

python.Querying.otherTargets

Section titled “python.Querying.otherTargets”

The names the target t binds when it is not a plain name (a.b, a[i], a, b).

python.Querying.otherIn

Section titled “python.Querying.otherIn”

The names the block ss binds otherwise than plainly (for, with, except, import, def, class, unpacking, :=): their types are not known.

python.Querying.otherOf

Section titled “python.Querying.otherOf”

The names the statement st binds otherwise than plainly, and its blocks’.

python.Querying.handlerOther

Section titled “python.Querying.handlerOther”

The names the handlers hs bind, and those their bodies bind otherwise than plainly.

python.Querying.withOther

Section titled “python.Querying.withOther”

The names with items bind.

python.Querying.argumentsBound

Section titled “python.Querying.argumentsBound”

The names a def’s decorators and the defaults of its arguments bind with :=.

python.Querying.bindingsOf

Section titled “python.Querying.bindingsOf”

The plain bindings of the name x among the block’s plain bindings.

python.Gives

Section titled “python.Gives”

What a binding gives: a known type, never a value (its outermost operation always raises TypeError), or not known.

python.Findings.errorAt

Section titled “python.Findings.errorAt”

Whether walking found, in the findings a, a type error at the node n.

python.Querying.gives

Section titled “python.Querying.gives”

What the binding b of the name x gives in the scope c.

python.Querying.seed

Section titled “python.Querying.seed”

The type the first plain assignment among the bindings bs of the name x that gives one gives in the scope c: the name’s candidate type.

python.Querying.keeps

Section titled “python.Querying.keeps”

Whether a binding that gives g keeps the type t.

python.Querying.candidate

Section titled “python.Querying.candidate”

The type of the name x when every binding of it among the block’s plain bindings keeps its candidate type (assuming the name has it, as x = x + 1 needs), in the scope c given the names known so far.

python.Querying.rounds

Section titled “python.Querying.rounds”

The types of the candidates known after fuel rounds from those known, by the block’s plain bindings in the scope c (knowing more names only makes more bindings known, so as many rounds as names reach the fixed point).

python.Querying.scopeTypes

Section titled “python.Querying.scopeTypes”

The types of the names the body of a scope binds, before those it sees from outside, the scope c; unknown are names whose type cannot be known (its parameters, names changed elsewhere).

python.Seen.function

Section titled “python.Seen.function”

The scope of a function with arguments and body, defined in the scope c: its own locals are known by its own bindings; a name that is not local is the enclosing function’s (free, of unknown type) or else the module’s.

python.Seen.classBody

Section titled “python.Seen.classBody”

The scope of a class body in the scope c: the names it binds are the class’s attributes (not followed); its functions see the module.

python.Seen.module

Section titled “python.Seen.module”

The scope of the module p (with the holes’ assumed types): a name some function declares global is not known.

python.Querying.target

Section titled “python.Querying.target”

The assignment target t walked in the scope c, added to the findings a (a name’s binding is not an expression; a.b and a[i] are).

python.Querying.targets

Section titled “python.Querying.targets”

The assignment targets ts walked in the scope c, added to the findings a.

python.Querying.block

Section titled “python.Querying.block”

The block ss walked in the scope c, added to the findings a.

python.Querying.statement

Section titled “python.Querying.statement”

The statement st walked in the scope c, added to the findings a (a function’s and a class’s bodies in their own).

python.Querying.handlers

Section titled “python.Querying.handlers”

The handlers hs walked in the scope c, added to the findings a.

python.Querying.items

Section titled “python.Querying.items”

The with items walked in the scope c, added to the findings a.

python.Querying.analyze

Section titled “python.Querying.analyze”

What walking the program p finds (the holes assumed of some types).

python.Fit

Section titled “python.Fit”

How a candidate type fits a hole.

python.Querying.newError

Section titled “python.Querying.newError”

The first of the type errors not already among those found without the hole’s type, base.

python.Querying.fit

Section titled “python.Querying.fit”

How the type t fits the hole labelled label at place in the program p (base what walking it finds without the hole’s type): no when it makes a type error; else exact when the operation the hole is an operand of can be decided (or any type fits there), unknown otherwise.

python.Fit.exact

Section titled “python.Fit.exact”

Whether the fit f is exact.

python.Fit.unknown

Section titled “python.Fit.unknown”

Whether the fit f is unknown.

python.Querying.commas

Section titled “python.Querying.commas”

The names xs joined with commas.

python.Querying.exactly

Section titled “python.Querying.exactly”

The candidate types that fit exactly, by their fits.

python.Querying.display

Section titled “python.Querying.display”

What a hole shows by how the candidate types fit it, fits: the one type it expects, the types it accepts, or why none is known.

python.Querying.expects

Section titled “python.Querying.expects”

The type a hole expects, when exactly one of the fits fits exactly.

python.Fit.json

Section titled “python.Fit.json”

The fit f as JSON.

python.Querying.slot

Section titled “python.Querying.slot”

The entry of the hole h (its label and place) in the program p, with what walking finds without it, base: what it shows, the type it expects, how each of the candidates fits.

python.Querying.candidates

Section titled “python.Querying.candidates”

The candidate types tried in a hole when none are given.

python.Querying.json

Section titled “python.Querying.json”

The types of the program p as JSON, trying the candidates in each hole: {nodes, slots, errors}.

python.Querying.types

Section titled “python.Querying.types”

The types of a program given as its syntax tree’s JSON, source, for the editor ({nodes, slots, errors}; see the module’s comment); candidates is a JSON list of the type names to try in each hole, empty for the default ones.

python.Observing.below

Section titled “python.Observing.below”

The node list xs without its first item when that is the node n (a callee’s own value is not in the table).

python.Observing.superReceiver

Section titled “python.Observing.superReceiver”

Whether the callee f is super().attr: the model looks the method up without making a super object, so super() there has no value in the table.

python.Observing.withoutTraceback

Section titled “python.Observing.withoutTraceback”

A function’s parameters a without the traceback one (the fourth positional) when it is __exit__ (name): the model gives it None, not the traceback CPython gives (Lowering.readsTraceback).

python.Observing.parameters

Section titled “python.Observing.parameters”

The nodes of the parameters xs.

python.Observing.parameter

Section titled “python.Observing.parameter”

The node of the parameter a, when there is one.

python.Observing.value

Section titled “python.Observing.value”

The nodes of the expression e in the table of observed types, in order: its own (its value), then those inside it. Not in the table: a callee’s own value (and super() in super().attr(...)), a slice, a starred item, a yield’s value, an f-string’s pieces (their values are), a comprehension’s targets, an editor’s empty slot.

python.Observing.values

Section titled “python.Observing.values”

The nodes of the expressions es, in order.

python.Observing.maybe

Section titled “python.Observing.maybe”

The nodes of the expression e, when there is one.

python.Observing.keys

Section titled “python.Observing.keys”

The nodes of a dict display’s keys ks (none for a ** item).

python.Observing.keywords

Section titled “python.Observing.keywords”

The nodes of the keyword arguments’ values, ks.

python.Observing.pieces

Section titled “python.Observing.pieces”

The nodes of an f-string’s formatted values among its pieces vs.

python.Observing.generators

Section titled “python.Observing.generators”

The nodes of the iterables and conditions of a comprehension’s fors gs (not its targets).

python.Observing.arguments

Section titled “python.Observing.arguments”

The nodes of a function’s parameters (the values bound to them) and of its default values.

python.Observing.target

Section titled “python.Observing.target”

The nodes of an assignment’s target t: a name (the values bound to it), and what an attribute’s or subscript’s target reads.

python.Observing.targets

Section titled “python.Observing.targets”

The nodes of the targets ts, in order.

python.Observing.deleted

Section titled “python.Observing.deleted”

The nodes of a del target t: what an attribute’s or subscript’s target reads.

python.Observing.deletedAll

Section titled “python.Observing.deletedAll”

The nodes of the del targets ts, in order.

python.Observing.statement

Section titled “python.Observing.statement”

The nodes of the statement s in the table of observed types (an annotation, an except clause’s class and the traceback parameter of __exit__ are not).

python.Observing.block

Section titled “python.Observing.block”

The nodes of the statements ss, in order.

python.Observing.handlers

Section titled “python.Observing.handlers”

The nodes of the bodies of the except clauses hs.

python.Observing.items

Section titled “python.Observing.items”

The nodes of with items: the context expression, then the as target.

The nodes of the program p in the table of observed types, in order.

python.Observing.ended

Section titled “python.Observing.ended”

The state the run c ended in, when it ended (finished, or left by an uncaught exception); none when it stopped or ran out of steps.

Section titled “python.Observing.verdict”

The verdict among a verdict’s fields (Lowering.fields).

python.Observing.json

Section titled “python.Observing.json”

The table of observed types as JSON: the verdict, then for each node of the table the union of the type texts seen there (nodes, empty when none) and whether it was seen (basis: observed or unreached).

python.Querying.observed

Section titled “python.Querying.observed”

The types a run of the program given as its syntax tree’s JSON, source, on the input for at most fuel steps observed, as JSON {verdict, nodes, basis}: each expression’s node (and each name an assignment binds, each parameter) with the union of the types its values had (int|str, in the order first seen; containers with the union of their items’ types, list[?] when empty: Value.typeText), observed; a node the run did not reach has the empty text, unreached. The types hold for this input only. A run that did not end (unknown: out of steps, a construct the model does not take) or a program that is not valid (invalid) gives no nodes.
