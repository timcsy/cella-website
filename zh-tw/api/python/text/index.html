Section titled “python.Text.isDigit”

Whether a code point is a decimal digit 0-9.

Section titled “python.Text.isUpper”

Whether a code point is an ASCII capital letter.

python.Text.isLower

Section titled “python.Text.isLower”

Whether a code point is an ASCII small letter.

python.Text.isCased

Section titled “python.Text.isCased”

Whether a code point is an ASCII letter (a letter with case).

python.Character

Section titled “python.Character”

What the model knows of a code point: a letter with case (an ASCII letter), a code point without case (whether it is a letter, a decimal digit, whitespace), or one past what the model classifies.

python.Text.caselessLetters

Section titled “python.Text.caselessLetters”

The letters without case the model knows (CPython’s str.isalpha): iteration marks, kana, bopomofo, CJK ideographs, Hangul syllables, halfwidth kana and Hangul.

python.Text.caselessBlocks

Section titled “python.Text.caselessBlocks”

The blocks whose other code points are known to be without case and neither letters, digits nor whitespace: general punctuation, CJK symbols, kana, bopomofo, halfwidth and fullwidth forms (but the fullwidth Latin letters, which have case).

python.Text.character

Section titled “python.Text.character”

What the model knows of a code point.

python.Text.classified

Section titled “python.Text.classified”

Whether the model knows the class of every code point of a text.

python.Text.asciiDigit

Section titled “python.Text.asciiDigit”

A code point as CPython reads numbers: a fullwidth digit as its ASCII digit, whitespace as a space.

python.Text.upper

Section titled “python.Text.upper”

A code point in capitals (ASCII only).

python.Text.lower

Section titled “python.Text.lower”

A code point in small letters (ASCII only).

python.Text.dropWhile

Section titled “python.Text.dropWhile”

The code points after the leading ones that p holds for.

python.Text.takeWhile

Section titled “python.Text.takeWhile”

The leading code points that p holds for.

python.Text.dropEnd

Section titled “python.Text.dropEnd”

The code points without the trailing ones that p holds for.

python.Text.strip

Section titled “python.Text.strip”

The code points without whitespace at either end (s.strip()).

python.Text.same

Section titled “python.Text.same”

Whether two texts are the same.

python.Text.wordsWithin

Section titled “python.Text.wordsWithin”

The words between whitespace (s.split(): runs of whitespace are one separator, none at either end), within fuel words.

python.Text.words

Section titled “python.Text.words”

The words between whitespace (s.split()).

python.Text.splitWithin

Section titled “python.Text.splitWithin”

The pieces between occurrences of a separator (not empty), the current piece so far, within fuel steps.

python.Text.split

Section titled “python.Text.split”

The pieces between occurrences of a separator (s.split(sep), sep not empty).

python.Text.usedUp

Section titled “python.Text.usedUp”

Whether a count of replacements is used up (none: no limit).

python.Text.oneLess

Section titled “python.Text.oneLess”

One replacement fewer left (none stays none).

python.Text.replaceWithin

Section titled “python.Text.replaceWithin”

s.replace(old, new, k) for an old text that is not empty, within fuel steps.

python.Text.replaceEmpty

Section titled “python.Text.replaceEmpty”

s.replace("", new, k): new before each code point and at the end, at most k times.

python.Text.replace

Section titled “python.Text.replace”

s.replace(old, new, k) (k none: every occurrence).

python.Text.countWithin

Section titled “python.Text.countWithin”

How many times a text not empty occurs without overlapping, within fuel steps.

python.Text.count

Section titled “python.Text.count”

s.count(part) for a part that is not empty.

python.Text.title

Section titled “python.Text.title”

s.title(): a letter with case in capitals after a code point without case, in small letters after one with case (whether the code point before had case).

python.Text.digits

Section titled “python.Text.digits”

Decimal digits with single underscores between digits as a natural (the value so far, whether the code point before was a digit); none for anything else, or nothing.

python.Text.digitsAfterUnderscore

Section titled “python.Text.digitsAfterUnderscore”

Digits after an underscore: a digit must come next.

python.Text.sign

Section titled “python.Text.sign”

A leading sign taken off: whether it was a minus, and the rest.

python.Text.signedInt

Section titled “python.Text.signedInt”

An int with a sign.

python.Text.toInt

Section titled “python.Text.toInt”

int(s) of decimal text: none when it is not one.

python.Text.exponent

Section titled “python.Text.exponent”

A decimal exponent’s text after e: a sign and digits.

python.Text.optionalDigits

Section titled “python.Text.optionalDigits”

Digits that may be absent: zero when there are none.

python.Text.decimal

Section titled “python.Text.decimal”

A decimal float’s text without its sign: digits, a fraction, an exponent (e or E), correctly rounded.

python.Text.toFloat

Section titled “python.Text.toFloat”

float(s): a decimal, or inf, infinity, nan in any case, with a sign; none when it is none of these.
