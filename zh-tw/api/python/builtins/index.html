python.Builtin

Section titled “python.Builtin”

What a built-in does with its arguments: the heap, the positional arguments, the keyword arguments.

python.Builtins.natural

Section titled “python.Builtins.natural”

An int of a natural value.

python.Builtins.floatResult

Section titled “python.Builtins.floatResult”

A float produced.

python.Builtins.floatOutcome

Section titled “python.Builtins.floatOutcome”

A float as an outcome.

python.Builtins.argument

Section titled “python.Builtins.argument”

The value of a positional argument (None when absent: the check before has made sure it is there).

python.Builtins.runsCode

Section titled “python.Builtins.runsCode”

What running a user’s method would need: unsupported here.

python.Builtins.definesAny

Section titled “python.Builtins.definesAny”

Whether a value is an instance whose class defines one of the methods.

python.Builtins.len

Section titled “python.Builtins.len”

len(x).

python.Builtins.abs

Section titled “python.Builtins.abs”

abs(x).

python.Builtins.round

Section titled “python.Builtins.round”

round(number, ndigits=None).

python.Builtins.divmod

Section titled “python.Builtins.divmod”

divmod(a, b): the floor quotient and the remainder.

python.Builtins.digitValue

Section titled “python.Builtins.digitValue”

The value of a digit in bases up to 36 (none for anything else).

python.Builtins.digitsIn

Section titled “python.Builtins.digitsIn”

Digits in a base with single underscores between them (an underscore may come first when a prefix came before): the value and how many digits; none for anything else.

python.Builtins.digitsAfterUnderscore

Section titled “python.Builtins.digitsAfterUnderscore”

Digits after an underscore: a digit must come next.

python.Builtins.prefixBase

Section titled “python.Builtins.prefixBase”

The base a prefix gives (0x, 0o, 0b in either case), if the text has one.

python.Builtins.powerOfTwo

Section titled “python.Builtins.powerOfTwo”

Whether a base is a power of two (its texts have no digit limit).

python.Builtins.allZeros

Section titled “python.Builtins.allZeros”

Whether decimal digits are all zeros (base 0 allows leading zeros only then).

python.Builtins.parseInt

Section titled “python.Builtins.parseInt”

int(text, base) (CPython’s PyLong_FromString): whitespace and a sign around, then a prefix that matches the base, then digits.

python.Builtins.toInt

Section titled “python.Builtins.toInt”

int(x) of a value without a base: a number truncated toward zero, a text in base 10.

python.Builtins.int

Section titled “python.Builtins.int”

int(x=0, /, base=10).

python.Builtins.float

Section titled “python.Builtins.float”

float(x=0.0).

python.Builtins.shown

Section titled “python.Builtins.shown”

str(x) or repr(x) of a value, checked for ints too long.

python.Builtins.str

Section titled “python.Builtins.str”

str(object=''), and str(object, encoding, errors) (bytes are not in the subset).

python.Builtins.repr

Section titled “python.Builtins.repr”

repr(x).

python.Builtins.truth

Section titled “python.Builtins.truth”

The truth of a value; none when it would run a user’s __bool__ or __len__.

python.Builtins.bool

Section titled “python.Builtins.bool”

bool(x=False).

python.Builtins.type

Section titled “python.Builtins.type”

type(x): its class (making a class with three arguments is not in the subset).

python.Builtins.format

Section titled “python.Builtins.format”

format(value, format_spec='').

python.Builtins.range

Section titled “python.Builtins.range”

range(stop), range(start, stop[, step]).

python.Builtins.items

Section titled “python.Builtins.items”

The items of an iterable argument, or the exception.

python.Builtins.collection

Section titled “python.Builtins.collection”

list(iterable=()), tuple(iterable=()), set(iterable=()).

python.Builtins.dict

Section titled “python.Builtins.dict”

dict(**kwargs), dict(mapping, **kwargs), dict(iterable, **kwargs): a new dict updated as dict.update.

python.Builtins.sorted

Section titled “python.Builtins.sorted”

sorted(iterable, /, *, key=None, reverse=False): a new list sorted as list.sort.

python.Builtins.floatSum

Section titled “python.Builtins.floatSum”

Neumaier’s compensated sum of floats (CPython’s builtin_sum_impl from 3.12): the sum so far, the compensation, the items left; an int that fits a C long is converted to a float first. The rest (the first item that is not a float or such an int) goes to the generic addition.

python.Builtins.compensated

Section titled “python.Builtins.compensated”

The compensation added in when it is finite and not zero.

python.Builtins.sumWithin

Section titled “python.Builtins.sumWithin”

Adding items to a sum in turn (fuel: the items left): a float sum is compensated.

python.Builtins.addThen

Section titled “python.Builtins.addThen”

Adding one item with +, then the rest.

python.Builtins.sum

Section titled “python.Builtins.sum”

sum(iterable, /, start=0): a str start is TypeError.

python.Builtins.extreme

Section titled “python.Builtins.extreme”

The first greatest (max) or least (min) of values.

python.Builtins.zipped

Section titled “python.Builtins.zipped”

Keys paired with items, in order (as long as the shorter).

python.Builtins.extremeBy

Section titled “python.Builtins.extremeBy”

The item of the greatest (max) or least key so far and the rest: the first such item, as CPython keeps the one it has unless a later key is strictly greater (or less).

python.Builtins.byKeys

Section titled “python.Builtins.byKeys”

sorted, min and max once a key function’s keys are known (the caller called it on each item, as CPython does before comparing): the items in the order of their keys (reversed as reverse says), or the item of the least or greatest key (the default, or ValueError, for none); keys whose comparison is a user’s code are not taken here.

python.Builtins.exceptionInit

Section titled “python.Builtins.exceptionInit”

An exception’s built-in __init__(self, *args) (a user’s exception class calling super().__init__): its args set (and a StopIteration’s value), None returned; keyword arguments are a TypeError.

python.Builtins.exceptionStr

Section titled “python.Builtins.exceptionStr”

An exception’s built-in __str__(self): ‘’ for no arguments, the str of the only one, else the str of the tuple; an argument whose str is a user’s code is not taken here.

python.Builtins.extremeOf

Section titled “python.Builtins.extremeOf”

max(iterable, *, key=None, default), max(a, b, *args, key=None), and min.

python.Builtins.decide

Section titled “python.Builtins.decide”

The truths of values in order, until one decides (any: a true one; all: a false one); none when a user’s code would run first.

python.Builtins.decideTaking

Section titled “python.Builtins.decideTaking”

any and all over an iterator: items taken one at a time until one decides (the rest stay in the iterator).

python.Builtins.anyAll

Section titled “python.Builtins.anyAll”

any(iterable), all(iterable).

python.Builtins.ord

Section titled “python.Builtins.ord”

ord(c).

python.Builtins.chr

Section titled “python.Builtins.chr”

chr(i).

python.Builtins.classTest

Section titled “python.Builtins.classTest”

isinstance(x, classes), issubclass(c, classes).

python.Builtins.wrapped

Section titled “python.Builtins.wrapped”

staticmethod(f), classmethod(f).

python.Builtins.property

Section titled “python.Builtins.property”

property(fget=None, fset=None, fdel=None, doc=None) (deleting through a property is not in the subset).

python.Builtins.propertyWith

Section titled “python.Builtins.propertyWith”

p.getter(f) and p.setter(f): a new property with the function as its getter or setter, the other kept (p.deleter is not in the subset, as deleting through a property is not).

python.Builtins.iter

Section titled “python.Builtins.iter”

iter(object) (with a sentinel it needs a callable: the user’s code, unsupported here).

python.Exec.builtinOf

Section titled “python.Exec.builtinOf”

Whether a value is a built-in function’s value.

python.Builtins.next

Section titled “python.Builtins.next”

next(iterator[, default]): StopIteration when it has run out and there is no default.

python.Builtins.enumerate

Section titled “python.Builtins.enumerate”

enumerate(iterable, start=0) (CPython’s own argument parsing: its own messages for keywords).

python.Builtins.iteratorsOf

Section titled “python.Builtins.iteratorsOf”

Iterators of iterables in turn, or the first exception.

python.Builtins.zip

Section titled “python.Builtins.zip”

zip(*iterables, strict=False).

python.Builtins.reversed

Section titled “python.Builtins.reversed”

reversed(seq): a list walked backward as it is, a tuple’s or a str’s items backward, a range backward (a dict, a dict’s view or a user’s sequence: unsupported here).

python.Builtins.named

Section titled “python.Builtins.named”

A built-in taking its own name first.

python.Builtins.functions

Section titled “python.Builtins.functions”

The built-in functions the model provides.

python.Builtins.real

Section titled “python.Builtins.real”

A real number argument of a math function as a float: TypeError for anything else, OverflowError for an int too large.

python.Builtins.sqrt

Section titled “python.Builtins.sqrt”

math.sqrt(x): ValueError for a negative x.

python.Builtins.fabs

Section titled “python.Builtins.fabs”

math.fabs(x).

python.Builtins.rounded

Section titled “python.Builtins.rounded”

math.floor(x), math.ceil(x): an int.

python.Builtins.mathPow

Section titled “python.Builtins.mathPow”

math.pow(x, y) (CPython’s math_pow_impl): a NaN from finite arguments, or zero to a negative power, is ValueError; an infinite result from finite arguments is OverflowError.

python.Builtins.gcdWithin

Section titled “python.Builtins.gcdWithin”

The greatest common divisor of two naturals, within fuel steps.

python.Builtins.gcdOf

Section titled “python.Builtins.gcdOf”

The greatest common divisor of two naturals.

python.Builtins.gcd

Section titled “python.Builtins.gcd”

math.gcd(*integers): zero for none.

python.Builtins.factorialOf

Section titled “python.Builtins.factorialOf”

n! within fuel steps.

python.Builtins.factorial

Section titled “python.Builtins.factorial”

math.factorial(n): ValueError for a negative n, OverflowError past a C long.

python.Builtins.math

Section titled “python.Builtins.math”

The math module’s functions the model provides.

python.Builtins.mathConstant

Section titled “python.Builtins.mathConstant”

The math module’s constants: the binary64 nearest to each (their shortest decimals read back to them).

python.Builtins.call

Section titled “python.Builtins.call”

Calling a built-in function or a math function by its name (math.sqrt); a name the model does not provide is unsupported.
