# cella-lang.org

The built website of [Cella](https://cella-lang.org/), a proof language that says what it checked.
This repository holds only the generated site that GitHub Pages serves; it is rebuilt and replaced on every release.

Cella 的官網（[cella-lang.org](https://cella-lang.org/)）的建置產物：這個 repo 只放 GitHub Pages 提供的網站，每次發布整個重建、取代。
