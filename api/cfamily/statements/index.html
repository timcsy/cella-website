statements

cfamily.StatementContext

Section titled “cfamily.StatementContext”

Where a statement is: the tables, the function’s result type (none is void), whether break (in a loop or switch) and continue (in a loop) are allowed, the labels in reach with the block each belongs to, and every label of the function (a goto to one out of reach is valid C the model does not run).

cfamily.StatementContext.loop

Section titled “cfamily.StatementContext.loop”

The context inside a loop: break and continue are allowed.

cfamily.StatementContext.switch

Section titled “cfamily.StatementContext.switch”

The context inside a switch: break is allowed.

cfamily.StatementChecker

Section titled “cfamily.StatementChecker”

The core’s statement checking functions, for a dialect checking its own statements.

cfamily.StatementExtension

Section titled “cfamily.StatementExtension”

How a dialect checks what the core does not know about statements. Each gives none to leave it to the core.

  • statement: its own statements;
  • declaration: declaring an object of its types (constructors, std::vector, a device on a board);
  • expressionStatement: an expression statement it handles (std::swap, a member call whose result is dropped);
  • condition: a condition of its types (a class’s operator bool);
  • endOfFullExpression: what ends with a full expression (C++’s temporaries; the statement itself otherwise);
  • returnValue: returning a value of its types (a return slot, a move);
  • declared: the variable one of its statements declares, with its type.

cfamily.StatementExtension.empty

Section titled “cfamily.StatementExtension.empty”

The statement extension of a dialect without statements of its own.

cfamily.StatementDialect

Section titled “cfamily.StatementDialect”

What checking statements needs of a dialect: what checking expressions needs, and its statement extension.

cfamily.LiftedInit

Section titled “cfamily.LiftedInit”

An initializer checked: the statements it needs first, the typed initializer, its accesses.

cfamily.LiftedInit.of

Section titled “cfamily.LiftedInit.of”

An initializer with its statements, writes and reads.

cfamily.TypedStmt.after

Section titled “cfamily.TypedStmt.after”

The statements before a statement, and the statement: one sequence (one stop), or the statement alone.

cfamily.TypedStmt.ofAll

Section titled “cfamily.TypedStmt.ofAll”

Statements in a statement’s place: one is itself, else a sequence.

cfamily.TypedStmt.alone

Section titled “cfamily.TypedStmt.alone”

A statement in a place of exactly one (a branch, a loop body): a sequence is wrapped in a block without a node, so its temporaries end each time it is left.

cfamily.Stmt.isFullExpression

Section titled “cfamily.Stmt.isFullExpression”

Whether a statement is a full expression (its temporaries end after it).

cfamily.Init.stringLength

Section titled “cfamily.Init.stringLength”

The length of the array a string literal is: its characters and the null.

cfamily.StatementDialect.declaredType

Section titled “cfamily.StatementDialect.declaredType”

The type of a declaration: an array of unknown length takes it from the initializer (a list’s length, a string’s with the null), C11 6.7.9p22.

cfamily.StatementDialect.declaredIn

Section titled “cfamily.StatementDialect.declaredIn”

The scope after a statement: what it declares added (a declaration, a variable length array, a label’s statement, the dialect’s).

cfamily.StatementDialect.concrete

Section titled “cfamily.StatementDialect.concrete”

A statement as the dialect makes it concrete before checking it (itself when the dialect does nothing).

cfamily.Stmt.concreteOr

Section titled “cfamily.Stmt.concreteOr”

The concrete statement when there is one, else the statement as written.

cfamily.StatementDialect.declaredInAll

Section titled “cfamily.StatementDialect.declaredInAll”

The scope after statements, in order.

cfamily.StatementContext.withLabels

Section titled “cfamily.StatementContext.withLabels”

The labels that are direct statements of a block, each with the block (goto may jump to them, C11 6.8.6.1).

cfamily.Init.character

Section titled “cfamily.Init.character”

A character of a string initializing an array element.

cfamily.StatementDialect.stringInit

Section titled “cfamily.StatementDialect.stringInit”

A string initializing a char array: each character, the null if there is room; too long is rejected, and by the rules C++ needs room for the null (C11 6.7.9p14, C++ [dcl.init.string]p2).

cfamily.StatementDialect.expressionInit

Section titled “cfamily.StatementDialect.expressionInit”

An expression initializing an object of type t: checked against t, converted as if by assignment.

cfamily.Init.repeated

Section titled “cfamily.Init.repeated”

The element type once per initializer.

cfamily.FieldTy.type

Section titled “cfamily.FieldTy.type”

The type of a member.

cfamily.Init.memberTypes

Section titled “cfamily.Init.memberTypes”

The types of the first members, one per initializer.

cfamily.LiftedInit.both

Section titled “cfamily.LiftedInit.both”

Two initializers unsequenced (the elements of a list, C11 6.7.9p23).

cfamily.CheckResult.isChecked

Section titled “cfamily.CheckResult.isChecked”

Whether a check succeeded.

cfamily.Expr.constantValue

Section titled “cfamily.Expr.constantValue”

The value of an integer constant expression (C11 6.6): literals, character constants, enumeration constants, and their negation, sum, difference and product.

cfamily.Ty.isAggregate

Section titled “cfamily.Ty.isAggregate”

Whether a type is an aggregate whose braces an initializer list may elide (an array, a struct or a union).

cfamily.Init.isList

Section titled “cfamily.Init.isList”

Whether an initializer is a brace-enclosed list.

cfamily.Init.isDesignated

Section titled “cfamily.Init.isDesignated”

Whether an initializer has a designator (.x = 1, [2] = 5).

cfamily.Init.isStringFor

Section titled “cfamily.Init.isStringFor”

Whether an initializer is a string literal for a character array (it initializes the array by itself).

cfamily.Ty.slots

Section titled “cfamily.Ty.slots”

The types of the subobjects an initializer list fills in order: an array’s elements, a struct’s named members (an unnamed bit-field takes none), a union’s first member.

cfamily.Init.regroup

Section titled “cfamily.Init.regroup”

An initializer list with the braces it elides put back (C11 6.7.9p20, [dcl.init.aggr]p15), for subobjects of the slots’ types in order: an initializer that is a list, a string for a character array, or an expression that initializes the subobject whole (a struct of its type) stays as it is; otherwise the subobject takes as many initializers from the list as it needs (Ty.elidedCount), as a list. Initializers past the slots stay as they are (too many). A list among the ones taken (braces inside an elided subobject) is not modeled.

cfamily.Designator.memberPlace

Section titled “cfamily.Designator.memberPlace”

The place among a struct’s named members of the one of a name.

cfamily.Designator.place

Section titled “cfamily.Designator.place”

The slot a designator names in an aggregate of a type (C11 6.7.9p6-7): a struct’s named member, or an array’s element by an index within its length; none when it names none.

cfamily.Init.cellsWith

Section titled “cfamily.Init.cellsWith”

The cells of an aggregate’s slots with one set: a whole initializer replaces the cell; one for a part of it (a longer designator path) is added to the cell’s list.

cfamily.Init.Filling

Section titled “cfamily.Init.Filling”

The slots filled so far while designators are put in place, and the next slot.

cfamily.Init.positioned

Section titled “cfamily.Init.positioned”

An initializer list with designators put in the positions of a type’s slots (C11 6.7.9p17-19): a designator moves to its slot, an initializer without one goes to the slot after the last; a slot set twice keeps the later; a slot left empty is zero (an empty list for an aggregate). An initializer without a designator that falls on an aggregate slot without its own braces (braces elided after a designator) is not modeled.

cfamily.Init.listLength

Section titled “cfamily.Init.listLength”

The length of an array an initializer list gives (C11 6.7.9p22): one past the last element it initializes, with designators.

cfamily.Init.bracingDepth

Section titled “cfamily.Init.bracingDepth”

The levels of nesting Init.braced goes down at most (a type nests its aggregates fewer times than that).

cfamily.StatementDialect.condition

Section titled “cfamily.StatementDialect.condition”

A condition: a scalar, the dialect’s conversion for its types first (C11 6.8.4.1p1, 6.8.5p2).

cfamily.Signature.droppedInto

Section titled “cfamily.Signature.droppedInto”

The temporary a dropped result still is: a structure’s or a class’s (whose end the dialect may run something for, a destructor, [class.temporary]p4), none for a scalar or no result.

cfamily.StatementDialect.callStatement

Section titled “cfamily.StatementDialect.callStatement”

The call of a function whose result is dropped (a statement): the arguments converted; a temporary only for a result of a structure or a class (it ends with the full expression).

cfamily.StatementDialect.releaseNull

Section titled “cfamily.StatementDialect.releaseNull”

free of a null pointer constant (it does nothing, C11 7.22.3.3p2).

cfamily.StatementDialect.freeStatement

Section titled “cfamily.StatementDialect.freeStatement”

free(p): p is a pointer (or a null pointer constant).

cfamily.StatementDialect.exitStatement

Section titled “cfamily.StatementDialect.exitStatement”

exit (C11 7.22.4.4): the run ends normally, the status its exit code; nothing after it runs. A status known when checking (a constant, EXIT_FAILURE) is supported; one computed while running is not yet.

cfamily.StatementDialect.abortStatement

Section titled “cfamily.StatementDialect.abortStatement”

abort (C11 7.22.4.1): the program ends abnormally, a termination the standard defines.

cfamily.StatementDialect.assertStatement

Section titled “cfamily.StatementDialect.assertStatement”

assert (C11 7.2.1.1, a macro of <assert.h>): when the condition is false the program aborts. Without the header the name is undeclared.

cfamily.CheckDialect.evaluatedStatement

Section titled “cfamily.CheckDialect.evaluatedStatement”

An expression statement’s expression evaluated and its value dropped.

cfamily.StatementDialect.expressionStatement

Section titled “cfamily.StatementDialect.expressionStatement”

An expression statement: the dialect’s first; calls drop their results (void functions included, by name or through a pointer, and a cast to void, C11 6.5.4p2); an assignment or an increment is its statements (postfix as prefix: the value is not used); else the value is evaluated for its undefined behavior.

cfamily.StatementDialect.returnStatement

Section titled “cfamily.StatementDialect.returnStatement”

return: with a value converted to the result type (the dialect’s for its types), without one in a void function.

cfamily.StatementDialect.declaration

Section titled “cfamily.StatementDialect.declaration”

A declaration: the dialect’s for objects of its types; an incomplete type is rejected; with an initializer, its statements first.

cfamily.StatementDialect.variableArray

Section titled “cfamily.StatementDialect.variableArray”

A variable length array (by the rules): the element type complete, the length an integer (as long). As an implementation’s extension, the run notes that it assumes it.

cfamily.TypedStmt.target

Section titled “cfamily.TypedStmt.target”

The variable a call’s result goes into, if any.

cfamily.TypedStmt.endingTemporaries

Section titled “cfamily.TypedStmt.endingTemporaries”

A full expression’s statement followed by the end of its temporaries, the last created first (C11 6.2.4p8).

cfamily.Lifted.settled

Section titled “cfamily.Lifted.settled”

A condition whose statements create temporaries: its value kept in a temporary named by the condition’s node (like a call’s result), then the temporaries end, before the branch is taken.

cfamily.Stmt.recovered

Section titled “cfamily.Stmt.recovered”

In the type query’s collect mode, a statement that does not check is recorded and checking goes on; otherwise the error stands.

cfamily.StatementChecker.fuel

Section titled “cfamily.StatementChecker.fuel”

The fuel for checking one function body: deeper nesting of statements is rejected.

cfamily.Stmt.check

Section titled “cfamily.Stmt.check”

Checks a statement in a context and scope.

cfamily.Stmt.checkAll

Section titled “cfamily.Stmt.checkAll”

Checks the statements of a block in a context and scope.

cfamily.StatementChecker.of

Section titled “cfamily.StatementChecker.of”

The core’s statement checker, for a dialect.
