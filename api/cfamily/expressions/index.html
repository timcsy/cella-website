cfamily.Env

Section titled “cfamily.Env”

The local variables in scope: each declaration with its type, the innermost first.

cfamily.Statements

Section titled “cfamily.Statements”

The statements a check makes, in order.

cfamily.Env.lookup

Section titled “cfamily.Env.lookup”

The type of a variable in scope, if it is.

cfamily.Checker

Section titled “cfamily.Checker”

The core’s checking functions, for a dialect checking its own syntax: an expression, an lvalue, expressions unsequenced with one another, and an expression against an expected type (malloc’s result takes its type from it).

cfamily.ExpressionExtension

Section titled “cfamily.ExpressionExtension”

How a dialect checks what the core does not know. Each gives none to leave it to the core.

  • expression, lvalue: its own syntax (C++’s member calls, new, iostream), with the core’s checker;
  • call: a function it adds by name (std::max, Arduino’s digitalWrite), before the program’s and the C library’s;
  • unary, binary, assign: operators whose checked operands are of its types (C++’s std::string +, a class’s operators and operator=);
  • index, member: subscripts and members of its types (a std::vector, a class with access control and bases);
  • variableUse: the expression a variable of its type designates (a reference designates what it refers to);
  • callResult: the expression a call’s result is, for its types (a function returning a reference);
  • memberUse: the expression a member of its types designates (a member of reference type, what it refers to);
  • isLvalue: which of its expressions are lvalues;
  • against: an expression checked against an expected type it gives meaning to (C++’s overloaded function name, whose function is the one of the target’s type, [over.over]);
  • mismatch: what a call of the program’s function (by name) whose arguments do not match its parameters (too few, too many, one that does not convert) is rejected with, instead of the core’s reason (C++’s overload resolution finds no viable function, even with one candidate).

cfamily.ExpressionExtension.empty

Section titled “cfamily.ExpressionExtension.empty”

The extension of a dialect without constructs of its own.

cfamily.CheckDialect

Section titled “cfamily.CheckDialect”

What checking expressions needs of a dialect: its name (in rejections), the target, the rules, the C library, and the extensions of types, conversions, effects and expressions.

cfamily.CheckDialect.platform

Section titled “cfamily.CheckDialect.platform”

The platform of a dialect’s target.

cfamily.Ty.visibleMembers

Section titled “cfamily.Ty.visibleMembers”

The visible members of a type (not a base’s or the dynamic type’s parts, named with #).

cfamily.CheckDialect.notPart

Section titled “cfamily.CheckDialect.notPart”

A rejection: the construct is not part of the dialect.

cfamily.Rules.undeclaredLibraryName

Section titled “cfamily.Rules.undeclaredLibraryName”

A name a standard header declares, used without including that header: undeclared, unless the dialect’s headers may include the others and the program includes some (then whether it is declared depends on the library).

cfamily.TypeSyntax.hiddenLibraryType

Section titled “cfamily.TypeSyntax.hiddenLibraryType”

The type a standard header names that a written type uses without the program including the header, if any.

cfamily.CheckDialect.resolve

Section titled “cfamily.CheckDialect.resolve”

A written type resolved and completed, or rejected at the node.

cfamily.CheckDialect.complete

Section titled “cfamily.CheckDialect.complete”

A type completed.

cfamily.CheckDialect.rvalue

Section titled “cfamily.CheckDialect.rvalue”

The value of a typed expression (arrays decay).

cfamily.CheckDialect.typeOf

Section titled “cfamily.CheckDialect.typeOf”

The type of a typed expression.

cfamily.CheckDialect.int

Section titled “cfamily.CheckDialect.int”

The int type of the dialect’s target.

cfamily.CheckDialect.readsOf

Section titled “cfamily.CheckDialect.readsOf”

The reads of an lvalue’s value.

cfamily.Ty.hasIncomplete

Section titled “cfamily.Ty.hasIncomplete”

Whether a type has an incomplete part (not behind a pointer): a struct known only by name, void, an array of unknown length.

cfamily.Ty.anyIncomplete

Section titled “cfamily.Ty.anyIncomplete”

Whether a member has an incomplete type.

cfamily.Ty.memberNamed

Section titled “cfamily.Ty.memberNamed”

The member named f of a struct or union type: its position and type.

cfamily.Ty.members

Section titled “cfamily.Ty.members”

The members of a struct or union type, if it is one.

cfamily.Ty.functionPointer

Section titled “cfamily.Ty.functionPointer”

The parameter and result types of a function pointer type, if it is one.

cfamily.TypedStmt.storing

Section titled “cfamily.TypedStmt.storing”

The value stored by an assignment of v to the lvalue lv.

cfamily.Lifted.writable

Section titled “cfamily.Lifted.writable”

A rejection unless the lvalue may be written: a const object cannot (C11 6.5.16p2).

cfamily.Effects.writeAccesses

Section titled “cfamily.Effects.writeAccesses”

The accesses a call makes: the callee’s effects, as input or output, the globals it touches, memory elsewhere.

cfamily.Effects.readAccesses

Section titled “cfamily.Effects.readAccesses”

The reads a call makes.

cfamily.CheckDialect.receiverAccesses

Section titled “cfamily.CheckDialect.receiverAccesses”

The accesses a call makes to its receiver, the object whose address is its first argument: a variable’s, else memory elsewhere.

cfamily.CheckDialect.calleeEffects

Section titled “cfamily.CheckDialect.calleeEffects”

The effects of calling the function named f: the program’s summary, or the library’s.

cfamily.Lifted.withExpr

Section titled “cfamily.Lifted.withExpr”

The lifted expression with another expression, its statements and accesses kept.

cfamily.Lifted.reading

Section titled “cfamily.Lifted.reading”

An expression that needs nothing first and makes the reads.

cfamily.CheckDialect.pure

Section titled “cfamily.CheckDialect.pure”

A literal or other expression that needs nothing first.

cfamily.CheckDialect.libraryConstant

Section titled “cfamily.CheckDialect.libraryConstant”

A macro constant of the standard headers (eConst), when the program includes a header that declares it; otherwise the name is undeclared (C11 6.5.1p2: an identifier is a primary expression only if declared).

cfamily.Rules.libraryConstant

Section titled “cfamily.Rules.libraryConstant”

A macro constant under a dialect’s rules: its value when the program includes a header that declares it.

cfamily.CheckDialect.integerLiteral

Section titled “cfamily.CheckDialect.integerLiteral”

A decimal integer constant: int, long or long long, the first that holds it.

cfamily.CheckDialect.writtenInteger

Section titled “cfamily.CheckDialect.writtenInteger”

An integer constant written with a suffix or not in decimal: its type by C11 6.4.4.1p5.

cfamily.CheckDialect.floatLiteral

Section titled “cfamily.CheckDialect.floatLiteral”

A floating constant as written: float with the f suffix, else double.

cfamily.CheckDialect.stringOf

Section titled “cfamily.CheckDialect.stringOf”

A string literal: an array of char (const char by the rules) with room for the null.

cfamily.CheckDialect.wideStringOf

Section titled “cfamily.CheckDialect.wideStringOf”

A wide string literal: an array of wchar_t (int on LP64), one element per code point and the null.

cfamily.CheckDialect.characterLiteral

Section titled “cfamily.CheckDialect.characterLiteral”

A character constant: of type char or int by the rules.

cfamily.CheckDialect.booleanLiteral

Section titled “cfamily.CheckDialect.booleanLiteral”

true or false: of type bool or int by the rules.

cfamily.CheckDialect.variableExpr

Section titled “cfamily.CheckDialect.variableExpr”

The expression a variable designates: the dialect’s (a reference), or the variable itself.

cfamily.CheckDialect.variableLvalue

Section titled “cfamily.CheckDialect.variableLvalue”

A variable used as an lvalue: a local or global in scope; an enumeration constant is not an lvalue.

cfamily.CheckDialect.variableValue

Section titled “cfamily.CheckDialect.variableValue”

A variable’s value: a variable in scope (read), or an enumeration constant (an int constant, C11 6.4.4.3p2).

cfamily.CheckDialect.hole

Section titled “cfamily.CheckDialect.hole”

A hole of the type query: a value of the type it stands for; outside the query an empty slot.

cfamily.CheckDialect.unary

Section titled “cfamily.CheckDialect.unary”

A unary operator on a checked operand: the dialect’s for its types, else the core’s.

cfamily.CheckDialect.shortCircuit

Section titled “cfamily.CheckDialect.shortCircuit”

&& and || whose right side needs statements first: the right side runs only when needed, its value in a temporary named for the node (C11 6.5.13p4, 6.5.14p4).

cfamily.CheckDialect.binary

Section titled “cfamily.CheckDialect.binary”

A binary operator on checked operands: the dialect’s for its types; && and || short-circuit; else both operands unsequenced (C11 6.5p2) and the core’s typing.

cfamily.CheckDialect.assignLifted

Section titled “cfamily.CheckDialect.assignLifted”

e converted to t as if by assignment: the dialect’s own conversions first (with the statements they need first, a temporary a const reference binds to), else the core’s.

cfamily.CheckDialect.assignTo

Section titled “cfamily.CheckDialect.assignTo”

e converted to t as if by assignment where nothing can run first (an assignment’s value, a conditional’s operands): a conversion that needs a temporary is rejected.

cfamily.CheckDialect.assignedValue

Section titled “cfamily.CheckDialect.assignedValue”

The value an assignment stores: e converted to the lvalue’s type; for op=, lv op e converted back.

cfamily.CheckDialect.assignment

Section titled “cfamily.CheckDialect.assignment”

An assignment of a checked right side to a checked lvalue: the dialect’s for its types (operator=), else the value stored after both sides; the value of the expression is the lvalue (C11 6.5.16p3). Where the right side goes first (C++17), it does, its value kept in a temporary when the left side has statements of its own.

cfamily.CheckDialect.increment

Section titled “cfamily.CheckDialect.increment”

++ or – on a checked lvalue: prefix gives the lvalue after the change, postfix the value before it (kept in a temporary named for the node).

cfamily.CheckDialect.incremented

Section titled “cfamily.CheckDialect.incremented”

++ or – of an lvalue whose type may be incremented.

cfamily.CheckDialect.indirection

Section titled “cfamily.CheckDialect.indirection”

The lvalue *p from a checked pointer: the pointed-to type must be complete.

cfamily.CheckDialect.subscript

Section titled “cfamily.CheckDialect.subscript”

The lvalue a[i] (= *(a + i), C11 6.5.2.1p2) from checked operands: the dialect’s for its types, else a pointer and an integer, unsequenced.

cfamily.CheckDialect.memberOf

Section titled “cfamily.CheckDialect.memberOf”

The member f of a checked lvalue of struct or union type: the dialect’s for its types, else by name.

cfamily.CheckDialect.bindingPart

Section titled “cfamily.CheckDialect.bindingPart”

A structured binding’s k-th part of an object with count names: the k-th element of an array, the k-th visible member of a struct or class; a different number of parts than names is an error ([dcl.struct.bind]p3, p5).

cfamily.CheckDialect.reading

Section titled “cfamily.CheckDialect.reading”

A value with its reads added.

cfamily.CheckDialect.sizeOfType

Section titled “cfamily.CheckDialect.sizeOfType”

sizeof a type: the size by the dialect’s layout, as size_t; an incomplete type has none.

cfamily.CheckDialect.sizeOfExpr

Section titled “cfamily.CheckDialect.sizeOfExpr”

sizeof an expression (not evaluated): a variable length array’s size at run time, else its type’s.

cfamily.CheckDialect.conditionalOf

Section titled “cfamily.CheckDialect.conditionalOf”

c ? a : b from checked operands: the type by C11 6.5.15; without effects in a or b the lazy conditional, else a temporary named for the node assigned in a branch (only one side runs).

cfamily.CheckDialect.evaluating

Section titled “cfamily.CheckDialect.evaluating”

Evaluating an expression’s value only for its undefined behavior.

cfamily.CheckDialect.afterDropped

Section titled “cfamily.CheckDialect.afterDropped”

a, b with a’s statements already made (its effects, Expr.droppedWithin): a sequence point, then b (C11 6.5.17: not an lvalue; C++ [expr.comma]p1: an lvalue when b is, by the rules).

cfamily.CheckDialect.convertAll

Section titled “cfamily.CheckDialect.convertAll”

Arguments converted to the parameters’ types as if by assignment, with the statements the conversions need first (after the arguments’). Each is converted at its own node: a temporary a const reference binds to is named for the node, so two arguments bound that way (std::min(2, 5)) need two.

cfamily.CheckDialect.convertValues

Section titled “cfamily.CheckDialect.convertValues”

Arguments converted where nothing can run first (a library function’s parameters are C’s types).

cfamily.CheckDialect.defaults

Section titled “cfamily.CheckDialect.defaults”

The arguments for defaulted parameters (all must have defaults): their statements and values.

cfamily.CheckDialect.resultOf

Section titled “cfamily.CheckDialect.resultOf”

The expression a call’s result is: the dialect’s for its types, else the temporary named for the node.

cfamily.CheckDialect.printArguments

Section titled “cfamily.CheckDialect.printArguments”

The arguments of printf and sprintf after the default argument promotions (C11 6.5.2.2p6): integers promoted, floating values as double; strings as pointers; other pointers are not supported.

cfamily.CheckDialect.printArgument

Section titled “cfamily.CheckDialect.printArgument”

One argument of printf after the default argument promotions.

cfamily.CheckDialect.scanTargets

Section titled “cfamily.CheckDialect.scanTargets”

The targets of scanf and sscanf: pointers to integers or floating objects.

cfamily.CheckDialect.callConverted

Section titled “cfamily.CheckDialect.callConverted”

A call with checked arguments already converted: the call into a temporary named for the node (the result’s type, declared in the caller’s scope), and the callee’s effects as accesses.

cfamily.CheckDialect.variadicArguments

Section titled “cfamily.CheckDialect.variadicArguments”

The arguments of a library function that takes more after its parameters: the parameters’ converted, the rest as printf’s arguments or scanf’s targets.

cfamily.CheckDialect.libraryArguments

Section titled “cfamily.CheckDialect.libraryArguments”

The arguments of a library function converted: to its parameters’ types, and any after them as it takes them.

cfamily.CheckDialect.sizeArgument

Section titled “cfamily.CheckDialect.sizeArgument”

A size argument as size_t.

cfamily.CheckDialect.allocationSize

Section titled “cfamily.CheckDialect.allocationSize”

The bytes malloc (one argument) or calloc (two, multiplied) allocates.

cfamily.CheckDialect.reallocated

Section titled “cfamily.CheckDialect.reallocated”

realloc’s first argument: a pointer to the element type, or a null pointer constant (realloc(NULL, n) is malloc).

cfamily.CheckDialect.reallocation

Section titled “cfamily.CheckDialect.reallocation”

realloc(old, size) into a pointer to the element: the pointer in a temporary named for the node.

cfamily.CheckDialect.allocation
