cfamily.FitLevel.toFloat

Section titled “cfamily.FitLevel.toFloat”

cfamily.FitLevel.ofExpression

Section titled “cfamily.FitLevel.ofExpression”

The level one expression with the hole’s node gives: the hole itself is exact; a conversion around it (the checker gives a conversion its operand’s node) is as lossy as it is; its address and what that address designates are exact (how C++ binds a reference to it and reads it through the reference: the identity conversion, [over.ics.ref]p1; the object itself has the node too and gives its own level).
