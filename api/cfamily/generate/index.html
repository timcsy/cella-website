A printed line: its text and the nodes printed on it.

Section titled “cfamily.PrintedLine.of”

A line with its nodes.

cfamily.PrintedLine.plain

Section titled “cfamily.PrintedLine.plain”

A line with no nodes.

cfamily.Names

Section titled “cfamily.Names”

Declaration nodes to source names.

cfamily.Names.of

Section titled “cfamily.Names.of”

The source name of a declaration (its node when it has none).

cfamily.Print.indent

Section titled “cfamily.Print.indent”

k levels of indentation, two spaces each.

cfamily.Print.namedEscape

Section titled “cfamily.Print.namedEscape”

The escape a control character has a name for (C11 6.4.4.4: a, b, t, n, v, f and r after a backslash), if it has one.

cfamily.Print.octalEscape

Section titled “cfamily.Print.octalEscape”

A code as a three-digit octal escape (three digits, so a digit after it is not read as part of it).

cfamily.Print.escapeCode

Section titled “cfamily.Print.escapeCode”

A character escaped for a quote: a control character by its name or in octal, backslash and the quote itself.

cfamily.Print.escapeString

Section titled “cfamily.Print.escapeString”

A string’s contents as in a C string literal.

cfamily.Print.escapeCharacter

Section titled “cfamily.Print.escapeCharacter”

A character constant’s contents (‘\0’ for the null).

cfamily.Print.commas

Section titled “cfamily.Print.commas”

Texts separated by commas.

cfamily.Print.isEmpty

Section titled “cfamily.Print.isEmpty”

Whether a string is empty.

cfamily.Print.hexDigits

Section titled “cfamily.Print.hexDigits”

The hexadecimal digits of a number put before acc (fuel bounds the digits).

cfamily.Print.hexLiteral

Section titled “cfamily.Print.hexLiteral”

An integer constant written in hexadecimal (an octal one has the same type, C11 6.4.4.1p5).

cfamily.UnaryOp.symbol

Section titled “cfamily.UnaryOp.symbol”

A unary operator as written.

cfamily.BinaryOp.symbol

Section titled “cfamily.BinaryOp.symbol”

A binary operator as written.

cfamily.Manipulator.name

Section titled “cfamily.Manipulator.name”

A stream manipulator’s name after std::.

cfamily.Param.text

Section titled “cfamily.Param.text”

A parameter as declared in a definition: int a[3].

cfamily.Param.list

Section titled “cfamily.Param.list”

A parameter list: void for none.

cfamily.Param.names

Section titled “cfamily.Param.names”

The parameters’ names.

cfamily.Capture.text

Section titled “cfamily.Capture.text”

A lambda’s capture as written.

cfamily.Expr.lambdaText

Section titled “cfamily.Expr.lambdaText”

A lambda on one line: its captures, parameters, mutable, result type, and its body’s lines (printed) joined.

cfamily.Print.lambdaKey

Section titled “cfamily.Print.lambdaKey”

The key a lambda’s text is kept under in the names (its sLambda declares it for the statements after it).

cfamily.Expr.printTop

Section titled “cfamily.Expr.printTop”

An expression at the top (a statement or a for step): no outer parentheses.

cfamily.Expr.nodesOption

Section titled “cfamily.Expr.nodesOption”

The nodes of an optional expression.

cfamily.Init.nodesOption

Section titled “cfamily.Init.nodesOption”

The nodes of an optional initializer.

cfamily.Print.declaration

Section titled “cfamily.Print.declaration”

A declaration without its semicolon: int a[3] = {1, 2, 3}.

cfamily.Print.closing

Section titled “cfamily.Print.closing”

A closing brace at k levels.

cfamily.PrintedLine.at

Section titled “cfamily.PrintedLine.at”

A line at k levels of indentation.

cfamily.Print.braced

Section titled “cfamily.Print.braced”

A head line, the lines inside, and the closing brace at k levels.

cfamily.Field.declarator

Section titled “cfamily.Field.declarator”

A member as declared: its type around the name, and a bit-field’s width after it.

cfamily.StructDefinition.lines

Section titled “cfamily.StructDefinition.lines”

A struct’s or union’s definition at k levels of indentation.

cfamily.Enumerator.names

Section titled “cfamily.Enumerator.names”

The enumerators’ names.

cfamily.Enumerator.textOf

Section titled “cfamily.Enumerator.textOf”

An enumerator: a, or b = 2.

cfamily.Enumerator.text

Section titled “cfamily.Enumerator.text”

The enumerators separated by commas.

cfamily.Enumerator.nodes

Section titled “cfamily.Enumerator.nodes”

The nodes of the enumerators’ values.

cfamily.TypeDefinition.lines

Section titled “cfamily.TypeDefinition.lines”

A type defined in a block, at k levels of indentation (an enum’s values with its enumerators in scope).

cfamily.Binder.printAll

Section titled “cfamily.Binder.printAll”

A structured binding’s names as written: [a, b].

cfamily.Binder.names

Section titled “cfamily.Binder.names”

A structured binding’s names, each its label and name.

cfamily.Stmt.namesAfter

Section titled “cfamily.Stmt.namesAfter”

The names a statement brings into scope for the statements after it.

cfamily.Stmt.namesAfterAll

Section titled “cfamily.Stmt.namesAfterAll”

The names after statements in order.

cfamily.Stmt.namesAfterOption

Section titled “cfamily.Stmt.namesAfterOption”

The names after an optional statement (a for’s init).

cfamily.Stmt.forInit

Section titled “cfamily.Stmt.forInit”

A for’s init on its line: a declaration or an expression, without the semicolon.

cfamily.Stmt.forInitNodes

Section titled “cfamily.Stmt.forInitNodes”

The nodes of a for’s init.

cfamily.Expr.printOption

Section titled “cfamily.Expr.printOption”

An optional expression’s text, empty when absent.

cfamily.Stmt.printSimple

Section titled “cfamily.Stmt.printSimple”

A statement with no statements inside it, on one line (the lowering’s copies print nothing).

cfamily.Print.member

Section titled “cfamily.Print.member”

A member of the object a member function runs on, named as it is written: alone, or after this-> where a local or a parameter of the same name hides it.

cfamily.Stmt.braceNodes

Section titled “cfamily.Stmt.braceNodes”

The node of a block whose braces a construct prints as its own (recorded on the construct’s line).

cfamily.Param.declared

Section titled “cfamily.Param.declared”

A parameter as declared in a prototype or a class: with its default value (the names in scope, the globals’).

cfamily.FunctionDefinition.isConversion

Section titled “cfamily.FunctionDefinition.isConversion”

A conversion function (operator T) has no result type written.

cfamily.FunctionDefinition.conversionName

Section titled “cfamily.FunctionDefinition.conversionName”

A conversion function’s name as declared: its class’s part, then operator and the type as written (a pointer to member (spelled with ::*) by its typedef, operator Helper: the type’s own spelling is not a declarator there, [class.conv.fct]p1).

cfamily.FunctionDefinition.head

Section titled “cfamily.FunctionDefinition.head”

A function’s head: the result type, name and parameters, with the defaults or without.

cfamily.Print.noexcept

Section titled “cfamily.Print.noexcept”

“ noexcept” when a constructor or function is.

cfamily.FunctionDefinition.noexcept

Section titled “cfamily.FunctionDefinition.noexcept”

“ noexcept” when the function is.

cfamily.FunctionDefinition.renamed

Section titled “cfamily.FunctionDefinition.renamed”

The function with another name.

cfamily.Print.prototypes

Section titled “cfamily.Print.prototypes”

Prototypes of the functions other than main, so they may call each other in any order; a function in early has had its defaults written already and is declared without them (a default is given once, C++ [dcl.fct.default]p4).

cfamily.Print.functionWith

Section titled “cfamily.Print.functionWith”

A function’s definition: its head and its body, with the parameters in scope; the default arguments written when it is the only declaration (a function template has no prototype before it, so without them its defaults were lost).

cfamily.Print.function

Section titled “cfamily.Print.function”

A function’s definition after its prototype (which has the default arguments).

cfamily.Print.isIdentifierCode

Section titled “cfamily.Print.isIdentifierCode”

Whether a character can be part of an identifier.

cfamily.Print.wordAt

Section titled “cfamily.Print.wordAt”

Whether a word starts the characters and ends there as an identifier.

cfamily.Print.hasWordIn

Section titled “cfamily.Print.hasWordIn”

Whether one of the words occurs as a whole identifier in the characters.

cfamily.Print.hasWord

Section titled “cfamily.Print.hasWord”

Whether one of the words occurs as a whole identifier in a text.

cfamily.Print.named

Section titled “cfamily.Print.named”

The functions whose names occur in a text.

cfamily.Member.defaults

Section titled “cfamily.Member.defaults”

The expressions in a class that may call functions: members’ defaults and parameters’ defaults.

cfamily.ClassDefinition.defaultsText

Section titled “cfamily.ClassDefinition.defaultsText”

A class’s defaults as text, to find the functions they call.

cfamily.Item.early

Section titled “cfamily.Item.early”

The functions whose prototypes are printed early with their defaults: those a global’s initializer or a class’s defaults call (C++ dynamic initialization).

cfamily.TemplateParam.name

Section titled “cfamily.TemplateParam.name”

A template parameter’s name.

cfamily.TemplateParam.text

Section titled “cfamily.TemplateParam.text”

Template parameters: typename T = int, int N; the defaults only in the first declaration.

cfamily.TemplateParam.header

Section titled “cfamily.TemplateParam.header”

The template header: template .

Section titled “cfamily.Access.word”

An access as written.

cfamily.Access.same

Section titled “cfamily.Access.same”

Whether two accesses are the same.

cfamily.Access.label

Section titled “cfamily.Access.label”

An access label when the access changes.

cfamily.Base.textOf

Section titled “cfamily.Base.textOf”

A base: virtual public A.

cfamily.Base.text

Section titled “cfamily.Base.text”

The bases: “ : public A, virtual private B”.

cfamily.Virtuality.before

Section titled “cfamily.Virtuality.before”

virtual before a method’s declaration.

cfamily.Virtuality.after

Section titled “cfamily.Virtuality.after”

override or = 0 after a method’s declaration.

cfamily.Member.enumeratorNames

Section titled “cfamily.Member.enumeratorNames”

The enumerators the members define, those of nested classes too.

cfamily.Member.qualifiedEnumeratorNames

Section titled “cfamily.Member.qualifiedEnumeratorNames”

The enumerators a class’s members define (those of nested classes too), qualified by the class (C::E, which names the enumerator anywhere: outside the class the bare name is not in scope).

cfamily.Member.staticNames

Section titled “cfamily.Member.staticNames”

The names of a class’s static data members, qualified by the class (C::n, which names the member anywhere).

cfamily.Member.lines

Section titled “cfamily.Member.lines”

The members declared in a class (access labels only where the access changes); x is the class’s name.

cfamily.ClassDefinition.lines

Section titled “cfamily.ClassDefinition.lines”

A class’s definition with its members’ declarations; the members’ definitions are printed after it.

cfamily.ClassDefinition.instance

Section titled “cfamily.ClassDefinition.instance”

The class named as an instance: class C.

cfamily.MemberInit.textOf

Section titled “cfamily.MemberInit.textOf”

A constructor’s initializer: a(x).

cfamily.MemberInit.text

Section titled “cfamily.MemberInit.text”

A constructor’s initializers: “ : a(x), b(y)“.

cfamily.MemberInit.nodes

Section titled “cfamily.MemberInit.nodes”

The nodes of a constructor’s initializers.

cfamily.Member.typesOf

Section titled “cfamily.Member.typesOf”

The types a class defines (nested classes, unions, enumerations, member typedefs), each by its name and its name qualified by the class (typename C<T>::y in a template, where the class is dependent).

cfamily.FunctionDefinition.outsideOf

Section titled “cfamily.FunctionDefinition.outsideOf”

A member function with its result type written outside the class (a conversion function’s result is part of its name, after the class’s qualifier, so in the class’s scope already).

cfamily.Item.methods

Section titled “cfamily.Item.methods”

The member definitions of the items’ classes, in order (a full specialization’s members are ordinary members).

cfamily.Item.templates

Section titled “cfamily.Item.templates”

The function templates and their specializations, after the prototypes.

cfamily.Item.names

Section titled “cfamily.Item.names”

The names the items declare: globals, enumerators (a class’s too), and those inside namespaces.

cfamily.Item.classes

Section titled “cfamily.Item.classes”

The classes the items define, with whether each is declared with class.

cfamily.Print.forwards

Section titled “cfamily.Print.forwards”

Forward declarations of the later classes the lines name: a type has to be declared before it is written.

cfamily.Item.withoutStatic

Section titled “cfamily.Item.withoutStatic”

An item without its file-scope static.

cfamily.Expr.calls

Section titled “cfamily.Expr.calls”

Whether an expression calls one of the functions by name.

cfamily.Item.calls

Section titled “cfamily.Item.calls”

Whether the items call one of the functions anywhere: functions, templates, classes, globals’ initializers and namespaces.

cfamily.PrintedLine.hasWord

Section titled “cfamily.PrintedLine.hasWord”

Whether a line has one of the words as an identifier.

cfamily.PrintedLine.contains

Section titled “cfamily.PrintedLine.contains”

Whether a line contains one of the texts (std::max( and the like).

cfamily.Print.header

Section titled “cfamily.Print.header”

A header when it is needed.

cfamily.Print.mathNames

Section titled “cfamily.Print.mathNames”

The <math.h> functions the model has (<cmath>’s under std::).

cfamily.Print.mathCalls

Section titled “cfamily.Print.mathCalls”

How a call of a <cmath> function starts in the printed C++ (std::sqrt(, and C++’s own std::abs().

cfamily.Print.headers

Section titled “cfamily.Print.headers”

The headers chosen by what the program uses: stdio always; for C, stdbool when it writes bool; for C++, the streams, strings, containers and exceptions it names; and the C library headers of the functions it calls.

cfamily.Item.includes

Section titled “cfamily.Item.includes”

The program’s own includes, in order.

cfamily.Program.generatedLines

Section titled “cfamily.Program.generatedLines”

The printed lines with the nodes on each: the headers (the program’s own when it writes any), then the body.

cfamily.Program.generate

Section titled “cfamily.Program.generate”

A program as C or C++ source, one statement per line.

cfamily.PrintedLine.find

Section titled “cfamily.PrintedLine.find”

The line (counting from k) a node is printed on, or 0 when it is not printed.

cfamily.NodeId.origin

Section titled “cfamily.NodeId.origin”

A node without its last :part, if it has one: a node the checker makes for part of a construct (n:element of a range-based for, n:list of a braced list) is the construct’s node and a suffix.

cfamily.PrintedLine.findOrigin

Section titled “cfamily.PrintedLine.findOrigin”

The line a node or the construct it was made for is printed on, trying the node without its suffixes in turn.

cfamily.Program.generatedLineOf

Section titled “cfamily.Program.generatedLineOf”

The line (counting from 1) a node is printed on, or 0 when it is not printed; a node made for part of a construct is found by the construct’s node.
