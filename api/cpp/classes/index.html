classes

cpp.Member.entry

Section titled “cpp.Member.entry”

A member’s name and access, if it is a data member, a member function or a name a using-declaration brings in (lookup of the name then stops at the class, [namespace.udecl]p1; the access is the declaration’s, p19).

cpp.Classes.importsOf

Section titled “cpp.Classes.importsOf”

The names a class brings in with using-declarations, each with the base it names.

cpp.Classes.all

Section titled “cpp.Classes.all”

Every result in order, or the first error.

cpp.Classes.numbered

Section titled “cpp.Classes.numbered”

Each element with its position.

cpp.Classes.constructorName

Section titled “cpp.Classes.constructorName”

The name of a class’s k-th constructor’s function.

cpp.Classes.destructorName

Section titled “cpp.Classes.destructorName”

The name of a class’s destructor’s function.

cpp.Classes.named

Section titled “cpp.Classes.named”

The class a written type names, among the known ones; a const class is still that class ([basic.type.qualifier]p1), so a const object is constructed and destroyed as any other.

cpp.TypeSyntax.dimensions

Section titled “cpp.TypeSyntax.dimensions”

The lengths of a written array type’s dimensions, outermost first, and its element type (no lengths for a type that is not an array).

cpp.Classes.elementCount

Section titled “cpp.Classes.elementCount”

How many elements an array of the lengths has.

cpp.Classes.fieldClass

Section titled “cpp.Classes.fieldClass”

The class a written type is, or the class of its elements when it is an array (of arrays) of one.

cpp.TypeSyntax.isArray

Section titled “cpp.TypeSyntax.isArray”

Whether a written type is an array.

cpp.Classes.leafAt

Section titled “cpp.Classes.leafAt”

The j-th element (row by row; j a surface expression) of an array of the given lengths: a[j / d1][j % d1].

cpp.Classes.leafLoop

Section titled “cpp.Classes.leafLoop”

A loop over the indices of count elements (the first first, or the last first), with a statement for each.

cpp.DataMember

Section titled “cpp.DataMember”

A data member: its name, written type and default member initializer.

cpp.Member.fields

Section titled “cpp.Member.fields”

The data members of a class’s members, in order.

cpp.Classes.dynamicType

Section titled “cpp.Classes.dynamicType”

The hidden member that keeps a polymorphic object’s dynamic type (cpp.polymorphism).

cpp.Member.isVirtual

Section titled “cpp.Member.isVirtual”

Whether a member function is virtual as declared (virtual, override or pure).

cpp.Member.functionName

Section titled “cpp.Member.functionName”

The name a member function declares, if the member is one.

cpp.Member.isHidden

Section titled “cpp.Member.isHidden”

Whether a data member is one of a class’s hidden parts that a copy keeps its own of: the dynamic type, the pointers to its virtual bases, and their storage (a copy’s virtual bases are made by the complete object).

cpp.Member.copiedFields

Section titled “cpp.Member.copiedFields”

The data members that are copied and assigned: all but the hidden ones (a copy keeps its own).

cpp.Classes.polymorphic

Section titled “cpp.Classes.polymorphic”

Whether a class (its members, with its bases as subobjects) is polymorphic: it declares a virtual function, or a base is polymorphic ([class.virtual]p1).

cpp.Classes.needsDefault

Section titled “cpp.Classes.needsDefault”

Whether a class needs a constructor it does not declare: a default member initializer, a member of a class with constructors ([class.default.ctor]p4), or a dynamic type to keep (a polymorphic class).

cpp.Classes.destroysMembers

Section titled “cpp.Classes.destroysMembers”

Whether a class has members to destroy: a member (or an array of them) of a class with a destructor.

cpp.DeclaredConstructor

Section titled “cpp.DeclaredConstructor”

A constructor to lower: its access, node, parameters, member initializers and body.

cpp.Classes.names

Section titled “cpp.Classes.names”

Whether a written type names a class (as a class or a struct).

cpp.Classes.isReferenceTo

Section titled “cpp.Classes.isReferenceTo”

Whether a written type is a reference to a class, const or not.

cpp.Classes.isCopyParameters

Section titled “cpp.Classes.isCopyParameters”

Whether a constructor’s parameters make it a copy constructor of a class: one reference to the class, const or not ([class.copy.ctor]p1).

cpp.Classes.isRvalueReferenceTo

Section titled “cpp.Classes.isRvalueReferenceTo”

Whether a written type is an rvalue reference to a class, const or not.

cpp.Classes.isMoveParameters

Section titled “cpp.Classes.isMoveParameters”

Whether a constructor’s parameters make it a move constructor of a class: one rvalue reference to the class ([class.copy.ctor]p3).

cpp.Member.moveAssigns

Section titled “cpp.Member.moveAssigns”

Whether a member is a move assignment operator of class x: operator= taking an rvalue reference to a (const) x ([class.copy.assign]p3).

cpp.Classes.made

Section titled “cpp.Classes.made”

The node of the code the branch makes for a written node n (an implicit member’s body, the dynamic type set in a constructor): not one the program wrote, so the debugger does not stop at it, and a problem found in it is placed at n (Program.placedNode).

cpp.Member.isImplicit

Section titled “cpp.Member.isImplicit”

Whether a member is one the class has implicitly: a member function carrying the class’s own node (the implicit assignment operators).

cpp.Classes.declaresMove

Section titled “cpp.Classes.declaresMove”

Whether class x (of node n) declares a move constructor or a move assignment operator.

cpp.Classes.declaresCopying

Section titled “cpp.Classes.declaresCopying”

Whether class x (of node n) declares a copy or move constructor, a copy or move assignment operator, or a destructor (with none of them it has an implicit move, [class.copy.ctor]p8, [class.copy.assign]p4).

cpp.Classes.movedFrom

Section titled “cpp.Classes.movedFrom”

The value of a member (of a written type) to move from: an xvalue of it (static_cast<T &&>; an array’s elements are then xvalues too, [expr.sub]p2).

cpp.Classes.copiesMembers

Section titled “cpp.Classes.copiesMembers”

Whether copying a class’s members needs a constructor: a member (or an array of them) of a class with a copy constructor.

cpp.Classes.nothrowMembers

Section titled “cpp.Classes.nothrowMembers”

Whether moving (or copying) each member of a class (its base subobjects too) cannot throw: of a class that moves so, or not of a class (an implicit move or copy constructor is noexcept so, [except.spec]p8).

cpp.Classes.implicitCopy

Section titled “cpp.Classes.implicitCopy”

The implicit copy constructor, when the class declares none (nor a move, which deletes it) and copying its members needs one: each member initialized from the other object’s ([class.copy.ctor]p14).

cpp.Classes.implicitMove

Section titled “cpp.Classes.implicitMove”

The implicit move constructor, when the class declares no copy or move operation nor destructor and moving its members differs from copying them (a member, or a base subobject, of a class with a move constructor): each member initialized from the other object’s as an xvalue ([class.copy.ctor]p14).

cpp.Classes.lacksDefault

Section titled “cpp.Classes.lacksDefault”

Whether a data member (a base subobject too) without a default member initializer is of a class an object of which cannot be default-initialized: the implicit default constructor is then deleted ([class.default.ctor]p2.4).

cpp.Classes.declaredConstructors

Section titled “cpp.Classes.declaredConstructors”

The constructors a class declares, in order.

cpp.Classes.defaultConstructibleOf

Section titled “cpp.Classes.defaultConstructibleOf”

Whether an object of a class can be default-initialized: without declared constructors, unless its implicit default constructor is deleted; else by a constructor callable without arguments (each parameter has a default).

cpp.Classes.constructorsIn

Section titled “cpp.Classes.constructorsIn”

A class’s constructors in order: the declared ones (else the implicit default one, if it needs one and is not deleted), then the implicit copy constructor, if it has one ([class.default.ctor]p1: only a declared constructor suppresses the default one).

cpp.Classes.constructorEntry

Section titled “cpp.Classes.constructorEntry”

The k-th constructor’s entry in its class’s table.

cpp.Classes.constructorsOf

Section titled “cpp.Classes.constructorsOf”

A class’s constructors for its table: the function each is lowered to, its arity and access.

cpp.Classes.copyConstructorOf

Section titled “cpp.Classes.copyConstructorOf”

A class’s copy constructor’s function, if it has one.

cpp.Classes.nothrowMoveOf

Section titled “cpp.Classes.nothrowMoveOf”

Whether moving an object of a class cannot throw (std::is_nothrow_move_constructible, what libc++’s move_if_noexcept asks): its move constructor is noexcept; without one, its copy constructor is, or it has none (copied bit for bit).

cpp.Classes.moveConstructorOf

Section titled “cpp.Classes.moveConstructorOf”

A class’s move constructor’s function, if it has one.

cpp.Classes.destroyedOf

Section titled “cpp.Classes.destroyedOf”

Whether a class has a destructor to run: declared, or for its members.

cpp.ClassMembers.assigns

Section titled “cpp.ClassMembers.assigns”

Whether a class has a copy assignment operator (declared or implicit).

cpp.Classes.assignmentDeleted

Section titled “cpp.Classes.assignmentDeleted”

Whether a class’s implicit copy and move assignment operators are deleted ([class.copy.assign]p7): a data member (or an array’s elements) is const or a reference, or is of a class (a base subobject included) whose are.

cpp.Member.copyAssigns

Section titled “cpp.Member.copyAssigns”

Whether a member is a copy assignment operator of class x: operator= taking an x or a reference to a (const) x ([class.copy.assign]p1).

cpp.Classes.implicitAssignment

Section titled “cpp.Classes.implicitAssignment”

The implicit copy assignment operator, when the class declares no copy assignment (nor a move, which deletes it) and assigning its members needs one, or it declares another operator= (both are then chosen between, [class.copy.assign]p2): each member assigned from the other object’s (an array element by element), then *this returned ([class.copy.assign]p12).

cpp.Classes.implicitMoveAssignment

Section titled “cpp.Classes.implicitMoveAssignment”

The implicit move assignment operator, when the class declares no copy or move operation nor destructor and a member (or a base subobject) is of a class with a move assignment operator: each member assigned from the other object’s as an xvalue (an array element by element), then *this returned ([class.copy.assign]p12).

cpp.Classes.baseField

Section titled “cpp.Classes.baseField”

The name of a class’s k-th base class subobject, a member of its struct.

cpp.Classes.constructionField

Section titled “cpp.Classes.constructionField”

The member of a class that keeps virtual bases holding, while a base subobject of it is constructed or destroyed, the number of its first construction context in the complete object (Polymorphism.block).

cpp.Classes.virtualPointer

Section titled “cpp.Classes.virtualPointer”

The name of the member pointing to a direct virtual base’s subobject (the complete object’s).

cpp.Classes.virtualStorage

Section titled “cpp.Classes.virtualStorage”

The name of the member a complete object keeps a virtual base’s subobject in.

cpp.Classes.distinct

Section titled “cpp.Classes.distinct”

The names in order, each once (its first).

cpp.Classes.virtualBasesOf

Section titled “cpp.Classes.virtualBasesOf”

The virtual bases of a hierarchy with direct bases, in the order a complete object constructs them: depth first, left to right, a base’s own virtual bases before it, each once ([class.base.init]p13).

cpp.Classes.baseMembers

Section titled “cpp.Classes.baseMembers”
