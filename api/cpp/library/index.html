The library’s vector class template.

cpp.Library.stringName

Section titled “cpp.Library.stringName”

The library’s string class.

cpp.Library.listName

Section titled “cpp.Library.listName”

The library’s class template of a braced list’s elements (the one the language names, [dcl.init.list]p5).

cpp.Library.vectorType

Section titled “cpp.Library.vectorType”

The syntax’s vector type as the library’s template’s instance.

cpp.Library.isVector

Section titled “cpp.Library.isVector”

Whether a written type is a vector (the syntax’s, or the template’s instance).

cpp.Library.stringMember

Section titled “cpp.Library.stringMember”

The full name of a member type of the library’s string written name (string::size_type under using namespace std, or std::string::size_type), if that is what it is.

cpp.Library.stringType

Section titled “cpp.Library.stringType”

The syntax’s string type as the library’s class; a member type of it as the typedef the class’s lowering declares.

cpp.Library.isString

Section titled “cpp.Library.isString”

Whether a written type is a string or a member type of one (the syntax’s, or the library’s class).

cpp.Library.isList

Section titled “cpp.Library.isList”

Whether a written type is a std::initializer_list.

cpp.Library.lastName

Section titled “cpp.Library.lastName”

A name without its qualifiers.

cpp.Library.typePrefix

Section titled “cpp.Library.typePrefix”

What the names member types are kept by start with, a member type’s name after it (Library.typeOf).

cpp.Library.typeOf

Section titled “cpp.Library.typeOf”

The name a library class’s member type (its typedef) named x is kept by: only a type that names it uses it, and what it stands for may be a class template’s instance (string’s reverse_iterator is __reverse_iterator<char *, char>), which a kept typedef makes every program with the class expand ([temp.inst]p11).

cpp.Library.typeNames

Section titled “cpp.Library.typeNames”

The member types and class templates a written type t may name: Library.typeOf the name, without its qualifiers, of each type inside it that is named.

cpp.Library.calledName

Section titled “cpp.Library.calledName”

The name a call names: a member function’s, or a function’s without its qualifier.

cpp.Library.operatorUsed

Section titled “cpp.Library.operatorUsed”

The operator functions an expression can use by its operator ([over.match.oper]).

cpp.Library.usedName

Section titled “cpp.Library.usedName”

The functions an expression names: by a call, or by an operator.

cpp.Library.streamed

Section titled “cpp.Library.streamed”

The operator functions a statement can use: output’s operator<<.

cpp.Library.severalPrefix

Section titled “cpp.Library.severalPrefix”

What the names a construction may give two or more arguments start with, its class’s name after it (Library.severalOf).

cpp.Library.severalOf

Section titled “cpp.Library.severalOf”

The name a library class’s constructors needing two or more arguments are kept by: only a construction given two or more can choose one ([over.match.viable]p2), so a program (with the library’s functions it keeps) that has no such construction of the class does not need them, nor what their bodies call (std::string(n, c) throws std::length_error: kept, it would bring the standard exception classes into every program with a string). x is the class’s name without its qualifiers; “*” stands for any class (a construction whose class is not written, a braced list without a type, a pack expansion), and so does a name that is no library class’s (a typedef, a template parameter: Library.severalNeeded).

cpp.Library.severalAny

Section titled “cpp.Library.severalAny”

The name of a construction that may give two or more arguments to any class’s constructor.

cpp.Library.constructedClass

Section titled “cpp.Library.constructedClass”

The class a written type t constructs, without its qualifiers (“*” when t does not name a class by itself).

cpp.Library.severalIf

Section titled “cpp.Library.severalIf”

Library.severalOf the class of t when a construction’s arguments args are two or more.

cpp.Library.severalList

Section titled “cpp.Library.severalList”

The names a braced list of the type t (its items xs) may construct with several arguments: t’s class (by its constructors, or each member of an aggregate by one item), std::initializer_list’s (the list object made from the items, Construction.fromList), and any class for an item that is a list itself (what it initializes is not written).

cpp.Library.severalInExpression

Section titled “cpp.Library.severalInExpression”

The names an expression e may construct with several arguments by: a temporary or a new with two or more, a braced list, a pack expansion.

cpp.Library.severalInInit

Section titled “cpp.Library.severalInInit”

The names an initializer init of the type t may construct with several arguments by: a braced list’s.

cpp.Library.severalInStatement

Section titled “cpp.Library.severalInStatement”

The names a statement s may construct with several arguments by: a declaration by a braced list or by two or more arguments, a member initialized so (its class is not written there).

cpp.Library.severalInMembers

Section titled “cpp.Library.severalInMembers”

The names the members ms’ static data members may construct with several arguments by (their initializers, a nested class’s members’ too).

cpp.Library.severalInItems

Section titled “cpp.Library.severalInItems”

The names items’ globals and static members may construct with several arguments by (a braced list, two or more arguments); their bodies’ statements are Library.severalInStatement’s.

cpp.Library.severalNeeded

Section titled “cpp.Library.severalNeeded”

Whether the names include one a library class’s (named x) constructors needing several arguments are kept by (Library.severalOf): x’s, any class’s, or a class’s that is none of the library’s classes (what it names is not known here).

cpp.Library.required

Section titled “cpp.Library.required”

How many arguments a constructor needs: its parameters ps without a default (a parameter pack needs none).

cpp.Library.needsSeveral

Section titled “cpp.Library.needsSeveral”

Whether a member m is a constructor needing two or more arguments (kept by Library.severalOf its class).

cpp.Library.declares

Section titled “cpp.Library.declares”

The names (without qualifiers) of the classes and the functions other than operators items declare.

cpp.Library.programNames

Section titled “cpp.Library.programNames”

The names (without qualifiers) a program’s items name: the classes of its written types and the functions it calls.

cpp.Library.asMember

Section titled “cpp.Library.asMember”

A free function seen as a member (whether it is kept and what it calls are found the same way).

cpp.Library.namesList

Section titled “cpp.Library.namesList”

Whether a written type names std::initializer_list (inside the library, before its namespace is flattened, without the qualifier).

cpp.Library.takesList

Section titled “cpp.Library.takesList”

Whether a member takes a std::initializer_list (only a braced list or a list object can be its argument, [over.match.list]).

cpp.Library.kept

Section titled “cpp.Library.kept”

Whether a library class’s member m is kept when the names are called (and lists, whether the program has std::initializer_list; several, whether a class’s constructors needing two or more arguments are, by its name x).

cpp.Library.prunedClass

Section titled “cpp.Library.prunedClass”

A class d with only its kept members (Library.kept: lists, names and several are its).

cpp.Library.pruned

Section titled “cpp.Library.pruned”

Library items with only their kept functions (their classes’ members, their free functions; Library.kept: lists, names and several are its).

cpp.LibraryMember

Section titled “cpp.LibraryMember”

A library class’s member: whether it is kept without being named, whether it takes a std::initializer_list, its name (a member function’s, Library.typeOf a member type’s), the names it calls (the member types its types name too), and for a constructor needing two or more arguments its class’s name (kept by Library.severalNeeded).

cpp.LibraryMember.of

Section titled “cpp.LibraryMember.of”

A member’s entry: what it calls (found as in a class of its own).

cpp.Library.members

Section titled “cpp.Library.members”

The functions of library items: their classes’ members (a class template’s explicit specializations’ too) and their free functions.

cpp.Library.closed

Section titled “cpp.Library.closed”

The names called, with those the usable members they name call, and so on (fuel bounds the rounds; classes are the library’s, for Library.severalNeeded). The members of a header used only by name come as a group with the names that open it: they count once one of those is called.

cpp.LibraryHeader

Section titled “cpp.LibraryHeader”

A header of the library: its name, the headers it includes (by name), the headers it uses only by name (a function it calls, a class template a member type names: included only when what the program keeps names one of their declarations, Library.headersFor), its items and their functions (made when a program includes it: a header’s items are a large tree, and a program that includes few headers does not build the others’), and the names it declares (Library.declares of its items, generated with them as data: choosing a program’s headers reads only these).

cpp.LibraryHeader.of

Section titled “cpp.LibraryHeader.of”

The header name that includes the headers needs and uses the headers uses by name, with its items and their functions members (each made when it is first needed: a top-level constant behind each, so made once) and the names declares they declare.

cpp.Library.headersFor

Section titled “cpp.Library.headersFor”

The headers a program gets, from the headers wanted (with the headers they include), and the names its kept functions call (Library.closed, from the names used; classes are the library’s). A header a chosen one uses only by name (LibraryHeader.uses) is added, with the headers it includes, when those names name one of its declarations (Library.openNames): its members are in the same closure, each counting once that happens, so the names are found once; another round only for the headers an added one uses (fuel bounds the rounds).
