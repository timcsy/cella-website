primitives

cpp.Primitives.boundsName

Section titled “cpp.Primitives.boundsName”

The primitive a precondition that does not hold is (an access past the object).

cpp.Primitives.internal

Section titled “cpp.Primitives.internal”

The internal function a primitive called as a statement is (cpp.construction), if it is one.

cpp.Primitives.reading

Section titled “cpp.Primitives.reading”

Whether a primitive reads standard input into a string’s layout, and how much: a line (true) or a word.

cpp.Primitives.read

Section titled “cpp.Primitives.read”

__cella_read_word(data, size, capacity) and __cella_read_line(...): a word (whitespace skipped first) or a line (up to the newline, which is read and not kept) read into a string’s layout, its three parts lvalues.

cpp.Primitives.lvalues

Section titled “cpp.Primitives.lvalues”

Expressions checked as lvalues, in order.

cpp.Primitives.choosing

Section titled “cpp.Primitives.choosing”

A primitive marking an implementation’s choice: noting it (0), releasing a block because of it (1), keeping a block under a new number because of it (2).

cpp.Primitives.choiceName

Section titled “cpp.Primitives.choiceName”

The name of a choice: a string literal.

cpp.Primitives.choose

Section titled “cpp.Primitives.choose”

__cella_implementation_choice("name"): the run notes that it assumes the choice. __cella_choice_release(p, "name"): the block released (as __cella_release), only because of the choice. __cella_choice_keep(p, "name"): the block p (an lvalue) points to is kept under a new number and p set to it, so a pointer taken before still reaches it assuming the choice.

cpp.Primitives.advance

Section titled “cpp.Primitives.advance”

__cella_advance(us): the simulated time advanced by us microseconds.

cpp.Primitives.environmental

Section titled “cpp.Primitives.environmental”

An environment statement with its operands checked in order (there must be count of them).

cpp.Primitives.showing

Section titled “cpp.Primitives.showing”

__cella_show_text’s index and text, or __cella_show_name’s index and pointer: the pointer’s value (an array decays to a pointer to its first character).

cpp.Primitives.show

Section titled “cpp.Primitives.show”

__cella_show("kind", index, value) (0), __cella_show_text("kind", index, text) (1) and __cella_show_name("kind", index, pointer) (2): the kind is a string literal.

cpp.Primitives.require

Section titled “cpp.Primitives.require”

__cella_require(ok, "name", detail): the name is a string literal.

cpp.Primitives.notModeled

Section titled “cpp.Primitives.notModeled”

What a library does not model yet (__cella_unsupported("String(double)"), a string literal): the verdict is unknown, with the reason, not a rejection of a valid program. A library function is checked only when used, so only a program that uses it is affected.

cpp.Primitives.cannotTell

Section titled “cpp.Primitives.cannotTell”

Where a run cannot tell what happens next (__cella_undetermined("HD44780 busy"), a string literal): the run stops there and the verdict is unknown, with the reason; only a run reaching it is affected.

cpp.Primitives.halt

Section titled “cpp.Primitives.halt”

Where the host stops watching (__cella_halt()): the run ends there, exit code 0, nothing after it run.

cpp.Primitives.asynchronous

Section titled “cpp.Primitives.asynchronous”

The environment’s primitives that let simulated time pass (__cella_wait, __cella_elapse): the timers’ events and the interrupts they run are the hardware’s, asynchronous to the code that waits, not its effects.

cpp.Primitives.interrupt

Section titled “cpp.Primitives.interrupt”

An interrupt handler run (__cella_interrupt(handler)): a call through the pointer, as written; what the handler does is not an effect of the code it interrupts (the effect summaries see a primitive without a body).

cpp.Primitives.statement

Section titled “cpp.Primitives.statement”

A primitive called as a statement: what it does. None for any other statement.

cpp.Primitives.moveIfNoexcept

Section titled “cpp.Primitives.moveIfNoexcept”

__cella_move_if_noexcept(x): x as an xvalue when moving an object of its class cannot throw or it cannot be copied, else x as it is (libc++’s std::move_if_noexcept, [utility]); an object not of a class as it is.

cpp.Primitives.inputLook

Section titled “cpp.Primitives.inputLook”

__cella_peek() and __cella_available(): the next byte of standard input without taking it (-1 when there is none) and how many are left, both an int (Serial’s peek() and available(); getchar() takes one).

cpp.Primitives.ahead

Section titled “cpp.Primitives.ahead”

The next byte of standard input, -1 when there is none.

cpp.Primitives.clock

Section titled “cpp.Primitives.clock”

__cella_clock(): the simulated time in microseconds, an unsigned long long.

cpp.Primitives.input

Section titled “cpp.Primitives.input”

__cella_input("kind", index, fallback) (a long) and __cella_input_real(...) (a double): the host’s input for kind:index now, else the fallback; the kind is a string literal.

cpp.Primitives.given

Section titled “cpp.Primitives.given”

The host’s input for a key at a time: the value of the last one given for it at or before the time.

cpp.Primitives.inputValue

Section titled “cpp.Primitives.inputValue”

Evaluating an input: its index and fallback, then the host’s value for kind:index (a double converts an integer given).

cpp.Primitives.expression

Section titled “cpp.Primitives.expression”

A primitive called as an expression: __cella_allocate<T>(n), a block of n objects of T not constructed; __cella_move_if_noexcept(x); __cella_clock(). None for any other expression.

cpp.Primitives.within

Section titled “cpp.Primitives.within”

__cella_points_within(p, start, n): a bool, its three operands checked in order.

cpp.Primitives.inside

Section titled “cpp.Primitives.inside”

Whether a pointer points to one of the n elements from start: the same array, start <= p < start + n.

cpp.Primitives.withinValue

Section titled “cpp.Primitives.withinValue”

Evaluating __cella_points_within: its operands, then 1 or 0.

cpp.Primitives.eepromByte

Section titled “cpp.Primitives.eepromByte”

__cella_eeprom_read(address): an unsigned char, its operand checked.

cpp.Primitives.levels

Section titled “cpp.Primitives.levels”

__cella_pin_levels(first, count): an int, its two operands checked in order.

cpp.Primitives.shownAt

Section titled “cpp.Primitives.shownAt”

A value the host was shown for a key now (mode:2), 0 when none.

cpp.Primitives.driven

Section titled “cpp.Primitives.driven”

The level a chip drives a pin to now: the last drive from a time not after now; none when none drives it or the last one lets it go.

cpp.Primitives.pinLevel

Section titled “cpp.Primitives.pinLevel”

A pin’s level now, as the headers’ __cella_pin_input gives it: an output’s written level (as shown); an input’s driven level, else the host’s input for digital:pin (unconnected: 0, 1 with the pull-up, mode 3).

cpp.Primitives.levelBits

Section titled “cpp.Primitives.levelBits”

The levels of count pins from first, the j-th in bit j.

cpp.Primitives.levelsValue

Section titled “cpp.Primitives.levelsValue”

Evaluating __cella_pin_levels: its operands, then the pins’ levels now.

cpp.Primitives.eepromAt

Section titled “cpp.Primitives.eepromAt”

The EEPROM’s byte at an address: the last one written there, else what the host gave it at power-up (eeprom:<address>), else 0xFF (erased).

cpp.Primitives.eepromValue

Section titled “cpp.Primitives.eepromValue”

Evaluating __cella_eeprom_read: its address, then the byte there.

cpp.Primitives.traceLimit

Section titled “cpp.Primitives.traceLimit”

The most pin changes kept for the host (the old model’s traceLimit).

cpp.Primitives.operand

Section titled “cpp.Primitives.operand”

The j-th of an environment statement’s operands’ values, as an integer (0 when there is none).

cpp.Primitives.keyed

Section titled “cpp.Primitives.keyed”

A table with the key’s value replaced, or added at the end when the key is new.

cpp.Primitives.changed

Section titled “cpp.Primitives.changed”

The environment after a statement of it, given its operands’ values.

cpp.Primitives.owner

Section titled “cpp.Primitives.owner”

The declaration owning a block among the scopes, the current ones and those the calls saved (“” when none does: allocated).

cpp.Primitives.elementIndices

Section titled “cpp.Primitives.elementIndices”

The element indices of an array type a path goes through ([1] for the second element; nothing past a member).

cpp.Primitives.ownerOf

Section titled “cpp.Primitives.ownerOf”

The declaration of the object a value points into, with the elements of an array it points to (arm@3[1]; “” for a pointer into no block).

cpp.Primitives.run

Section titled “cpp.Primitives.run”

Running a statement of the environment: its operands’ values, then the environment changed by them.
