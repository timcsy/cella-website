construction

cpp.Construction.rawArray

Section titled “cpp.Construction.rawArray”

The internal functions a container’s generated code calls for its elements (as std::allocator and std::allocator_traits do): a block of elements allocated without constructing them (#rawArray(new T[n])), an object constructed at a pointer with arguments (placement new, #construct(p, args)), one destroyed there (#destroy(p), nothing for an element without a destructor), a block released without destroying its elements (#releaseRaw(p)), an object moved to a pointer as a whole (#relocate(to, from): the source is not destroyed afterwards, as a moved-from vector or string owns nothing).

cpp.Construction.constructAt

Section titled “cpp.Construction.constructAt”

Placement new (see Construction.rawArray).

cpp.Construction.destroyAt

Section titled “cpp.Construction.destroyAt”

An object’s destruction at a pointer (see Construction.rawArray).

cpp.Construction.releaseRaw

Section titled “cpp.Construction.releaseRaw”

A block’s release without destroying its elements (see Construction.rawArray).

cpp.Construction.valueConstructAt

Section titled “cpp.Construction.valueConstructAt”

The internal function value-initializing an object at a pointer (::new (p) T(), [dcl.init]p9): a scalar zero, an object of a class by its default constructor.

cpp.Construction.relocate

Section titled “cpp.Construction.relocate”

An object moved as a whole (see Construction.rawArray).

cpp.TypedCpp

Section titled “cpp.TypedCpp”

A typed statement of C++.

cpp.Assigning

Section titled “cpp.Assigning”

How a value is converted for storing into an object of a type (the dialect’s assignment conversion).

cpp.Choosing

Section titled “cpp.Choosing”

What choosing a constructor uses: the types, the assignment conversion, and the checker of expressions.

cpp.Constructing

Section titled “cpp.Constructing”

What checking a construction as a statement uses: what choosing uses, and the checker of statements.

cpp.Construction.resolve

Section titled “cpp.Construction.resolve”

A written type resolved and completed (a class’s struct with its members).

cpp.Construction.promotes

Section titled “cpp.Construction.promotes”

Whether a type converts to another by a promotion ([conv.prom], [conv.fpprom]): an integer type to its promoted type, float to double.

cpp.Construction.rank

Section titled “cpp.Construction.rank”

How well an argument matches a parameter ([over.ics.rank]), if it can be passed at all: by the conversion, 0 the same type (or a reference bound to it), 1 a promotion, 2 any other standard conversion, 3 a pointer converted to void * or bool, 4 a user-defined conversion; four times that, two more for const added to a pointer’s pointee and one more for an rvalue bound to an lvalue reference (worse than to an rvalue reference, [over.ics.rank]p3.2.3).

cpp.Construction.better

Section titled “cpp.Construction.better”

Whether one candidate’s ranks are no worse than another’s for every argument and better for one ([over.match.best]p2).

cpp.Construction.ranks

Section titled “cpp.Construction.ranks”

The ranks of a constructor’s parameters for the arguments, if every argument can be passed (the parameters after this, from the lowered function’s signature).

cpp.Construction.choose

Section titled “cpp.Construction.choose”

The constructor for the arguments: among those taking as many (or more, with defaults), the ones every argument can be passed to, and of those the one better than every other ([over.match.best]); none is no match, several are ambiguous.

cpp.Construction.trivialCopy

Section titled “cpp.Construction.trivialCopy”

A copy of an object of a class without a copy constructor (its implicit one is trivial, [class.copy.ctor]p12): the other object (of the class, or of one derived from it: its base subobject) stored bit for bit. None unless the one argument is such an object.

cpp.Construction.constructorCall

Section titled “cpp.Construction.constructorCall”

The call of a class’s constructor on an object (its address and the arguments), checked as a statement: the constructor chosen for the arguments, accessible here.

cpp.TypedExpr.isTemporary

Section titled “cpp.TypedExpr.isTemporary”

Whether an expression is a temporary the full expression ends (a call’s result, kept in a variable named for it).

cpp.Construction.fromTemporary

Section titled “cpp.Construction.fromTemporary”

An object initialized by a temporary of its class (a call’s result): the temporary becomes the object, without a copy ([dcl.init]p17.6.1, C++17’s guaranteed elision); it is handed over, so the full expression’s end does not destroy it. None when the initializer is anything else.

cpp.Construction.declareOf

Section titled “cpp.Construction.declareOf”

A declaration of an object of a class with constructors (its type resolved): initialized by a temporary of its class, else reserved, constructed with the arguments, and only then an object (a constructor that throws leaves none to destroy, [except.ctor]p3). A const object is not const while it is constructed ([class.ctor]p5).

cpp.Construction.declareObject

Section titled “cpp.Construction.declareObject”

A declaration of an object of a class with constructors, by its written type.

cpp.Construction.arguments

Section titled “cpp.Construction.arguments”

The arguments of an initializer for a constructor: none, the expression, or the braced list’s expressions.

cpp.Construction.classOf

Section titled “cpp.Construction.classOf”

The class with constructors a declaration’s type names, if any.

cpp.Construction.scalar

Section titled “cpp.Construction.scalar”

A member that is not of a class with constructors initialized in a constructor: the value (zero for x()) converted to the member’s type and stored, even into a const member (an initialization, not an assignment).

cpp.Construction.guarded

Section titled “cpp.Construction.guarded”

A constructed member’s guard after its construction: a pointer to it, declared in the constructor’s scope (named, so it is no temporary of the full expression and lasts to the scope’s end), which destroys it when an exception leaves the constructor ([except.ctor]p3: the constructed members and bases, in reverse order).

cpp.Construction.member

Section titled “cpp.Construction.member”

A member initialized in a constructor: one of a class with constructors is constructed (this->y with the arguments), any other initialized by its value; guarded when its class has a destructor.

cpp.Construction.defaulted

Section titled “cpp.Construction.defaulted”

A member of a class without constructors default-initialized in a constructor: nothing stored, but guarded (the member’s class has a destructor, so it is destroyed if a later member throws, [except.ctor]p3).

cpp.Construction.declaredObject

Section titled “cpp.Construction.declaredObject”

A declaration of an object of a class with constructors (no initializer-list constructor taking its list).

cpp.Construction.listParameter

Section titled “cpp.Construction.listParameter”

The std::initializer_list<E> instance a class’s initializer-list constructor takes (its one parameter, by value or by reference, [dcl.init.list]p2), with E, if it has one.

cpp.Construction.listed

Section titled “cpp.Construction.listed”

C x = {a, b…} for a class with an initializer-list constructor ([dcl.init.list]p3.6, p5): x reserved; in a block of its own, the backing array const E[n] initialized from the list (each element copy-initialized), x constructed from std::initializer_list<E>(array, n); the block’s end destroys the array, as the declaration’s end does.

cpp.Construction.directScalar

Section titled “cpp.Construction.directScalar”

T x(args); of a type that is not a class: a scalar’s is its initialization by the one argument (int z(7);, [dcl.init]p17.8), none is default initialization (as T x;), more is excess elements in scalar initializer (clang’s words); any other type takes no constructor’s arguments.

cpp.Construction.statement

Section titled “cpp.Construction.statement”

C++’s statements that construct objects.

cpp.Construction.defaultDeleted

Section titled “cpp.Construction.defaultDeleted”

Whether a declaration default-initializes an object (or an array of them) of a class that cannot be ([class.default.ctor]p2: its implicit default constructor deleted, or no constructor callable without arguments).

cpp.Construction.noDefault

Section titled “cpp.Construction.noDefault”

Why an object of a class cannot be default-initialized.

cpp.Construction.declared

Section titled “cpp.Construction.declared”

What a statement of C++ declares: C x(args); declares x.

cpp.Construction.destroying

Section titled “cpp.Construction.destroying”

The call of an object’s class’s destructor (given a pointer to it), if the program has one.

cpp.Construction.ending

Section titled “cpp.Construction.ending”

What runs before an object ends: its class’s destructor, if the program has one; for a member’s guard, the member’s destructor when an exception leaves the scope, else nothing.
