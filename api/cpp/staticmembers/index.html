staticmembers

cpp.StaticMembers.first

Section titled “cpp.StaticMembers.first”

The first of the values found.

cpp.StaticMembers.anyNamed

Section titled “cpp.StaticMembers.anyNamed”

Whether some class has a static member by a name (before checking an object for one).

cpp.StaticMembers.named

Section titled “cpp.StaticMembers.named”

The static member a class has by a name, its own or a base’s (the class it belongs to with it).

cpp.StaticMembers.lowered

Section titled “cpp.StaticMembers.lowered”

The static member a declaration or a function is lowered from, with its class.

cpp.StaticMembers.checked

Section titled “cpp.StaticMembers.checked”

A use of a static member rejected when the function being checked may not use it.

cpp.StaticMembers.through

Section titled “cpp.StaticMembers.through”

A static member through an object, as the object evaluated and then the member (use makes it from what the member is lowered to), as an lvalue or not; none when the object’s class has no static member by the name.

cpp.StaticMembers.expression

Section titled “cpp.StaticMembers.expression”

A use of a static member (as an lvalue or not): its access checked by name, its object evaluated through an object.

cpp.StaticMembers.call

Section titled “cpp.StaticMembers.call”

A call of a static member function by name, its access checked (a call statement is not an expression).
