python.Methods.fails

Section titled “python.Methods.fails”

An exception raised, the heap unchanged.

python.Methods.gives

Section titled “python.Methods.gives”

A value produced, the heap unchanged.

python.Methods.checked

Section titled “python.Methods.checked”

A check, then the method’s work when it passed.

python.Methods.notInteger

Section titled “python.Methods.notInteger”

TypeError: a value that is not an index.

python.Methods.sizeLimit

Section titled “python.Methods.sizeLimit”

The largest Py_ssize_t, 2^63 - 1.

python.Methods.fitsSize

Section titled “python.Methods.fitsSize”

Whether an int fits a Py_ssize_t.

python.Methods.size

Section titled “python.Methods.size”

An index argument as a Py_ssize_t: TypeError for a value that is not an index, OverflowError past the range.

python.Methods.sliceBound

Section titled “python.Methods.sliceBound”

A slice bound (_PyEval_SliceIndex): an index clamped to Py_ssize_t, or None when it may be (none).

python.Methods.adjust

Section titled “python.Methods.adjust”

A bound adjusted to a length (ADJUST_INDICES): from the end when negative, then clamped to 0 and the length (an end only).

python.Methods.range

Section titled “python.Methods.range”

The start and end arguments of find and the others (each optional, None allowed), adjusted to a length.

python.Methods.slot

Section titled “python.Methods.slot”

The value of a parsed parameter, if it was given.

python.Methods.codes

Section titled “python.Methods.codes”

The code points of a str receiver.

python.Methods.text

Section titled “python.Methods.text”

A text produced.

python.Methods.bool

Section titled “python.Methods.bool”

A bool produced.

python.Methods.unclassified

Section titled “python.Methods.unclassified”

What the model cannot tell: a code point it does not classify, for a method that needs its class.

python.Methods.classifiedOnly

Section titled “python.Methods.classifiedOnly”

A str method of no arguments that needs every code point classified.

python.Methods.isAlpha

Section titled “python.Methods.isAlpha”

Whether a code point is a letter (str.isalpha).

python.Methods.isDigit

Section titled “python.Methods.isDigit”

Whether a code point is a decimal digit (str.isdigit on the classified code points).

python.Methods.allOf

Section titled “python.Methods.allOf”

Whether a text is not empty and every code point is of a class.

python.Methods.caseChange

Section titled “python.Methods.caseChange”

s.upper(), s.lower(), s.title(), s.capitalize().

python.Methods.classTest

Section titled “python.Methods.classTest”

s.isdigit(), s.isalpha(), s.isupper(), s.islower().

python.Methods.strip

Section titled “python.Methods.strip”

s.strip(chars), lstrip, rstrip: whitespace, or the code points of chars (None: whitespace).

python.Methods.wordsWithin

Section titled “python.Methods.wordsWithin”

The pieces between whitespace, at most k splits (CPython’s split_whitespace): the rest after the last split, without its leading whitespace, is the last piece.

python.Methods.splitWithin

Section titled “python.Methods.splitWithin”

The pieces between occurrences of a separator, at most k splits, within fuel steps (piece: the current one).

python.Methods.splitCount

Section titled “python.Methods.splitCount”

The most splits a count asks for: every one for a negative count.

python.Methods.split

Section titled “python.Methods.split”

s.split(sep=None, maxsplit=-1).

python.Methods.firstNotText

Section titled “python.Methods.firstNotText”

The first item of a list that is not a str, and where it is.

python.Methods.joinWith

Section titled “python.Methods.joinWith”

Texts joined with a separator between them.

python.Methods.join

Section titled “python.Methods.join”

s.join(iterable): every item a str.

python.Methods.mustBeText

Section titled “python.Methods.mustBeText”

TypeError: a str method’s argument that must be a str.

python.Methods.replace

Section titled “python.Methods.replace”

s.replace(old, new, /, count=-1).

python.Methods.findFrom

Section titled “python.Methods.findFrom”

Where a text first occurs within [start, end) of another, from position k.

python.Methods.search

Section titled “python.Methods.search”

s.find, s.index, s.count of a part within [low, high), which is at least as long as the part: where it first is (-1: not there), or how many times it is there without overlapping (an empty part: between every two code points and at both ends).

python.Methods.find

Section titled “python.Methods.find”

s.find(sub[, start[, end]]), s.index, s.count: ValueError from index when it is not there.

python.Methods.tailMatch

Section titled “python.Methods.tailMatch”

Whether a text has a part at the start (or the end) of [start, end) (CPython’s tailmatch).

python.Methods.prefixes

Section titled “python.Methods.prefixes”

The texts a startswith argument gives: a str, or a tuple of them.

python.Methods.startsWith

Section titled “python.Methods.startsWith”

s.startswith(prefix[, start[, end]]), s.endswith.

python.Methods.fill

Section titled “python.Methods.fill”

The fill character of ljust and the others (a space when absent).

python.Methods.padded

Section titled “python.Methods.padded”

A text padded to a width: on the right (ljust), the left (rjust), or both (center: the extra one on the left when the margin and the width are both odd, as CPython’s pad does).

python.Methods.memoryLimit

Section titled “python.Methods.memoryLimit”

The width past which a padded text would not fit the model’s memory (2^32 code points): MemoryError.

python.Methods.justify

Section titled “python.Methods.justify”

s.ljust(width[, fillchar]), rjust, center.

python.Methods.zfill

Section titled “python.Methods.zfill”

s.zfill(width): zeros on the left, after a leading sign.

A method of a receiver: its name, and what calling it with arguments does.

Section titled “python.Methods.named”

A method that takes its own name first.

Section titled “python.Methods.caseMethod”

s.upper() and the other case changes.

Section titled “python.Methods.testMethod”

s.isdigit() and the other class tests.

python.Methods.ofText

Section titled “python.Methods.ofText”

The str methods the model provides.

Section titled “python.Piece”

What reading the next piece of a format string gives (CPython’s MarkupIterator_next): the end, literal text, literal text followed by a replacement field (its name, conversion, spec, and whether the spec holds fields of its own), or an exception.

python.Format.fails

Section titled “python.Format.fails”

A format string’s ValueError.

python.Format.spec

Section titled “python.Format.spec”

A field’s spec up to its closing brace, nested braces counted (k: braces still open).

python.Format.name

Section titled “python.Format.name”

A field’s name up to :, ! or } (a [ skips to its ]), within fuel steps: the name, the code point that ended it, the rest.

python.Format.afterConversion

Section titled “python.Format.afterConversion”

After a field’s conversion specifier: } ends the field, : starts its spec.

python.Format.field

Section titled “python.Format.field”

A replacement field after its { (CPython’s parse_field).

python.Format.next

Section titled “python.Format.next”

The next piece of a format string.

python.Numbering

Section titled “python.Numbering”

How replacement fields are numbered so far: not yet, automatically (the next number), or by hand.

python.Format.integer

Section titled “python.Format.integer”

A field name’s part as an index (CPython’s get_integer): none unless every code point is a decimal digit; ValueError past Py_ssize_t.

python.Formatting

Section titled “python.Formatting”

The arguments a format string reads.

An attribute of a value in a field name (a property would run a user’s code: unsupported here).

python.Format.walk

The rest of a field name after its first part: .name and [key] in turn (CPython’s FieldNameIterator).

python.Format.object

Section titled “python.Format.object”

The value a field’s name gives.

python.Format.hex

Section titled “python.Format.hex”

Hexadecimal digits of a natural, in small letters, at least a width of them.

python.Format.ascii

ascii() of a repr: code points past ASCII as \xNN, \uNNNN or \UNNNNNNNN.

python.Format.convert

Section titled “python.Format.convert”

python.Built

python.Format.render

Section titled “python.Format.render”

One replacement field rendered (CPython’s output_markup).
