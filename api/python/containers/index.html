containers

python.Ordering

Section titled “python.Ordering”

How values compare without the heap: an order (-1, 0 or 1), unordered (a NaN takes part: every comparison is false), or incomparable (< raises TypeError).

python.Value.identity

Section titled “python.Value.identity”

The identity of the value v when the model keeps it: an object’s address, a user’s function’s (its object’s).

python.Value.sameIdentity

Section titled “python.Value.sameIdentity”

Whether the identity y (if any) is x.

python.Value.isPlainBuiltin

Section titled “python.Value.isPlainBuiltin”

Whether v is a built-in function holding nothing (one object for its name, as CPython’s are).

python.Value.withoutIdentity

Section titled “python.Value.withoutIdentity”

Whether the value v has no identity in the model where CPython goes by it: a function without its object (a built-in function holding values), a method bound to a value that is not an object or to such a function (a method equals another bound to the same object with an equal function), a NaN (a dict, a set and in check identity before ==, and a NaN equals only itself that way).

python.Value.equal

Section titled “python.Value.equal”

Whether the values a and b are equal without looking at the heap: numbers by value, str by code points, tuples item by item, objects on the heap by address.

python.Value.equalOther

Section titled “python.Value.equalOther”

Whether a, a value that is not a number, equals b.

python.Value.equalAll

Section titled “python.Value.equalAll”

Whether the lists of values xs and ys are equal item by item.

python.Value.compareCodes

Section titled “python.Value.compareCodes”

Comparing the code points xs with ys: -1, 0 or 1.

python.Value.order

Section titled “python.Value.order”

How the values a and b compare without the heap.

python.Value.orderOther

Section titled “python.Value.orderOther”

How a, a value that is not a number, compares with b: str by code points, tuples by their first unequal items, slices as the tuples of their start, stop and step.

python.Value.orderAll

Section titled “python.Value.orderAll”

How the lists xs and ys compare: by the first items that are not equal, else by length.

python.Changed

Section titled “python.Changed”

What changing the heap gives: the new heap and the outcome.

python.Changed.same

Section titled “python.Changed.same”

The heap h unchanged, with the outcome o.

python.Changed.value

Section titled “python.Changed.value”

The heap h with the value v produced.

python.Heap.allocate

Section titled “python.Heap.allocate”

The new object o on the heap h: the heap with it, and a reference to it.

python.Heap.store

Section titled “python.Heap.store”

The heap h with the object at the address a replaced by o.

python.Heap.list

Section titled “python.Heap.list”

A new list of the values xs on the heap h.

python.Attributes.find

Section titled “python.Attributes.find”

The attribute of a name among attributes in order.

python.Class.order

Section titled “python.Class.order”

The class value c’s method resolution order (itself first) on the heap h: empty for a built-in class.

python.Class.attributes

Section titled “python.Class.attributes”

The class value c’s own attributes on the heap h.

python.Class.hashable

Section titled “python.Class.hashable”

Whether instances of the classes in the method resolution order on the heap h are hashable: the first class defining __hash__ or __eq__ decides (__eq__ without __hash__, or __hash__ = None, makes them unhashable).

python.Value.unhashablePart

Section titled “python.Value.unhashablePart”

The value inside v on the heap h that makes it unhashable, if any (CPython’s message names the innermost): a list, dict, set, a dict’s keys or items view, or an instance whose class makes it unhashable (Class.hashable); a tuple’s first item that has one.

python.Value.unhashableIn

Section titled “python.Value.unhashableIn”

The first unhashable part of the values vs on the heap h (Value.unhashablePart).

python.Value.holdsWithoutIdentity

Section titled “python.Value.holdsWithoutIdentity”

Whether the value v or an item of a tuple v has no identity in the model (Value.withoutIdentity).

python.Value.anyWithoutIdentity

Section titled “python.Value.anyWithoutIdentity”

Whether one of the values vs holds a value without identity (Value.holdsWithoutIdentity).

python.Value.hashable

Section titled “python.Value.hashable”

Whether the value v on the heap h can be a dict key or a set item here: it has no unhashable part, and no part without identity (Containers.unhashable says why not).

python.Containers.unhashable

Section titled “python.Containers.unhashable”

Why the value v on the heap h cannot be a dict key or set item (role: “dict key” or “set element”): TypeError naming the type of v and of its innermost unhashable part (CPython 3.14’s words), or unsupported for a value without identity in the model.

python.Containers.unhashableKey

Section titled “python.Containers.unhashableKey”

Why the value v on the heap h cannot be a dict key (Containers.unhashable).

python.Containers.unhashableItem

Section titled “python.Containers.unhashableItem”

Why the value v on the heap h cannot be a set item (Containers.unhashable).

python.Dict.get

Section titled “python.Dict.get”

The value for the key k in the dict’s pairs.

python.Dict.set

Section titled “python.Dict.set”

The dict’s pairs with the key k set to v: an existing key keeps its key and place, a new one goes last.

python.Dict.remove

Section titled “python.Dict.remove”

The dict’s pairs without the key k.

python.Dict.ofPairs

Section titled “python.Dict.ofPairs”

A dict from pairs in order (a later pair’s value wins).

python.Dict.keys

Section titled “python.Dict.keys”

The keys of the dict’s pairs.

python.Dict.values

Section titled “python.Dict.values”

The values of the dict’s pairs.

python.Dict.items

Section titled “python.Dict.items”

The dict’s pairs as tuples.

python.Set.has

Section titled “python.Set.has”

Whether the value x is among the values xs (by ==, without the heap).

python.Set.remove

Section titled “python.Set.remove”

The set’s items xs without the item x.

python.Heap.dict

Section titled “python.Heap.dict”

A new dict from pairs on the heap h.

python.Index.within

Section titled “python.Index.within”

The index i, counted from the end when negative, if it is within the length size.

python.Index.wrongType

Section titled “python.Index.wrongType”

TypeError for the index i that is not an int, into the sequence named what (its type name read from the heap h).

python.Index.notSubscriptable

Section titled “python.Index.notSubscriptable”

TypeError for the value c that cannot be indexed, its type name read from the heap h.

python.Index.item

Section titled “python.Index.item”

The item of items at the index i on the heap h, or IndexError (what: the sequence’s name in the message).

python.Containers.listValues

Section titled “python.Containers.listValues”

The list’s items xs (every place in a list holds a value).

python.Raised.keyError

Section titled “python.Raised.keyError”

KeyError for the key not there, on the heap h: the key itself its argument (e.args[0]), its repr the message.

python.Index.objectItem

Section titled “python.Index.objectItem”

c[i] of the object o that c refers to on the heap h.

python.Index.get

Section titled “python.Index.get”

c[i] on the heap h.

python.Index.notAssignable

Section titled “python.Index.notAssignable”

TypeError for the value c whose items cannot be assigned, its type name read from the heap h.

python.Index.setObject

Section titled “python.Index.setObject”

c[i] = v on the object o that c refers to at the address a on the heap h.

python.Index.set

Section titled “python.Index.set”

c[i] = v on the heap h.

python.Index.notDeletable

Section titled “python.Index.notDeletable”

TypeError for the value c whose items cannot be deleted, its type name read from the heap h (a tuple’s and a str’s message says “doesn’t”, as CPython’s do).

python.Index.deleteObject

Section titled “python.Index.deleteObject”

del c[i] on the object o that c refers to at the address a on the heap h: a list’s item at an index (counted from the end when negative), a dict’s key (KeyError when it is not there).

python.Index.delete

Section titled “python.Index.delete”

del c[i] on the heap h.

python.Slice.bound

Section titled “python.Slice.bound”

The slice bound v clamped to a sequence of size items as CPython’s PySlice_AdjustIndices does (counted from the end when negative; up is whether the step is positive); None is the bound’s default absent.

python.Slice.indexesWithin

Section titled “python.Slice.indexesWithin”

The indexes from i toward stop by step (going up when up), within fuel indexes.

python.Slice.indexes

Section titled “python.Slice.indexes”

The indexes the slice from start to stop by step takes from a sequence of size items.

python.Slice.pick

Section titled “python.Slice.pick”

The items of xs at the indexes.

python.Slice.get

Section titled “python.Slice.get”

c[start:stop:step] on the heap h for a list, str, tuple or range c, the slice already read (Slice.stepOf: step not 0). A range’s slice is a range (CPython’s compute_slice): from the item at the first index to the item at the last, by step times the range’s step.

python.Containers.noLength

Section titled “python.Containers.noLength”

TypeError for the value v without a length, its type name read from the heap h.

python.Object.size

Section titled “python.Object.size”

The number of items in the object o on the heap h, if it has a length.

python.Containers.size

Section titled “python.Containers.size”

len(v) on the heap h.

python.Items

Section titled “python.Items”

What iterating gives: the values in order, or an exception.

python.Range.values

Section titled “python.Range.values”

The count values of a range from start by step.

python.Heap.listItems

Section titled “python.Heap.listItems”

The values the list v holds now on the heap h (none if it is not a list).

python.Object.items

Section titled “python.Object.items”

The values iterating over the object o on the heap h gives, if it can be iterated.

python.Containers.runsCode

Section titled “python.Containers.runsCode”

Whether iterating over the object o that v refers to on the heap h runs a user’s code or changes its state: a generator, an iterator (taking its items uses it up: python.iterators’s Iterator.drain), or an instance whose class defines __iter__ or __getitem__.

python.Containers.runs

Section titled “python.Containers.runs”

Whether iterating over the value v on the heap h runs a user’s code or uses up an iterator (Containers.runsCode).

python.Containers.iterate

Section titled “python.Containers.iterate”

Iterating over the value v on the heap h; iterating that runs a user’s code or uses up an iterator is the caller’s, unsupported here.

python.Text.findWithin

Section titled “python.Text.findWithin”

Where part (not empty) first occurs in cs, within fuel steps (k: the position so far).

python.Containers.concatenate

Section titled “python.Containers.concatenate”

a + b for two lists on the heap h (none when a is not a list: another operator’s case).

python.Containers.repeat

Section titled “python.Containers.repeat”

The items xs repeated n times (none when n is not positive).

python.Containers.repeatError

Section titled “python.Containers.repeatError”

TypeError for repeating a sequence by the value v that is not an int, its type name read from the heap h.

python.Containers.repeatList

Section titled “python.Containers.repeatList”

a * b for a list a or b and a count, on the heap h (none when neither side is a list).

python.Outcome.truth

Section titled “python.Outcome.truth”

The bool b produced.

python.Set.same

Section titled “python.Set.same”

Whether the sets with the items xs and ys have the same items.

python.Contents.fuel

Section titled “python.Contents.fuel”

How deep comparing contents may go.

python.Contents.unsupported

Section titled “python.Contents.unsupported”

The comparison the model cannot make: a user’s comparison method inside a container, or a NaN or a method of a value that is not an object with one alike (Contents.identityEqual).

python.Class.lookup

Section titled “python.Class.lookup”

The attribute name along the method resolution order on the heap h, if a class in it defines it.

python.Value.isInstance

Section titled “python.Value.isInstance”

Whether the value v is an instance of a user’s class on the heap h.

python.Value.defines

Section titled “python.Value.defines”

Whether the value v is an instance on the heap h whose class defines a method name.

python.Value.definesComparison

Section titled “python.Value.definesComparison”

Whether the class of the value v on the heap h defines a comparison method.

python.Contents.equalOther

Section titled “python.Contents.equalOther”

Equality of the values a and b of different kinds (or a user’s objects) on the heap h: not equal, unless one defines __eq__ (unsupported here: none).

python.Contents.identityEqual

Section titled “python.Contents.identityEqual”

Equality of a and b inside a container or for in (CPython checks identity first) when one has no identity in the model (Value.withoutIdentity): a function equals only itself, a bound method another bound to the same object with an equal function (CPython’s method_richcompare). Two that differ in their definition, what they hold or what they are bound to are different objects (false); two alike may still be different objects (a built-in method of a value taken twice, a method bound to an int), and two NaNs equal only when they are one object: none, the model cannot tell.

python.Contents.equalWithin

Section titled “python.Contents.equalWithin”

Whether the values a and b are equal by their contents on the heap h, within fuel levels: none when it cannot be decided here.

python.Contents.equalAllWithin

Section titled “python.Contents.equalAllWithin”

Equality of the lists of values xs and ys item by item on the heap h, within fuel levels.

python.Contents.equalPairs

Section titled “python.Contents.equalPairs”

Equality of the dict’s pairs with the others on the heap h, within fuel levels: each key in the other with an equal value (the sizes are equal).

python.Contents.equalObjects

Section titled “python.Contents.equalObjects”

Equality of the objects oa and ob that a and b refer to on the heap h, by their contents within fuel levels: a dict’s keys or items view compares with a set or such a view as a set (CPython’s dictviews_richcompare).

python.Object.isView

Section titled “python.Object.isView”

Whether the object o is a dict’s view.

python.Object.setLike

Section titled “python.Object.setLike”

The items of the object o on the heap h if it compares as a set: a set, or a dict’s keys or items view.

python.Contents.equalViews

Section titled “python.Contents.equalViews”

Equality of the objects x and y that a and b refer to on the heap h, where a view takes part: as sets when both compare as sets, else as other objects do.

python.Contents.equal

Section titled “python.Contents.equal”

a == b on the heap h as the built-in types decide it (a user’s object, whose methods were tried and declined, is equal only to itself; a float by its value, since == does not check identity).

python.Contents.has

Section titled “python.Contents.has”

x in xs for a sequence’s items xs on the heap h: x is y or x == y for some item.

python.Position

Section titled “python.Position”

Where an item first equals x: its position, none, or the comparison the model cannot make.

python.Contents.position

Section titled “python.Contents.position”

The first position from k where an item of xs equals x on the heap h.

python.Contents.count

Section titled “python.Contents.count”

How many items of xs equal x on the heap h (counted so far: so).

python.Contents.shortSort

Section titled “python.Contents.shortSort”

The items xs (fewer than 64) sorted by their key on the heap h as CPython’s listsort does (one run: count_run then binarysort), so a comparison that raises is the one CPython makes first: the items sorted, or as far as the sorting got, with the exception.

python.Contents.sortPartly

Section titled “python.Contents.sortPartly”

The items xs sorted by their key on the heap h, with the exception a comparison raised (the items then as far as the sorting got, as CPython’s list.sort leaves them): fewer than 64 as CPython compares them (Contents.shortSort); more by a stable merge sort, which gives the same order, but a comparison that raises there is not taken (CPython may compare another pair first). When reversed, CPython reverses, sorts and reverses again (after a failure too), so items with equal keys keep their order.
