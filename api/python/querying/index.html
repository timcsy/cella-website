querying

python.Querying.heap

Section titled “python.Querying.heap”

The heap the representative values are on: an empty list at 0, an empty dict at 1, an empty set at 2.

python.Querying.representative

Section titled “python.Querying.representative”

A value of a type to try operations on (none for a type that has none).

python.Tried

Section titled “python.Tried”

What trying an operation gave: the result’s type, a TypeError’s message, or something else (an exception that depends on the values).

python.Querying.outcome

Section titled “python.Querying.outcome”

What an outcome on the representatives’ heap tried.

python.Querying.evaluated

Section titled “python.Querying.evaluated”

What an expression on the representatives tried.

python.Querying.changed

Section titled “python.Querying.changed”

What a change of the heap tried.

python.HolePlace

Section titled “python.HolePlace”

Where a hole is: an operand (the operation decides whether a type fits), a place any type fits, or elsewhere (it depends on values at run time).

python.Seen

Section titled “python.Seen”

What walking a scope knows: the names’ types it sees, the built-in names there, the holes’ assumed types, the module’s types and built-in names, the enclosing functions’ locals (free names inside, of unknown type), the names some function changes with nonlocal.

python.Findings

Section titled “python.Findings”

What walking finds: the nodes’ types, the type errors, the operations whose operands’ types are unknown, and the holes’ places (each list newest first).

python.Findings.empty

Section titled “python.Findings.empty”

Nothing found.

python.Findings.node

Section titled “python.Findings.node”

A node’s type found, when it is known.

python.Findings.error

Section titled “python.Findings.error”

A type error at a node.

python.Findings.undecided

Section titled “python.Findings.undecided”

An operation whose operands’ types are not known.

python.Findings.hole

Section titled “python.Findings.hole”

A hole’s place.

python.Querying.lookup

Section titled “python.Querying.lookup”

A name’s type in a list of names’ types.

python.Querying.without

Section titled “python.Querying.without”

Names without some others.

python.Seen.forget

Section titled “python.Seen.forget”

The scope without some names (they are its own, of unknown type).

python.Querying.builtinResults

Section titled “python.Querying.builtinResults”

The built-ins’ result types (whatever the arguments; a call that raises has no result).

python.Querying.same

Section titled “python.Querying.same”

Two types when they are the same.

python.Querying.both

Section titled “python.Querying.both”

The representatives of two types, when both have one.

python.Querying.binary

Section titled “python.Querying.binary”

a op b (or a op= b) at a node, with its operands’ types: str % x formats (whether it fails depends on the format); else the operation tried on representatives.

python.Querying.unary

Section titled “python.Querying.unary”

op a at a node, with its operand’s type (not is always a bool).

python.Querying.comparison

Section titled “python.Querying.comparison”

One comparison tried on representatives.

python.Querying.compare

Section titled “python.Querying.compare”

a < b < c: only the first pair is always compared (the rest may be cut short); the result is a bool when all of them can be compared.

python.Querying.constant

Section titled “python.Querying.constant”

A constant’s type.

python.Querying.allSame

Section titled “python.Querying.allSame”

The type of all of some values, when they have the same.

python.Querying.builtin

Section titled “python.Querying.builtin”

Whether a callee is a built-in’s name.

python.Querying.called

Section titled “python.Querying.called”

A call’s type: a built-in’s result.

python.Querying.typed

Section titled “python.Querying.typed”

An expression at a node whose type is known, with what walking found.

python.Binding

Section titled “python.Binding”

A plain binding of a name: x = e (and x: T = e), or x op= e.

python.Querying.named

Section titled “python.Querying.named”

A plain binding of a target that is a name.

python.Querying.walrus

Section titled “python.Querying.walrus”

The names an expression binds with :=.

python.Querying.walrusOf

Section titled “python.Querying.walrusOf”

The names an optional expression binds with :=.

python.Querying.otherTargets

Section titled “python.Querying.otherTargets”

The names a target binds that are not a plain name (a.b, a[i], a, b).

python.Querying.argumentsBound

Section titled “python.Querying.argumentsBound”

The names a def’s decorators and defaults bind with :=.

python.Querying.bindingsOf

Section titled “python.Querying.bindingsOf”

A name’s plain bindings.

python.Gives

Section titled “python.Gives”

What a binding gives: a known type, never a value (its outermost operation always raises TypeError), or not known.

python.Findings.errorAt

Section titled “python.Findings.errorAt”

Whether walking found a type error at a node.

python.Querying.gives

Section titled “python.Querying.gives”

What a binding of a name gives in a scope.

python.Querying.seed

Section titled “python.Querying.seed”

The type the first plain assignment that gives one gives: the name’s candidate type.

python.Querying.keeps

Section titled “python.Querying.keeps”

Whether a binding keeps a type.

python.Querying.candidate

Section titled “python.Querying.candidate”

A name’s type when every binding of it keeps its candidate type (assuming the name has it, as x = x + 1 needs), given the names known so far.

python.Querying.rounds

Section titled “python.Querying.rounds”

The names’ types known after some rounds (knowing more names only makes more bindings known, so as many rounds as names reach the fixed point).

python.Querying.scopeTypes

Section titled “python.Querying.scopeTypes”

A scope’s names’ types (before those it sees from outside); unknown are names whose type cannot be known (its parameters, names changed elsewhere).

python.Seen.function

Section titled “python.Seen.function”

A function’s scope: its own locals are known by its own bindings; a name that is not local is the enclosing function’s (free, of unknown type) or else the module’s.

python.Seen.classBody

Section titled “python.Seen.classBody”

A class body’s scope: the names it binds are the class’s attributes (not followed); its functions see the module.

python.Seen.module

Section titled “python.Seen.module”

The module’s scope (with the holes’ assumed types): a name some function declares global is not known.

python.Querying.target

Section titled “python.Querying.target”

An assignment target walked (a name’s binding is not an expression; a.b and a[i] are).

python.Querying.targets

Section titled “python.Querying.targets”

Assignment targets walked.

python.Querying.analyze

Section titled “python.Querying.analyze”

What walking a program finds (the holes assumed of some types).

python.Fit

Section titled “python.Fit”

How a candidate type fits a hole.

python.Querying.newError

Section titled “python.Querying.newError”

The first type error not already found without the hole’s type.

python.Querying.fit

Section titled “python.Querying.fit”

How a type fits a hole: no when it makes a type error; else exact when the operation the hole is an operand of can be decided (or any type fits there), unknown otherwise.

python.Fit.exact

Section titled “python.Fit.exact”

Whether a fit is exact.

python.Fit.unknown

Section titled “python.Fit.unknown”

Whether a fit is unknown.

python.Querying.commas

Section titled “python.Querying.commas”

Names joined with commas.

python.Querying.exactly

Section titled “python.Querying.exactly”

The candidate types that fit exactly.

python.Querying.display

Section titled “python.Querying.display”

What a hole shows: the one type it expects, the types it accepts, or why none is known.

python.Querying.expects

Section titled “python.Querying.expects”

The type a hole expects, when exactly one fits exactly.

python.Fit.json

Section titled “python.Fit.json”

A fit as JSON.

python.Querying.slot

Section titled “python.Querying.slot”

A hole’s entry: what it shows, the type it expects, how each candidate fits.

python.Querying.candidates

Section titled “python.Querying.candidates”

The candidate types tried in a hole when none are given.

python.Querying.json

Section titled “python.Querying.json”

The types of a program as JSON: {nodes, slots, errors}.

python.Querying.types

Section titled “python.Querying.types”

The types of a program given as its syntax tree’s JSON for the editor ({nodes, slots, errors}; see the module’s comment); candidates is a JSON list of the type names to try in each hole, empty for the default ones.
