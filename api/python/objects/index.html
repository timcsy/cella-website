The built-in exception classes the subset has.

Section titled “python.Exceptions.isName”

Whether a name is a built-in exception class’s.

python.Exceptions.chainWithin

Section titled “python.Exceptions.chainWithin”

A built-in exception class and the ones above it, nearest first, within fuel steps.

python.Exceptions.chain

Section titled “python.Exceptions.chain”

A built-in class and the exception classes above it (only itself for a class that is not an exception).

python.Exceptions.chainOf

Section titled “python.Exceptions.chainOf”

A built-in class (as code points) and the exception classes above it.

python.Attributes.set

Section titled “python.Attributes.set”

Attributes with a name set to a value: replaced where it is, or added at the end.

python.Attributes.remove

Section titled “python.Attributes.remove”

Attributes without a name; none when no attribute has it.

python.Class.same

Section titled “python.Class.same”

Whether two values are the same class: the same object on the heap, or the same built-in class.

python.Class.among

Section titled “python.Class.among”

Whether a class is among classes.

python.Class.isUser

Section titled “python.Class.isUser”

Whether a value is a user’s class.

python.Class.is

Section titled “python.Class.is”

Whether a value is a class: a built-in one or a user’s.

python.Class.exceptionBase

Section titled “python.Class.exceptionBase”

The built-in exception class a class derives from: empty for a class that is not an exception.

python.Class.isException

Section titled “python.Class.isException”

Whether a class is an exception class.

python.Class.firstExceptionBase

Section titled “python.Class.firstExceptionBase”

The built-in exception class the first exception class among bases derives from.

python.Class.tail

Section titled “python.Class.tail”

A list without its first item.

python.Class.dropHead

Section titled “python.Class.dropHead”

A list without its first item when that item is a class.

python.Class.pick

Section titled “python.Class.pick”

C3: the first head among candidates that is in no sequence’s tail.

python.Class.mergeWithin

Section titled “python.Class.mergeWithin”

C3: merging sequences into one order, within fuel steps; none when they cannot be ordered.

python.Class.total

Section titled “python.Class.total”

How many classes sequences hold.

python.Class.listNames

Section titled “python.Class.listNames”

Names joined with commas.

python.Class.make

Section titled “python.Class.make”

class name(bases): a new class with its attributes in order, and the built-in exception class it derives from (empty: inherited from the bases); TypeError when the bases cannot be ordered.

python.Descriptor

Section titled “python.Descriptor”

What a class attribute is when read: a static method, a class method, a property (its getter and setter, None when it has none), or a plain attribute.

python.Descriptor.ofWrapper

Section titled “python.Descriptor.ofWrapper”

What a wrapper of a kind is.

python.Descriptor.of

Section titled “python.Descriptor.of”

What a class attribute is.

python.Function.isUser

Section titled “python.Function.isUser”

Whether a value is a user’s function (a built-in one’s name starts with “builtin “).

python.Function.bindTo

Section titled “python.Function.bindTo”

A user’s function bound to an instance as a method; anything else as it is.

python.Function.name

Section titled “python.Function.name”

A function value’s name.

python.Function.captured

Section titled “python.Function.captured”

The cells a function value captured.

python.Function.shortName

Section titled “python.Function.shortName”

A function’s __name__: a built-in’s name without “builtin “, a nested function’s last part (outer.inner is inner), without the suffix that tells functions of the same name apart (from code point 1 on).

python.Function.qualifiedName

Section titled “python.Function.qualifiedName”

A function’s __qualname__: its name in the program’s table before the mark (a built-in’s without its module’s, Printing.builtinName).

python.Function.ownName

Section titled “python.Function.ownName”

A function’s __name__: a user’s own name, a built-in’s without its module’s.

python.Descriptor.fromInstance

Section titled “python.Descriptor.fromInstance”

A class attribute read from an instance: a user’s function bound to the instance, a static method’s function, a class method bound to the class; anything else as it is.

python.Descriptor.fromClass

Section titled “python.Descriptor.fromClass”

A class attribute read from the class: a static method’s function, a class method bound to the class; anything else (a function too) as it is.

python.Class.property

Section titled “python.Class.property”

The property of a name along a class’s order: its getter and setter.

python.Access

Section titled “python.Access”

What accessing an attribute gives: the heap and a value, a user’s function to call with arguments (a property’s getter or setter), or an exception.

python.Objects.always

Section titled “python.Objects.always”

The attributes every object has in CPython (dir(object), and a user’s instance’s __dict__, __module__ and __weakref__): one the model does not give is something it cannot do, not an AttributeError.

python.Objects.alwaysOnClasses

Section titled “python.Objects.alwaysOnClasses”

The attributes every class has in CPython (dir(type) and dir(object), without __abstractmethods__, which an ordinary class does not have).

python.Objects.missing

Section titled “python.Objects.missing”

AttributeError: the value’s type has no attribute of the name.

python.Objects.classMissing

Section titled “python.Objects.classMissing”

AttributeError: a class has no attribute of the name.

python.Objects.throughProperty

Section titled “python.Objects.throughProperty”

A property’s getter or setter called with arguments; AttributeError when it has none (None).

python.Objects.ofInstance

Section titled “python.Objects.ofInstance”

An instance’s attribute: __class__, a property, its own attribute, then along its class’s order.

python.Class.mro

Section titled “python.Class.mro”

A class’s __mro__: itself, its order, the built-in exception classes above the one it derives from that are not in it, and object.

python.Class.builtinMro

Section titled “python.Class.builtinMro”

A built-in class’s __mro__: bool is under int, an exception class under its own, all under object.

python.Objects.ofClass

Section titled “python.Objects.ofClass”

A user’s class’s attribute: __name__, __mro__, then along its order; a class that defines __eq__ and no __hash__ has __hash__ None (CPython sets it so).

python.Objects.ofProperty

Section titled “python.Objects.ofProperty”

A property’s attribute: fget and fset (None when it has none), and its methods getter, setter and deleter bound to it (python.builtins).

python.Objects.ofObject

Section titled “python.Objects.ofObject”

An attribute of an object on the heap.

python.Objects.ofException

Section titled “python.Objects.ofException”

A built-in exception’s attribute: args, and a StopIteration’s value.

python.Objects.get

Section titled “python.Objects.get”

v.name.

python.Objects.noDict

Section titled “python.Objects.noDict”

AttributeError for setting an attribute on a value that has no attributes of its own.

python.Objects.setObject

Section titled “python.Objects.setObject”

v.name = x on an object on the heap.

python.Objects.set

Section titled “python.Objects.set”

v.name = x: an instance’s or a user’s class’s own attribute, or a property’s setter called.

python.Objects.deleteObject

Section titled “python.Objects.deleteObject”

del v.name on an object on the heap.

python.Objects.delete

Section titled “python.Objects.delete”

del v.name: an instance’s or a user’s class’s own attribute.

python.Value.classOf

Section titled “python.Value.classOf”

A value’s class: an instance’s class, or the built-in class of its type.

python.Objects.hasUserAttribute

Section titled “python.Objects.hasUserAttribute”

Whether a value’s class or the instance itself has an attribute of a name (a user’s attribute, not a built-in method).

python.Class.after

Section titled “python.Class.after”

The classes after a class in an order.

python.Objects.super

Section titled “python.Objects.super”

super().name in a method of class c whose first argument is x: looked up along the order of x’s class after c. An exception class’s __init__ and __str__ are the built-in exception’s.

python.Objects.instantiate

Section titled “python.Objects.instantiate”

A new instance of a class; an exception class’s instance keeps its arguments as args.

python.Objects.withoutInit

Section titled “python.Objects.withoutInit”

Calling a user’s class that has no __init__: TypeError for arguments (an exception class takes positional ones, not keyword ones).

python.Objects.initReturned

Section titled “python.Objects.initReturned”

What __init__ returned: TypeError unless None.

python.Bound.arguments

Section titled “python.Bound.arguments”

The arguments to call a value with: a bound method’s instance before the others.

python.Bound.function

Section titled “python.Bound.function”

The function to call for a value: a bound method’s function.

python.Cell.make

Section titled “python.Cell.make”

A new cell, with a value or without.

python.Cell.content

Section titled “python.Cell.content”

What a cell holds.

python.Cell.read

Section titled “python.Cell.read”

Reading a captured variable: UnboundLocalError for the function’s own variable without a value, NameError for an enclosing function’s.

python.Cell.write

Section titled “python.Cell.write”

A cell given a value.

python.Exceptions.of

Section titled “python.Exceptions.of”

The exception classes a value is an instance of, nearest first: a built-in exception’s by the hierarchy, a user’s exception’s along its class’s order and then the built-in ones; empty for a value that is not an exception.

python.Class.within

Section titled “python.Class.within”

Whether class c is class b or a subclass of it.

python.Objects.isSubclass

Section titled “python.Objects.isSubclass”

issubclass(c, b): b a class or a tuple of classes.

python.Objects.instanceOf

Section titled “python.Objects.instanceOf”

Whether a value is an instance of a class.

python.Objects.isInstance

Section titled “python.Objects.isInstance”

isinstance(x, c): c a class or a tuple of classes.

python.Exceptions.arguments

Section titled “python.Exceptions.arguments”

An exception’s args.

python.Exceptions.text

Section titled “python.Exceptions.text”

str(e) of an exception without its own __str__: empty for no arguments, the str of one (a KeyError’s repr), the tuple’s repr for more.

python.Showing

Section titled “python.Showing”

A user’s __str__ or __repr__ to call before printing a value: the instance, the bound method, and whether it is __str__ (whose text str uses) rather than __repr__ (the instance is the target).

python.Showing.ofInstance

Section titled “python.Showing.ofInstance”

The method an instance is shown with: __str__ at the top (when its class defines one), else __repr__.

python.Showing.flatten

Section titled “python.Showing.flatten”

The keys and values of pairs, in order.

python.Showing.ofObject

Section titled “python.Showing.ofObject”

The methods to call for an object on the heap, after the ones found, within fuel levels.

python.Showing.collectWithin

Section titled “python.Showing.collectWithin”

The methods to call for a value, in the order printing reaches them, after the ones found, within fuel levels.

python.Showing.each

Section titled “python.Showing.each”

The methods to call for the items of a container (each shown with __repr__).

python.Showing.targets

Section titled “python.Showing.targets”

The methods to call before printing values, in order: an instance at the top with __str__ when top holds (as print and str do), every one inside with __repr__.

python.Showing.store

Section titled “python.Showing.store”

An instance with the text its method returned kept for printing.

python.Showing.remember

Section titled “python.Showing.remember”

What a method returned, kept in its instance; TypeError when it is not a str.
