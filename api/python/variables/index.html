variables

python.Variables.user

Section titled “python.Variables.user”

Whether a name is the user’s (the translation’s own names start with a dot or a space).

python.Variables.maybe

Section titled “python.Variables.maybe”

An optional name as a list of names.

python.Variables.at

Section titled “python.Variables.at”

Names bound at a node.

python.Variables.parameterBinds

Section titled “python.Variables.parameterBinds”

A function’s parameters with their nodes.

python.Variables.functionBinds

Section titled “python.Variables.functionBinds”

A function’s binding nodes: its parameters’, then its body’s.

python.Variables.declOf

Section titled “python.Variables.declOf”

A name’s first binding node (empty when it has none).

python.Shown

Section titled “python.Shown”

A function as the debugger shows it: its name in the program’s table, its name shown, its locals’ places, its own locals (not its free names), its captured locals and its binding nodes.

python.Variables.path

Section titled “python.Variables.path”

A function’s name shown (within fuel): a nested function’s after its enclosing ones, a method’s after its class.

python.Variables.display

Section titled “python.Variables.display”

A function’s name shown, made unique: one shown like an earlier function’s gets a mark (code 1) and its number.

python.Variables.shown

Section titled “python.Variables.shown”

A function as the debugger shows it.

python.Shows

Section titled “python.Shows”

What the debugger shows of a program: the module’s names with their slots and declaration nodes, and its functions.

python.Variables.moduleDecl

Section titled “python.Variables.moduleDecl”

A module name’s declaration node: its first binding in the module, else where a function declaring it global binds it.

python.Variables.of

Section titled “python.Variables.of”

What the debugger shows of a program (its module’s slots as Lowering.program lays them out).

python.Shows.function

Section titled “python.Shows.function”

The function of a name in the program’s table (a generator’s continuation is its function’s).

python.Variables.generatorState

Section titled “python.Variables.generatorState”

A generator’s state as CPython’s inspect.getgeneratorstate names it.

python.Variables.shownValue

Section titled “python.Variables.shownValue”

The value a variable shows: a captured one’s is in its cell.

python.Variables.slot

Section titled “python.Variables.slot”

A place’s slot.

python.Variables.captured

Section titled “python.Variables.captured”

Whether a place holds a cell.

python.Variables.moduleName

Section titled “python.Variables.moduleName”

A module’s name, when a value is one (the model holds import math as a class named module math).

python.Variables.typeOf

Section titled “python.Variables.typeOf”

A value’s type name as the debugger shows it (a module’s is module).

python.Variables.reprOf

Section titled “python.Variables.reprOf”

A value’s repr as the debugger shows it (a module’s is <module 'name'>, without where CPython found it).

python.Variables.plain

Section titled “python.Variables.plain”

A variable’s fields as JSON: its id, name, type and repr (null while unbound), declaration node.

python.Variables.saved

Section titled “python.Variables.saved”

A suspended generator’s own local variables that are bound, from its kept locals (each shown plainly).

python.Variables.generatorFields

Section titled “python.Variables.generatorFields”

A generator’s state, and its local variables unless it is running or done.

python.Variables.json

Section titled “python.Variables.json”

A variable as JSON (a generator’s with its state and frame).

python.Variables.globals

Section titled “python.Variables.globals”

The globals as JSON: the module’s names in the order of their slots.

python.Variables.locals

Section titled “python.Variables.locals”

A call’s own local variables as JSON, read from its locals.

python.Variables.call

Section titled “python.Variables.call”

One shown call: its function (a name in the program’s table; a class body’s is its class’s name, the module’s is empty), where it is, its variables (the module’s and a class body’s have none).

python.Variables.statementAt

Section titled “python.Variables.statementAt”

The statement last entered at a depth of calls (none when there is none).

python.Variables.calls

Section titled “python.Variables.calls”

The calls of a run, innermost first, from the node it is at, its locals and its depth of calls: a call’s frame says whose they are, and holds the caller’s state; a caller is at the statement it last entered at its depth (else the call); the model’s own calls are passed over; the module’s comes last.

python.Variables.frames

Section titled “python.Variables.frames”

The calls of a run stopped at a node, as JSON, innermost first (with the statements last entered at each depth of calls and the depth it is at).

python.Variables.literal

Section titled “python.Variables.literal”

A Python literal a variable is set from: a number, a string in quotes, True, False or None.

python.Variables.setLocal

Section titled “python.Variables.setLocal”

Locals with a call’s own variable (by its id) set: none when the call has no such variable; an error for a captured one.

python.Locals

Section titled “python.Locals”

A call’s locals.

python.Change

Section titled “python.Change”

Where a variable is set: in the locals of a call below (the frames rebuilt with them), or in the globals.

python.Variables.change

Section titled “python.Variables.change”

A variable of the n-th shown call set, from the locals of the call the frames say (innermost first; the model’s own calls are not counted): the frames rebuilt with the caller’s locals changed.

python.Variables.setGlobal

Section titled “python.Variables.setGlobal”

A module variable (by its name) set in the globals.

python.Variables.set

Section titled “python.Variables.set”

A run with a variable of the n-th shown call (innermost first) set from a Python literal.
