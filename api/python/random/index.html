python.Words

Section titled “python.Words”

The 624 words in a complete binary tree of depth 10 (the leaves past 623 are unused zeros): reads and writes take ten steps (the standard library’s Array carries a proof in each array, which makes evaluating 624 writes in the checker too slow).

python.Generator

Section titled “python.Generator”

The generator’s state: 624 words of 32 bits and the position of the next one (624: all used); whether CPython would have seeded it from the operating system (the model has seed(0)’s words instead), and whether a draw was made in that state.

python.Random.keyed

Section titled “python.Random.keyed”

init_by_array’s first loop: mt[i] = (mt[i] ^ (mix(mt[i-1]) * 1664525)) + key[j] + j, k steps.

python.Random.unkeyed

Section titled “python.Random.unkeyed”

init_by_array’s second loop: mt[i] = (mt[i] ^ (mix(mt[i-1]) * 1566083941)) - i, k steps.
