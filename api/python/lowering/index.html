python.Context

Section titled “python.Context”

What the translation knows: each module name’s slot, the current function’s names and their places (none at the module level), the first temporary slot (a local slot in a function, a global one at the module level), the program’s symbol table, its functions and their bodies; in a class body, the names it binds and their places; which class each method’s node belongs to, and the class of the current method; in a comprehension run in place, its variables’ temporaries (they hide the names around it); the names import binds anywhere in the program (a module there is read only as module.member).

python.Lowering

Section titled “python.Lowering”

A translation step: from the context and the next free temporary, its result and the next free temporary, or the construct it cannot take.

python.Lowering.run

Section titled “python.Lowering.run”

Running a translation step.

python.Lowering.give

Section titled “python.Lowering.give”

A step that gives a value.

python.Lowering.then

Section titled “python.Lowering.then”

A step after another.

python.Lowering.fail

Section titled “python.Lowering.fail”

The translation stops: a construct it cannot take.

python.Lowering.context

Section titled “python.Lowering.context”

The context.

python.Lowering.within

Section titled “python.Lowering.within”

A translation step under a changed context (a class body’s names, for one).

python.Lowering.fresh

Section titled “python.Lowering.fresh”

A new temporary slot.

python.Lowering.each

Section titled “python.Lowering.each”

Steps in order, their results in a list.

python.Lowering.paired

Section titled “python.Lowering.paired”

Two lists paired item by item (as long as the shorter).

python.Lowered

Section titled “python.Lowered”

An expression’s translation: the statements to run first, and the expression reading its value.

python.Lowered.plain

Section titled “python.Lowered.plain”

A translation that needs nothing first.

python.Context.place

Section titled “python.Context.place”

The place of a module name.

python.Lowering.functionNames

Section titled “python.Lowering.functionNames”

The built-in functions a name refers to when the module does not bind it.

python.Lowering.classNames

Section titled “python.Lowering.classNames”

The built-in classes a name refers to when the module does not bind it (the exception classes too).

python.Lowering.unprovided

Section titled “python.Lowering.unprovided”

CPython’s built-in names the model does not provide yet: reading one stops the translation (it is unsupported, not a NameError).

python.Lowering.isBuiltin

Section titled “python.Lowering.isBuiltin”

Whether a name is built-in.

python.Lowering.builtin

Section titled “python.Lowering.builtin”

The value of a built-in name.

python.Lowering.builtinRead

Section titled “python.Lowering.builtinRead”

Reading a built-in name.

python.Lowering.mathFunctions

Section titled “python.Lowering.mathFunctions”

The math functions the model provides.

python.Lowering.mathConstants

Section titled “python.Lowering.mathConstants”

The math constants, as CPython’s repr writes them (the nearest binary64).

python.Lowering.randomFunctions

Section titled “python.Lowering.randomFunctions”

The random module’s functions the model provides (python.random).

python.Lowering.member

Section titled “python.Lowering.member”

A member of math or random: a function (the built-in function named by the module) or a constant.

python.Lowering.moduleValue

Section titled “python.Lowering.moduleValue”

A module bound by import (its class name starts with module , which no class has).

python.Lowering.moduleOf

Section titled “python.Lowering.moduleOf”

The module a value is, if it is one.

python.Lowering.holdsModule

Section titled “python.Lowering.holdsModule”

Whether the place holds a module.

python.Lowering.memberOf

Section titled “python.Lowering.memberOf”

module.attr for the module in a place: its member, or unsupported when the model does not have it.

python.Lowering.nameValue

Section titled “python.Lowering.nameValue”

A name’s value from its place: a module there is not taken as a value (only as module.member).

python.Lowering.importedPlace

Section titled “python.Lowering.importedPlace”

The place of a name import binds, when the expression is that name.

python.Lowering.moduleOr

Section titled “python.Lowering.moduleOr”

module.attr into result when the place (of a name import binds) holds a module, the general statement otherwise (the name was bound to something else); reading the name first (NameError before the import).

python.Lowering.name

Section titled “python.Lowering.name”

A name read: its slot, or the built-in it refers to (a CPython built-in the model does not provide stops the translation).

python.Lowering.isPlainBuiltin

Section titled “python.Lowering.isPlainBuiltin”

Whether a name is read as the built-in (the module does not bind it).

python.Lowering.constant

Section titled “python.Lowering.constant”

A constant’s value.

python.Lowering.operator

Section titled “python.Lowering.operator”

An operator’s symbol, its method and its reflected method.

python.Lowering.arithmetic

Section titled “python.Lowering.arithmetic”

The built-in operation of an operator (the data layer’s).

python.Lowering.formatsOperands

Section titled “python.Lowering.formatsOperands”

a op b on built-in values: printf-style formatting (str % b) shows b (its items) as text, noted by Run.shown (by repr, which %s of an object without a __str__ shows too).

python.Lowering.binary

Section titled “python.Lowering.binary”

result = a op b with the operands in places.

python.Lowering.containing

Section titled “python.Lowering.containing”

a in b (Exec.containsBy: a list’s or tuple’s items compared with the user’s __eq__ when they define it).

python.Lowering.identical

Section titled “python.Lowering.identical”

x is y: the same object, None, NotImplemented or bool (each one object); unsupported for numbers and strings (their identity is the implementation’s).

python.Lowering.comparison

Section titled “python.Lowering.comparison”

result = a op b for one comparison, the operands in places.

python.Lowering.input

Section titled “python.Lowering.input”

input(prompt): the prompt (a str, already made) written, then a line of the input without its newline; EOFError when the input has none left. A read that reaches the end of the input without a newline marks the console (atEnd): a debugger whose input is not closed waits for more there.

python.Lowering.made

Section titled “python.Lowering.made”

A list’s items, a tuple, a set or a dict from values.

python.Lowering.dict

Section titled “python.Lowering.dict”

A dict from keys and values in order.

python.Exec.method

Section titled “python.Exec.method”

result = receiver.name(*arguments, **keywords): the attribute’s value called (a user’s method bound to an instance, or any callable attribute), else a built-in type’s method.

python.Lowering.definedAt

Section titled “python.Lowering.definedAt”

The function defined at a node, in the symbol table.

python.Lowering.argName

Section titled “python.Lowering.argName”

An argument’s name.

python.Lowering.parameterNames

Section titled “python.Lowering.parameterNames”

The parameters’ names in Calls.bind’s order: positional (positional-only first), keyword-only, *args, **kwargs.

python.Lowering.ownName

Section titled “python.Lowering.ownName”

A function’s own name (<lambda> for a lambda).

python.Lowering.scopedName

Section titled “python.Lowering.scopedName”

A function’s name in its scope: a method’s has its class’s name before it.

python.Lowering.enclosing

Section titled “python.Lowering.enclosing”

The function a function is in (within fuel): not a list, set or dict comprehension’s, which CPython runs in place (a generator expression’s is a function of its own).

python.Lowering.qualname

Section titled “python.Lowering.qualname”

A function’s __qualname__: the enclosing functions’ names with .<locals>. between (a generator expression’s scope adds only a dot, as CPython’s compiler does for a comprehension’s), within fuel.

python.Lowering.tableName

Section titled “python.Lowering.tableName”

A function’s name in the program’s table: its qualified name, a mark (code 1, which the messages cut at) and its number, so that two functions of the same name differ.

python.Lowering.signature

Section titled “python.Lowering.signature”

A function’s signature for Calls.bind.

python.Lowering.layout

Section titled “python.Lowering.layout”

Where a function’s names live: its parameters (in Calls.bind’s order), then its free variables (the cells its value captured), then its other locals; a variable a nested function captures is a cell. The second is the count.

python.Lowering.cellsMade

Section titled “python.Lowering.cellsMade”

A function’s own cells made on entry: a parameter’s cell holds the argument, any other is empty.

python.Lowering.cellRef

Section titled “python.Lowering.cellRef”

The reference of a cell a new function captures (its place in the current scope must be a cell).

python.Lowering.madeFunction

Section titled “python.Lowering.madeFunction”

A function value made at its definition: its table name, the cells it captures, its defaults (already in temporaries: positional, then the keyword-only ones that have one).

python.Lowering.read

Section titled “python.Lowering.read”

A name’s read when it is not a built-in shortcut (the module binds it).

python.Lowering.forcedStop

Section titled “python.Lowering.forcedStop”

A step that always stops the debugger at a node (marked with the code 1; python.debugging).

python.Lowering.leavingStops

Section titled “python.Lowering.leavingStops”

A comprehension run in place, where an exception leaving it stops the debugger at it once more (CPython’s cleanup of the comprehension’s variables is on its line) and goes on out.

python.Lowering.special

Section titled “python.Lowering.special”

The built-ins whose calls are statements here (they may run the user’s methods, or use the console): print (with sep and end), len, str, repr and bool of one argument, input of none or one; none for any other name or shape.

python.Lowering.stepping

Section titled “python.Lowering.stepping”

The built-ins that take items one by one as for does (a generator’s included): any and all of one argument, stopping at the first item that decides; next of one or two (the default).

python.Lowering.consumes

Section titled “python.Lowering.consumes”

The built-ins that take all the items of their first argument (min and max only when it is their only argument): it is gathered into a list first when taking its items runs a user’s code (Exec.gathered).

python.Lowering.gathering

Section titled “python.Lowering.gathering”

The first argument gathered (when it should be, by the run’s check; its length hint taken first when hinted, Exec.gathered), and the arguments with the gathered one first.

python.Lowering.concatenated

Section titled “python.Lowering.concatenated”

Texts joined (an f-string’s parts).

python.Lowering.formatting

Section titled “python.Lowering.formatting”

format(value, spec) with the value and the spec (none for no spec) in places.

python.Lowering.isSuper

Section titled “python.Lowering.isSuper”

Whether an expression is super() with no arguments.

python.Lowering.superCall

Section titled “python.Lowering.superCall”

super().attr(*args, **keywords) in a method: the attribute found after the method’s class along the order of the first parameter’s class, bound to it (Objects.super), then called.

python.Lowering.formattedFrom

Section titled “python.Lowering.formattedFrom”

A formatted value of an f-string from its value and spec (in temporaries): the conversion (!s, !r; !a not yet), the methods its str needs run, then format(value, spec).

python.Lowering.keywordAt

Section titled “python.Lowering.keywordAt”

A keyword argument’s place, by name.

python.Lowering.numeric

Section titled “python.Lowering.numeric”

Whether a value is a number sum’s fast paths take (an int, a float or a bool).

python.Lowering.summed

Section titled “python.Lowering.summed”

sum(iterable, start) when the start or an item is a user’s object with __add__ or __radd__: as CPython, the numbers before the first other item summed by the built-in’s fast paths (a number start), then each item after added with + (the user’s methods run); any other sum is the built-in’s (general).

python.Lowering.sumShape

Section titled “python.Lowering.sumShape”

Whether sum is called as sum(iterable), sum(iterable, start) or sum(iterable, start=s).

python.Lowering.ordered

Section titled “python.Lowering.ordered”

sorted(xs, key=f, reverse=r), min(..., key=f, default=d) and max: the items in a list (an iterable’s taken as for takes them; several arguments’ as they are), their keys (the key function called on each, as CPython does before comparing; the items themselves for none or None), then the items by their keys (python.sorting: the user’s comparisons when the keys define them, else the built-in’s).

python.Lowering.takesOrder

Section titled “python.Lowering.takesOrder”

Whether sorted, min or max is called in a shape taken here: sorted of one argument with key and reverse, min and max with key and (of one argument) default.

python.Lowering.listSort

Section titled “python.Lowering.listSort”

xs.sort(key=f, reverse=r) when xs is a list (Sorting.listSort), the method called otherwise (general).

python.Lowering.lazyCall

Section titled “python.Lowering.lazyCall”

map(f, *iterables), filter(f, iterable), zip(*iterables) and enumerate(iterable) called by name: each iterable’s iterator taken first (Exec.iterate: a user’s __iter__ runs now, as CPython takes them when it is called), then the built-in generator (python.lazy); zip and enumerate over iterables whose items do not run a user’s code are the built-in iterators (general). Other shapes are the built-in’s (none).

python.Lowering.generatorOnly

Section titled “python.Lowering.generatorOnly”
