python.Codes

Section titled “python.Codes”

Text as Python sees it: its code points.

python.Codes.of

Section titled “python.Codes.of”

A string’s code points.

python.Codes.toString

Section titled “python.Codes.toString”

The string of code points.

python.Codes.startsWith

Section titled “python.Codes.startsWith”

Whether code points start with others.

python.Value

Section titled “python.Value”

A Python value. functionValue is a function by name with its captured cells (a built-in’s name starts with “builtin “); boundValue is a method bound to its object; notImplementedValue is NotImplemented (an operator method declining).

python.Slot

Section titled “python.Slot”

A slot of a set’s hash table: never used, used once and emptied (a dummy), or holding an item with its hash.

python.SetTable

Section titled “python.SetTable”

A set’s items: CPython’s hash table (its slots, how many hold items, how many hold items or dummies, and the implementation’s choices its order depends on: str.hash for a str’s hash, taken as under PYTHONHASHSEED=0, and object.address for an object’s, from the model’s addresses), or, when an item’s hash is not one the model gives, the items in the order they were added.

python.Iterating

Section titled “python.Iterating”

What an iterator walks: a list (forward or backward, as the list is now), the items of a tuple, str or reversed sequence (its type name), a range, a dict’s keys, values or items or a set (with the size they had and, for a dict, its keys then, to notice changes), an enumerate (its iterator and the next count), or a zip (its iterators and whether it is strict).

python.Object

Section titled “python.Object”

An object on the heap. A dict keeps its pairs in insertion order and a set its items in a SetTable; a view is a dict’s keys, values or items as the dict is now (its kind is its type name; it holds the dict’s address); an iterator walks what Iterating says, at a position; an instance has its class and attributes in order, and the text __repr__ and __str__ gave before printing; a class has its name, its method resolution order without itself, its attributes in order and the built-in exception class it derives from (empty when none); a wrapper is a staticmethod, classmethod or property (a property’s getter and setter, None when absent); a generator has its function, its next state, its locals while paused and whether it is done.

python.Iterating.typeName

Section titled “python.Iterating.typeName”

An iterator’s type name in CPython.

python.Slot.item

Section titled “python.Slot.item”

The item a slot holds, if any.

python.SetTable.items

Section titled “python.SetTable.items”

A set’s items in the order iterating gives them: the slots’ order, or the order they were added.

python.Names.joined

Section titled “python.Names.joined”

Names joined, each once, in the order first seen.

python.SetTable.chosen

Section titled “python.SetTable.chosen”

The implementation’s choices a set’s order depends on.

python.SetTable.choosing

Section titled “python.SetTable.choosing”

A table whose order also depends on more choices (built from a table that did).

python.Heap

Section titled “python.Heap”

The heap: objects by address.

python.Heap.empty

Section titled “python.Heap.empty”

An empty heap.

python.Heap.object

Section titled “python.Heap.object”

The object at an address, if there is one.

python.Value.ofString

Section titled “python.Value.ofString”

A str value.

python.Value.ofDecimal

Section titled “python.Value.ofDecimal”

A float literal m * 10^e, correctly rounded to binary64 (0.1 is m = 1, e = -1).

python.Value.negativeZero

Section titled “python.Value.negativeZero”

Negative zero (-0.0).

python.Raised

Section titled “python.Raised”

A raised exception: the classes it is an instance of (its own first, then its bases), its message, for an instance of a user’s class its object on the heap, and the node of the statement that raised it (empty until the statement fills it in).

python.Raised.named

Section titled “python.Raised.named”

A built-in exception of a type with a message, raised.

python.Raised.unsupportedType

Section titled “python.Raised.unsupportedType”

The class name of what the model cannot do (a space first, so no program’s class has it): a run stops with it and the verdict is unknown, not Python’s behavior.

python.Raised.unsupported

Section titled “python.Raised.unsupported”

What the model cannot do, raised (for example calling a user’s __eq__ while comparing containers).

python.Raised.type

Section titled “python.Raised.type”

The exception’s own class.

python.Outcome

Section titled “python.Outcome”

What evaluating gives: a value, or an exception raised.

python.Outcome.raise

Section titled “python.Outcome.raise”

Raising a built-in exception of a type with a message.

python.Exceptions.parent

Section titled “python.Exceptions.parent”

The base of a built-in exception class (CPython’s Objects/exceptions.c); none for BaseException.

python.Exceptions.derivesWithin

Section titled “python.Exceptions.derivesWithin”

Whether a built-in exception class is k or derives from it, within fuel steps up the hierarchy.

python.Exceptions.isSubclass

Section titled “python.Exceptions.isSubclass”

Whether except k catches a built-in exception of a type: the type is k or derives from it (the hierarchy is at most five deep).

python.Range.length

Section titled “python.Range.length”

How many values a range gives: none when it is empty (or the step is zero).

python.Value.className

Section titled “python.Value.className”

The name of a class value (a built-in class’s is its name; a user’s is on the heap).

python.Value.generatorType

Section titled “python.Value.generatorType”

A generator’s type name: a built-in generator’s is its function’s name (builtin map is a map).

python.Object.typeName

Section titled “python.Object.typeName”

The type name of an object on the heap.

python.Value.typeName

Section titled “python.Value.typeName”

type(x).__name__.

python.Heap.dictAt

Section titled “python.Heap.dictAt”

The pairs of the dict at an address (none for anything else).

python.Heap.viewItems

Section titled “python.Heap.viewItems”

What a view of a dict holds now: its keys, values or items (as 2-tuples), by the view’s type name.

python.Object.truthy

Section titled “python.Object.truthy”

bool(x) of an object on the heap: an empty list, dict, set or view is false; anything else is true.

python.Value.truthy

Section titled “python.Value.truthy”

bool(x): None, False, zero, an empty str, tuple, range or container is false; anything else is true.
