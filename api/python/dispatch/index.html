dispatch

python.Value.special

Section titled “python.Value.special”

A user’s special method of a value, bound to it: looked up on its class along the order (not the instance’s own attributes, as CPython does); none for anything but an instance of a user’s class.

python.Value.hasSpecial

Section titled “python.Value.hasSpecial”

Whether a value’s class has a special method.

python.Exec.steps

Section titled “python.Exec.steps”

Statements in order.

python.Exec.when

Section titled “python.Exec.when”

A statement run when a test of the run holds.

python.Exec.put

Section titled “python.Exec.put”

A value into a place.

python.Exec.flag

Section titled “python.Exec.flag”

A truth of the run into a place, as a bool.

python.Exec.choose

Section titled “python.Exec.choose”

One of two statements by a test of the run.

python.Run.declined

Section titled “python.Run.declined”

Whether a place holds NotImplemented.

python.Run.holds

Section titled “python.Run.holds”

Whether a place holds a true value.

python.Exec.special

Section titled “python.Exec.special”

result = receiver.name(*arguments) for a special method the receiver’s class has (the arguments read from places), run as a call.

python.Dispatch.reflectedFirst

Section titled “python.Dispatch.reflectedFirst”

Whether the right operand’s reflected method goes first: its class is a user’s, a proper subclass of the left’s, with that method.

python.Dispatch.tryReflected

Section titled “python.Dispatch.tryReflected”

Whether the right operand’s reflected method is tried after the left’s: always for a comparison, for arithmetic when the classes differ.

python.Exec.binary

Section titled “python.Exec.binary”

result = a op b with the user’s methods (method, its reflected reflected), then the built-in operation base when every method gave NotImplemented; the operands in the places left and right, whether the reflected method went first in the place first.

python.Value.sameObject

Section titled “python.Value.sameObject”

Whether two values are the same object (is).

python.Dispatch.equal

Section titled “python.Dispatch.equal”

The built-in == after the user’s methods: identity when either defines __eq__ (they gave NotImplemented), else equality by contents.

python.Dispatch.order

Section titled “python.Dispatch.order”

The built-in ordering after the user’s methods: TypeError when either defines a comparison (they gave NotImplemented), else the order of the data layer.

python.Exec.notEqual

Section titled “python.Exec.notEqual”

result = a != b: __ne__ (both ways), else not (a == b) with __eq__.

python.Exec.unary

Section titled “python.Exec.unary”

result = op a (-a, +a, ~a, abs(a)): the user’s method, else the built-in operation.

python.Dispatch.length

Section titled “python.Dispatch.length”

What __len__ gave, checked: a non-negative int (a bool counts as one), else ValueError or TypeError.

python.Exec.length

Section titled “python.Exec.length”

result = len(a): the user’s __len__ (checked), else the built-in length.

python.Dispatch.boolean

Section titled “python.Dispatch.boolean”

What __bool__ gave, checked: a bool, else TypeError.

python.Exec.truth

Section titled “python.Exec.truth”

result = bool(a) (the truth if, while, not, and and or use): __bool__ (checked), else __len__ (checked, true when not zero), else the built-in truth.

python.Expr.ofChanged

Section titled “python.Expr.ofChanged”

A change of the heap computed from the run, as an expression.

python.Expr.ofOutcome

Section titled “python.Expr.ofOutcome”

An outcome computed from the run, as an expression.

python.Dispatch.unsupported

Section titled “python.Dispatch.unsupported”

Unsupported: what CPython would do by running a user’s method in a way the model does not take.

python.Exec.contains

Section titled “python.Exec.contains”

result = x in c: the user’s __contains__ (its truth), else the data layer’s.

python.Exec.containsBy

Section titled “python.Exec.containsBy”

x in c for a list or tuple when x or an item defines comparison methods, as CPython’s list.__contains__: each item in turn (the list as it is then), true at the first that is x or equals it (item == x: the item’s __eq__, then the reflected one); else Exec.contains. The places after result are the loop’s and the comparison’s.

python.Expr.forKey

Section titled “python.Expr.forKey”

An expression looking a key up: a KeyError it raises shows the key’s repr (Run.raisedForKeys).

python.Exec.getItem

Section titled “python.Exec.getItem”

result = c[k]: the user’s __getitem__, else the data layer’s.

python.Exec.setItem

Section titled “python.Exec.setItem”

c[k] = v (the value first, then the container and the key, as CPython evaluates them): the user’s __setitem__ (its result into the scratch place), else the data layer’s.

python.Exec.deleteItem

Section titled “python.Exec.deleteItem”

del c[k]: the user’s __delitem__ (its result into the scratch place), else the data layer’s.

python.Dispatch.isIterator

Section titled “python.Dispatch.isIterator”

Whether a value is an iterator: a user’s object with __next__, or a built-in iterator or generator.

python.Dispatch.iterator

Section titled “python.Dispatch.iterator”

What __iter__ gave, checked: an iterator, else TypeError.

python.Dispatch.builtinIterator

Section titled “python.Dispatch.builtinIterator”

A built-in iterator over a value (unsupported for a user’s object iterated by __getitem__ alone).

python.Exec.iterate

Section titled “python.Exec.iterate”

iterator = iter(iterable): the user’s __iter__ (checked), else the built-in iterator.

python.Exec.advance

Section titled “python.Exec.advance”

The next item into its slot, or the end marked in the flag: a generator resumed (Exec.resume), the user’s __next__ (StopIteration is the end; the try needs its own flag place), else the built-in iterator’s.

python.Exec.forEachFrom

Section titled “python.Exec.forEachFrom”

The rounds of for over the iterator already in iterator (Exec.forEach without taking iter first).

python.Exec.forEach

Section titled “python.Exec.forEach”

for target in iterable: body else: otherwise with the user’s iteration methods (Exec.forLoop is the built-in iteration alone).

python.Dispatch.lengthHint

Section titled “python.Dispatch.lengthHint”

What __length_hint__ gave, checked: NotImplemented (no hint) or a non-negative int, else ValueError or TypeError.

python.Exec.lengthHint

Section titled “python.Exec.lengthHint”

How many items an iterable says it has before list takes them (CPython’s PyObject_LengthHint, in result): a user’s __len__ (checked; a TypeError, raised in it or by the check, is dropped), else a user’s __length_hint__; nothing for the built-in values, whose lengths run no code.

python.Exec.gathered

Section titled “python.Exec.gathered”

An iterable that runs a user’s code or uses up an iterator (a generator, say) gathered into a new list in into, its items taken as for takes them (each followed by round; after iter, its length hint first when hinted, as list and list.extend take it), for a built-in that takes them all (list, sum); any other value put there as it is.

python.Exec.takeRunning

Section titled “python.Exec.takeRunning”

Items of an iterable that runs a user’s code (a generator, a user’s iteration) taken as for takes them into a new list in items: at most limit of them (all with none), the iterator’s length hint once hintAfter are taken (as list takes the rest of a starred unpacking).

python.Unpack.counted

Section titled “python.Unpack.counted”

Items taken for unpacking into a count of targets (at most one more than the count, as CPython takes them from an iterator): ValueError for too few, or for one too many.

python.Unpack.splitAtLeast

Section titled “python.Unpack.splitAtLeast”

Items taken for a, *b, c = v: before items, the rest as a new list, after items; ValueError when there are fewer than before and after together.

python.Exec.unpackRunning

Section titled “python.Exec.unpackRunning”

a, b = v for an iterable that runs a user’s code: at most one item more than the targets taken (Exec.takeRunning), then the targets from them.

python.Exec.unpackRunningStarred

Section titled “python.Exec.unpackRunningStarred”

a, *b, c = v for an iterable that runs a user’s code: all its items taken (the iterator’s length hint after the targets before the star), then the targets from them.

python.Exec.anyAll

Section titled “python.Exec.anyAll”

any(iterable) (all false) and all(iterable) (all true) into result: the items taken one by one as for takes them, stopping at the first that decides (round after each that does not).

python.Exec.raiseStop

Section titled “python.Exec.raiseStop”

StopIteration raised with a value (a generator’s return value, in a place): an instance whose args are the value (none for None) and whose value is it, as CPython makes it.

python.Exec.nextOf

Section titled “python.Exec.nextOf”

next(iterator) and next(iterator, default) into result, as for takes an item (Exec.advance); when there is none, the default, or StopIteration (with a generator’s return value).

python.Exec.resumeMethod

Section titled “python.Exec.resumeMethod”

A generator’s send(value) (how 0), throw(value) (how 1) and close() (how 2) into result (Exec.resume): what it yields; when it ends, send and throw raise StopIteration with its return value.

python.Raised.isAttributeError

Section titled “python.Raised.isAttributeError”

Whether an exception is an AttributeError.

python.Exec.attribute

Section titled “python.Exec.attribute”

result = object.name, with the user’s __getattr__ for an attribute the object does not have.

python.Exec.assignAttribute

Section titled “python.Exec.assignAttribute”

object.name = value (the value first), with the user’s __setattr__ when the class has one.

python.Dispatch.targets

Section titled “python.Dispatch.targets”

The methods a value’s text needs, as a tuple of (instance, bound method, whether it is __str__) triples.

python.Dispatch.firstTarget

Section titled “python.Dispatch.firstTarget”

The first of the targets still to run, as a Showing.

python.Exec.resolve

Section titled “python.Exec.resolve”

Runs the methods a value’s text needs (__str__ at the top when top holds, __repr__ inside), in order, their texts kept on the instances (TypeError for a method that does not return a str); the targets still to run in the place pending, each method’s result in the place result.

python.Exec.text

Section titled “python.Exec.text”

result = str(a) or repr(a): the methods it needs run first, then the built-in text.

python.Dispatch.textOption

Section titled “python.Dispatch.textOption”

TypeError unless a value is None or a str (print’s sep and end).

python.Exec.printChecked

Section titled “python.Exec.printChecked”

The checks of print’s options (the tuple of sep and end in a place): each None or a str, else TypeError.

python.Exec.printAt

Section titled “python.Exec.printAt”

One of print’s values written (at a position of the tuple in arguments, the position from the run): the separator first unless it is the first (a space for a None sep), its str (the user’s __str__ run), the text.

python.Exec.printEnd

Section titled “python.Exec.printEnd”

print’s end written.

python.Exec.print

Section titled “python.Exec.print”

print(values, sep=, end=): the values and the options in tuples, the options checked, each value written.

python.Run.position

Section titled “python.Run.position”

A natural number kept in a place (a counter).

python.Exec.printFrom

Section titled “python.Exec.printFrom”

print of values gathered at run time (print(*xs)): the tuple in arguments and the options’ tuple in options already there; each value written in turn, its position counted in index.

python.Dispatch.calleeName

Section titled “python.Dispatch.calleeName”

What a call’s TypeError names: a user’s function or class as __main__. and its qualified name, a built-in by its name, a bound method by its function.

python.Dispatch.unpackable

Section titled “python.Dispatch.unpackable”

Whether *v can be unpacked in a call: it is iterable (__iter__) or a sequence (__getitem__).

python.Exec.typeError

Section titled “python.Exec.typeError”

A TypeError raised with a message from the run.

python.Exec.appendTo

Section titled “python.Exec.appendTo”

A value appended to the list in a place.

python.Exec.unpackInto

Section titled “python.Exec.unpackInto”

*iterable: its items appended to the list in items as for takes them (after iter, its length hint first when hinted, as a list or tuple display takes it); when it cannot be unpacked, TypeError with the message given (or, with none, the one iter raises).

python.Exec.spreadItems

Section titled “python.Exec.spreadItems”

*iterable among a call’s arguments (Exec.unpackInto), the TypeError naming the callee.

python.Exec.mergeInto

Section titled “python.Exec.mergeInto”

**mapping in a dict display: a dict’s pairs stored into the dict in into (a later key replacing an earlier one); a user’s mapping is not taken yet; TypeError for anything else.

python.Dispatch.keyword

Section titled “python.Dispatch.keyword”

A keyword argument added to the pairs gathered so far (the callee for the message): TypeError when the key is not a str, or when the call already has it.

python.Dispatch.keywords

Section titled “python.Dispatch.keywords”

Keyword arguments added in order.

python.Run.namedAdded

Section titled “python.Run.namedAdded”

Keyword arguments added to the dict in named (an evaluation of the run, its exception when one is wrong).

python.Exec.namedItem

Section titled “python.Exec.namedItem”

name=value among a call’s arguments, added to the dict in named.

python.Exec.spreadNamed

Section titled “python.Exec.spreadNamed”

**mapping among a call’s arguments: a dict’s pairs added to the dict in named; a user’s mapping is not taken yet; TypeError (naming the callee) for anything else.

python.Exec.callGathered

Section titled “python.Exec.callGathered”

The call with the arguments gathered at run time: the list’s items positional, the dict’s pairs as keywords.

python.Exec.keysOf

Section titled “python.Exec.keysOf”

The keys of a list’s items: the key function (a user’s or a built-in) called on each in turn, as CPython does before it compares, the results in a new list in keys.

python.Run.listed

Section titled “python.Run.listed”

A list’s items in order (a place’s).

python.Exec.byKeys

Section titled “python.Exec.byKeys”

sorted, min or max of the items in a list once their keys are in another (Builtins.byKeys), into result.
