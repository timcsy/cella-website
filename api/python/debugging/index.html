debugging

python.DebugRun

Section titled “python.DebugRun”

A run for the debugger: the machine’s configuration, the nodes it stops at (the program’s statements’), the statement node last entered at each depth of the user’s calls, and the node the last move entered (none when it entered none to stop at).

python.Debugging.internal

Section titled “python.Debugging.internal”

Whether a function or a node is the model’s own (CPython runs it in C): model sort, builtin map.<resume>, or one with no name.

python.Debugging.depth

Section titled “python.Debugging.depth”

How many of the user’s calls a configuration is in (the state’s depth: the model’s own functions do not count).

python.Debugging.markedWith

Section titled “python.Debugging.markedWith”

Whether a label is marked with a code first.

python.Debugging.forced

Section titled “python.Debugging.forced”

Whether a label is marked to always stop (the code 1 first).

python.Debugging.resumed

Section titled “python.Debugging.resumed”

Whether a label only tells the statement a resumed generator goes on with (the code 2 first).

python.Debugging.nodeOf

Section titled “python.Debugging.nodeOf”

A label’s node, without the mark.

python.Debugging.lastAt

Section titled “python.Debugging.lastAt”

The node last entered at a depth (the remembered nodes are the deepest first, none deeper than it).

python.Debugging.remember

Section titled “python.Debugging.remember”

The remembered nodes (none deeper than the depth) with the node at the depth.

python.Debugging.atLabel

Section titled “python.Debugging.atLabel”

Whether a configuration is at a label.

python.Debugging.lineOf

Section titled “python.Debugging.lineOf”

A node’s line in the host’s table.

python.Debugging.sameLine

Section titled “python.Debugging.sameLine”

Whether two nodes are on the same line in the host’s table (not when either has none).

python.Debugging.position

Section titled “python.Debugging.position”

A node’s position among the program’s statements (in the order of its syntax tree).

python.Debugging.moved

Section titled “python.Debugging.moved”

Whether going from the statement last entered at a depth to another moves to a new line, as CPython’s line event does: without the host’s table of lines, every other statement does; with it, one on another line, or one before it (a loop going back).

python.Debugging.entering

Section titled “python.Debugging.entering”

A run after a move to y: the node y is about to enter, if it is one to stop at. A marked step stops when the move reaches it (not again on the move inside it) and leaves the node remembered at its depth as it was: the statement around it goes on without stopping again. A statement on the line of the one before it is remembered without stopping (Debugging.moved).

python.Debugging.step

Section titled “python.Debugging.step”

One move.

python.Debugging.stoppable

Section titled “python.Debugging.stoppable”

The nodes a program stops at: its statements’ (the functions the translation makes of its comprehensions and generator expressions stop only at their marked steps, python.symbols).

python.Debugging.start

Section titled “python.Debugging.start”

A run of a program from its start, stopping at its statements.

python.Debugging.state

Section titled “python.Debugging.state”

The state of a run (none when it stopped without one).

python.Debugging.atEnd

Section titled “python.Debugging.atEnd”

Whether a run’s last read reached the end of the input without a whole line.

python.Debugging.blocked

Section titled “python.Debugging.blocked”

Whether a move from x to y waits for input: the input is not closed and the move reached its end.

python.Debugging.halt

Section titled “python.Debugging.halt”

How a finished run ends for the debugger: an uncaught exception, the end, or (what the model cannot do, or a stop) a behavior it does not specify.

python.Debugging.machine

Section titled “python.Debugging.machine”

The Python model’s machine for the debugger driver.

python.Debugging.stepsFrom

Section titled “python.Debugging.stepsFrom”

The nodes a run stops at stepping in from its start to its end (at most count stops, each within fuel moves); the input given at the start and closed.

python.Debugging.stopsOf

Section titled “python.Debugging.stopsOf”

The nodes a program (its syntax tree’s JSON) stops at, stepping in from its start (one starting with ? when it cannot run).

python.Debugging.lineTable

Section titled “python.Debugging.lineTable”

A host’s table of the lines of nodes (JSON: an object from a node to its line); empty for text it cannot read.

python.Debugging.stopsWithLines

Section titled “python.Debugging.stopsWithLines”

The nodes a program stops at with the host’s table of lines (JSON), stepping in from its start.

python.Debugging.stops

Section titled “python.Debugging.stops”

The nodes a program stops at, stepping in from its start, one per line.
