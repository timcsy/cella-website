arduino

arduino.Board.avrLibraries

Section titled “arduino.Board.avrLibraries”

The libraries of the AVR boards, by the header a sketch includes: the AVR core’s own and the ones the earlier model knew (LiquidCrystal_I2C), each its parts.

arduino.Board.espLibraries

Section titled “arduino.Board.espLibraries”

The libraries of the ESP boards, by the header a sketch includes: DHT (its timing not measured there: a sketch that makes one is judged unknown).

arduino.Board.esp32Libraries

Section titled “arduino.Board.esp32Libraries”

The libraries of the ESP32 boards only, by the header a sketch includes: WiFi (the station’s states as STA.cpp’s) and EEPROM (over NVS: arduino-esp32’s library, not the ESP8266’s).

arduino.Board.esp8266Libraries

Section titled “arduino.Board.esp8266Libraries”

The libraries of the ESP8266 boards only, by the header a sketch includes: EEPROM (a flash sector: the ESP8266 core’s library).

arduino.Board.libraries

Section titled “arduino.Board.libraries”

Every library, on the boards it is for.

arduino.Board.named

Section titled “arduino.Board.named”

The board of a name, with every library.

arduino.Item.namesIn

Section titled “arduino.Item.namesIn”

The program’s declarations with their names (a device’s input names its variable).

arduino.Board.unknownReason

Section titled “arduino.Board.unknownReason”

Why a program’s board is not one of the boards: it names none, or one that is unknown.

arduino.Board.withoutInputs

Section titled “arduino.Board.withoutInputs”

An object’s fields without its "inputs".

arduino.Board.sketch

Section titled “arduino.Board.sketch”

A program for a board as JSON and the host’s inputs it carries: the program’s object may have "inputs", the inputs over time ([{t, key, value}], times in milliseconds), which are the run’s environment, not the program’s syntax; without it there are none.

arduino.withInputs

Section titled “arduino.withInputs”

A program’s JSON with the host’s inputs ([{t, key, value}]) as its "inputs", replacing any it had (unchanged when either is not JSON or the program is not an object): for a host written in Cella; a host in JavaScript sets the field.

arduino.verdict

Section titled “arduino.verdict”

The verdict JSON of a program for a board given as JSON (with the host’s inputs it carries), run on an input for at most fuel steps.

arduino.Board.queryError

Section titled “arduino.Board.queryError”

A type query’s error as JSON.

arduino.QueryResult.ofSketch

Section titled “arduino.QueryResult.ofSketch”

A query’s answers about the sketch’s own nodes (not the board’s items, which are the library’s).

arduino.types

Section titled “arduino.types”

The type query JSON of a program for a board given as JSON, with the candidate types as a JSON array of strings: the sketch checked after the board’s items, as it runs; the nodes are the sketch’s.

arduino.Board.isPublicName

Section titled “arduino.Board.isPublicName”

Whether a name is the library’s own (an internal one starts with an underscore).

arduino.Board.everyItem

Section titled “arduino.Board.everyItem”

Every item a sketch on a board can use: the board’s, then each library’s (a part shared by several once).

arduino.Item.constantNames

Section titled “arduino.Item.constantNames”

The constants an item declares: a const global variable, the constants of an enumeration.

arduino.Item.globalObject

Section titled “arduino.Item.globalObject”

The global object an item declares and its class’s name, if it declares one.

arduino.Member.isConstructor

Section titled “arduino.Member.isConstructor”

Whether a class has a constructor of its own (a class a sketch declares objects of).

arduino.Item.constructedClass

Section titled “arduino.Item.constructedClass”

The class an item defines, if it has a constructor of its own.

arduino.Board.distinct

Section titled “arduino.Board.distinct”

Names not seen yet, each once, in order.

arduino.Board.publicNames

Section titled “arduino.Board.publicNames”

Names without the library’s own, each once, in order.

arduino.Board.listOf

Section titled “arduino.Board.listOf”

What an option holds, as a list of none or one.

arduino.Board.info

Section titled “arduino.Board.info”

What a sketch on a board can name, as JSON: the constants, the serial ports (HardwareSerial objects), the other global objects, and the classes with constructors (from the board’s items and every library it may include).

arduino.boardInfo

Section titled “arduino.boardInfo”

What a sketch on a board of a name can name, as JSON (an error for an unknown board).

arduino.Session

Section titled “arduino.Session”

A debugging session of a sketch on a board: the board, its C++ dialect, the names of the sketch’s declarations (devices’ inputs are named by them) and the core’s session.

arduino.Stopping

Section titled “arduino.Stopping”

Where the debugger stopped.

arduino.Session.unloaded

Section titled “arduino.Session.unloaded”

A session that cannot run: the reason it did not check (on the Uno, whose dialect reads nothing).

arduino.load

Section titled “arduino.load”

A session for a program given as JSON: a sketch for one of the boards (with the host’s inputs it carries), checked once after the board’s items.

arduino.Session.withCore

Section titled “arduino.Session.withCore”

The core’s session replaced.

arduino.run

Section titled “arduino.run”

Runs to the next stop: kind 0 continue, 1 step in, 2 step over, 3 step out; closed 1 when no more input comes.

arduino.stopConf

Section titled “arduino.stopConf”

The session resumed from a stop (unchanged when the run cannot go on).

arduino.stopKind

Section titled “arduino.stopKind”

Which kind of stop it is (the debugging host reads this, not the constructor).

arduino.stopNode

Section titled “arduino.stopNode”

The node a stop is at.

arduino.stopOut

Section titled “arduino.stopOut”

The output so far at a stop.

arduino.stopErr

Section titled “arduino.stopErr”

The error output so far at a stop.

arduino.stopDetail

Section titled “arduino.stopDetail”

A stop’s details as JSON (the reasons are the C++ branch’s, which the board’s dialect shares).

arduino.divergences

Section titled “arduino.divergences”

The divergences from the standard recorded so far, as JSON.

arduino.stopVisits

Section titled “arduino.stopVisits”

How many times the run to this stop entered each node, as JSON {"<node>": n} (the debugging host adds them up for a session’s coverage).

arduino.report

Section titled “arduino.report”

A run to its end with all the input given at once (and closed), as JSON: the stop’s kind, node, output and details.

arduino.feed

Section titled “arduino.feed”

More input.

arduino.globals

Section titled “arduino.globals”

The global variables as JSON.

arduino.frames

Section titled “arduino.frames”

The calls, stopped at a node, as JSON.

arduino.setVarErr

Section titled “arduino.setVarErr”

Why an integer variable of the n-th call cannot be set from text (empty when it can).

arduino.setVarConf

Section titled “arduino.setVarConf”

The session with an integer variable of the n-th call set from text (unchanged when it cannot be).

arduino.Session.environment

Section titled “arduino.Session.environment”

The board’s environment in a paused run (none once it ended).

arduino.env

Section titled “arduino.env”

The hardware the host shows (the wiring panel’s JSON), null once the run ended.

arduino.clockMs

Section titled “arduino.clockMs”

The simulated time of a paused run in milliseconds (0 once it ended).

arduino.Configuration.withEnvironment

Section titled “arduino.Configuration.withEnvironment”

A paused run’s configuration with its environment changed (unchanged once it ended).

arduino.setInput

Section titled “arduino.setInput”

The session with an input changed while paused, from now on (a key as verdict reads it, the value a number); unchanged when the value is not one or the run ended.
