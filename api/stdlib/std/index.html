Nat

Section titled “Nat”

The unary natural numbers: zero and successor.

Nat.add

Section titled “Nat.add”

Natural-number addition, by recursion on the first argument.

Nat.mul

Section titled “Nat.mul”

Natural-number multiplication, as repeated addition on the first argument.

Nat.sub

Section titled “Nat.sub”

Truncated natural-number subtraction: m - n, or zero when n exceeds m.

Bool

Section titled “Bool”

The booleans true and false.

Bool.and

Section titled “Bool.and”

Boolean conjunction.

Bool.leftOfAnd

Section titled “Bool.leftOfAnd”

The left side of a true conjunction is true.

Bool.rightOfAnd

Section titled “Bool.rightOfAnd”

The right side of a true conjunction is true.

Bool.andOfBoth

Section titled “Bool.andOfBoth”

Both sides of a conjunction true make it true.

Bool.or

Section titled “Bool.or”

Boolean disjunction.

Bool.not

Section titled “Bool.not”

Boolean negation.

Bool.dite

Section titled “Bool.dite”

If-then-else whose branches receive the proof of the condition (what termination_by turns an if into).

Nat.beq

Section titled “Nat.beq”

Boolean equality test on natural numbers.

Nat.blt

Section titled “Nat.blt”

Boolean strict less-than test on natural numbers: m < n.

Nat.ble

Section titled “Nat.ble”

Boolean less-than-or-equal test on natural numbers: m <= n.

Nat.bleOfBlt

Section titled “Nat.bleOfBlt”

Strictly less implies less or equal: m < n gives m <= n.

Nat.bgt

Section titled “Nat.bgt”

Boolean strict greater-than test on natural numbers: m > n.

Nat.divAuxFuel

Section titled “Nat.divAuxFuel”

Division by repeated subtraction with an accumulator q, bounded by fuel; stops when m < n, when n is zero, or when fuel runs out.

Nat.modAuxFuel

Section titled “Nat.modAuxFuel”

Remainder by repeated subtraction, bounded by fuel; returns m unchanged when n is zero.

Nat.div

Section titled “Nat.div”

Natural-number division m / n, rounding down; division by zero gives zero.

Nat.mod

Section titled “Nat.mod”

Natural-number remainder m mod n; the remainder modulo zero is m itself.

Nat.bge

Section titled “Nat.bge”

Boolean greater-than-or-equal test on natural numbers: m ≥ n.

Nat.bitwiseAndFuel

Section titled “Nat.bitwiseAndFuel”

Bitwise and of the lowest fuel bits of m and n.

Nat.bitwiseOrFuel

Section titled “Nat.bitwiseOrFuel”

Bitwise or of the lowest fuel bits of m and n.

Nat.bitwiseXorFuel

Section titled “Nat.bitwiseXorFuel”

Bitwise exclusive or of the lowest fuel bits of m and n.

Nat.bitwiseAnd

Section titled “Nat.bitwiseAnd”

Bitwise and of natural numbers.

Nat.bitwiseOr

Section titled “Nat.bitwiseOr”

Bitwise or of natural numbers.

Nat.bitwiseXor

Section titled “Nat.bitwiseXor”

Bitwise exclusive or of natural numbers.

Nat.min

Section titled “Nat.min”

The smaller of two natural numbers.

Nat.max

Section titled “Nat.max”

The larger of two natural numbers.

Nat.maxSucc

Section titled “Nat.maxSucc”

Successor distributes over max: succ (max j k) = max (succ j) (succ k).

Nat.maxComm

Section titled “Nat.maxComm”

Commutativity of max on natural numbers: max m n = max n m.

Option

Section titled “Option”

An optional value: nothing, or just a value of type A.

Option.withDefault

Section titled “Option.withDefault”

The value inside a Maybe, or the given default when it is nothing.

Option.isSome

Section titled “Option.isSome”

Boolean test for whether a Maybe holds a value.

Option.isNone

Section titled “Option.isNone”

Boolean test for whether a Maybe is nothing.

Option.map

Section titled “Option.map”

Apply a function to the value inside a Maybe, if any.

Pair

Section titled “Pair”

A pair of a value of type A and a value of type B.

keepType

Section titled “keepType”

Return the new value, constrained to have the same type as the old one; used to desugar assignment to a let mut variable.

Pair.fstPair

Section titled “Pair.fstPair”

The first component of a Pair.

Pair.sndPair

Section titled “Pair.sndPair”

The second component of a Pair.

Either

Section titled “Either”

A value that is either a left A or a right B.

Either.bimap

Section titled “Either.bimap”

One function applied to a left value, another to a right value.

Either.mapLeft

Section titled “Either.mapLeft”

A function applied to a left value; a right value stays.

Either.mapRight

Section titled “Either.mapRight”

A function applied to a right value; a left value stays.

Either.swapSides

Section titled “Either.swapSides”

The sides swapped: a left becomes a right and the other way round.

Either.isLeft

Section titled “Either.isLeft”

Whether it is a left value.

Either.isRight

Section titled “Either.isRight”

Whether it is a right value.

Either.fromLeft

Section titled “Either.fromLeft”

The value inside a left, or default for a right.

Either.fromRight

Section titled “Either.fromRight”

The value inside a right, or default for a left.

Either.fold

Section titled “Either.fold”

f of a left value, g of a right value.

List

Section titled “List”

Finite lists: nil, or an element consed onto a list.

List.map

Section titled “List.map”

Apply a function to every element of a list.

List.filter

Section titled “List.filter”

Keep the elements of a list that satisfy a boolean predicate.

List.append

Section titled “List.append”

Concatenate two lists.

List.length

Section titled “List.length”

The number of elements in a list.

List.listHead

Section titled “List.listHead”

The first element of a list, or the given default for an empty list.

List.listTail

Section titled “List.listTail”

A list without its first element; the empty list stays empty.

List.revAcc

Section titled “List.revAcc”

Reverse xs onto the front of the accumulator acc; the helper behind reverse.

List.reverse

Section titled “List.reverse”

Reverse a list.

List.foldl

Section titled “List.foldl”

Left fold: combine the elements from left to right, starting from z.

List.foldr

Section titled “List.foldr”

Right fold: combine the elements from right to left, ending with z.

List.take

Section titled “List.take”

The first n elements of a list (or the whole list if it is shorter).

List.drop

Section titled “List.drop”

A list without its first n elements.

List.replicate

Section titled “List.replicate”

A list of n copies of x.

List.rangeAcc

Section titled “List.rangeAcc”

The numbers 0 to n - 1 prepended to acc; the helper behind range.

List.range

Section titled “List.range”

The list of natural numbers 0, 1, …, n - 1.

Nat.addZeroR

Section titled “Nat.addZeroR”

Zero is a right identity for addition: m + 0 = m.

Nat.addSuccR

Section titled “Nat.addSuccR”

Successor in the right summand moves outside: m + succ n = succ (m + n).

Nat.addAssoc

Section titled “Nat.addAssoc”

Associativity of natural-number addition, right-nested to left-nested: m + (n + o) = (m + n) + o.

Bool.notnot

Section titled “Bool.notnot”

Boolean negation is an involution: not (not x) = x.

Bool.andTrue

Section titled “Bool.andTrue”

True is a right identity for conjunction: and a true = a.

Bool.orFalse

Section titled “Bool.orFalse”

False is a right identity for disjunction: or a false = a.

Bool.andFalse

Section titled “Bool.andFalse”

False absorbs conjunction on the right: and a false = false.

Bool.orTrue

Section titled “Bool.orTrue”

True absorbs disjunction on the right: or a true = true.

Bool.notTrue

Section titled “Bool.notTrue”

The negation of true is false.

Bool.notFalse

Section titled “Bool.notFalse”

The negation of false is true.

Nat.addZeroL

Section titled “Nat.addZeroL”

Zero is a left identity for addition: 0 + m = m.

Nat.addComm

Section titled “Nat.addComm”

Commutativity of natural-number addition: m + n = n + m.

List.appendNil

Section titled “List.appendNil”

The empty list is a right identity for append: append xs nil = xs.

Nat.subZero

Section titled “Nat.subZero”

Zero is a right identity for truncated subtraction: m - 0 = m.

Nat.mulZeroR

Section titled “Nat.mulZeroR”

Zero absorbs multiplication on the right: m * 0 = 0.

Nat.mulOneR

Section titled “Nat.mulOneR”

One is a right identity for multiplication: m * 1 = m.

Nat.addSwap

Section titled “Nat.addSwap”

Swap the first two summands of a right-nested sum: n + (k + x) = k + (n + x).

Nat.mulSuccR

Section titled “Nat.mulSuccR”

Multiplication by a successor adds one copy: m * succ n = m + m * n.

List.nthOption

Section titled “List.nthOption”

Returns the element at the given index, or none when the index is out of range.

List.headOption

Section titled “List.headOption”

The first element of a list, or none for an empty list.

List.zip

Section titled “List.zip”

Pair up corresponding elements of two lists, stopping at the shorter one.

List.zip3

Section titled “List.zip3”

Combine three lists elementwise into right-nested triples, stopping at the shortest.

List.enumerate

Section titled “List.enumerate”

Pair every element of a list with its index, counting from 0.

concat

Section titled “concat”

Flatten a list of lists into one list.

List.concatMap

Section titled “List.concatMap”

Map each element to a list and concatenate the results.

Monad

Section titled “Monad”

A monad: pure puts a value in, bind runs a computation and feeds its result to the next one. do blocks are written with these.

monadOption

Section titled “monadOption”

Maybe is a monad: bind stops at the first nothing.

monadEither

Section titled “monadEither”

Either E is a monad: bind stops at the first left.

monadList

Section titled “monadList”

List is a monad: bind maps each element to a list and concatenates the results.

LoopCtl

Section titled “LoopCtl”

Loop body result for loops using break or continue: continue with a state, or stop with a state.

LoopStep

Section titled “LoopStep”

Loop body result for loops using return: continue, break, or return a value early.

forInListM

Section titled “forInListM”

Expansion of for x in xs do ... in any monad: runs f on each element in order, threading a state through.

forInListCtlM

Section titled “forInListCtlM”

Like forInListM, for loops using break or continue.

forInListRM

Section titled “forInListRM”

Like forInListM, for loops using return: left v is an early return, right s the state at the end.

List.any

Section titled “List.any”

Whether some element of the list satisfies the predicate.

List.all

Section titled “List.all”

Whether every element of the list satisfies the predicate.

List.elemNat

Section titled “List.elemNat”
