map

Map

Section titled “Map”

An ordered finite map: a leaf, or a branch with its subtree’s size, an entry and the smaller and larger keys’ subtrees.

Split

Section titled “Split”

An entry taken out of a tree (its smallest or largest) and the tree that is left.

Map.Entry

Section titled “Map.Entry”

An entry: a key and its value.

Map.empty

Section titled “Map.empty”

The empty map.

Map.size

Section titled “Map.size”

The number of entries, in constant time.

Map.singleton

Section titled “Map.singleton”

The map with one entry.

Map.build

Section titled “Map.build”

A branch whose size is computed from its subtrees.

Map.rotateLeft

Section titled “Map.rotateLeft”

The branch of k over l and r turned left, when r is too heavy: once if r’s outer side is the heavier one, twice (through r’s inner side) otherwise.

Map.rotateRight

Section titled “Map.rotateRight”

The branch of k over l and r turned right, when l is too heavy (the mirror of rotateLeft).

Map.balance

Section titled “Map.balance”

The branch of k over l and r after one insertion or deletion, turned when one side outweighs the other three times.

Map.lookup

Section titled “Map.lookup”

The value at a key, if the key is there.

Map.contains

Section titled “Map.contains”

Whether a key is there.

Map.getOr

Section titled “Map.getOr”

The value at a key, or d when the key is not there.

Map.insertWith

Section titled “Map.insertWith”

The map with an entry inserted; when the key is already there, its value becomes f new old.

Map.insert

Section titled “Map.insert”

The map with an entry inserted, replacing the key’s value if it is already there.

Map.splitMin

Section titled “Map.splitMin”

The smallest entry of the branch of k over l and r, and the branch rebalanced without it.

Map.splitMax

Section titled “Map.splitMax”

The largest entry of the branch of k over l and r, and the branch rebalanced without it.

Map.join

Section titled “Map.join”

Two trees joined, every key of l smaller than every key of r: the new root is taken from the larger side.

Map.delete

Section titled “Map.delete”

The map without a key (unchanged when the key is not there).

Map.adjust

Section titled “Map.adjust”

The map with f applied to the value at a key (unchanged when the key is not there).

Map.foldRight

Section titled “Map.foldRight”

The entries folded from the largest key to the smallest: f key value rest.

Map.toList

Section titled “Map.toList”

The entries as key-value pairs, by ascending key.

Map.keys

Section titled “Map.keys”

The keys, ascending.

Map.values

Section titled “Map.values”

The values, by ascending key.

Map.fromList

Section titled “Map.fromList”

The map of key-value pairs; of pairs with the same key, the first one wins.

Map.mapValues

Section titled “Map.mapValues”

The map with f applied to every value; the keys and the shape stay.

Map.unionWith

Section titled “Map.unionWith”

The entries of both maps; a key in both gets f left right.

Map.depth

Section titled “Map.depth”

The height of the tree (for tests of the balance).

Map.before

Section titled “Map.before”

Whether a comes strictly before b.

Map.aboveLow

Section titled “Map.aboveLow”

Whether a key comes strictly after a lower bound, if there is one.

Map.belowHigh

Section titled “Map.belowHigh”

Whether a key comes strictly before an upper bound, if there is one.

Map.withinBounds

Section titled “Map.withinBounds”

Whether a key lies strictly between the bounds that are given.

Map.balancedBranch

Section titled “Map.balancedBranch”

Whether every branch records its size and is balanced (neither side outweighs the other three times).

Map.validWithin

Section titled “Map.validWithin”

Whether a tree is a valid weight-balanced search tree with every key strictly between the bounds that are given.

Map.valid

Section titled “Map.valid”

Whether a tree is a valid weight-balanced search tree: sizes recorded, keys ordered, branches balanced (for tests).
