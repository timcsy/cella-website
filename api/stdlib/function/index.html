function

idApply

Section titled “idApply”

Applying the identity function is a no-op: id a = a.

idApplyFn

Section titled “idApplyFn”

Post-composing a function with id gives back the function: (fun x => id (f x)) = f.

composeApply

Section titled “composeApply”

Composition unfolds pointwise: (g ∘ f) x = g (f x).

composeAssocFn

Section titled “composeAssocFn”

Function composition is associative: h ∘ (g ∘ f) = (h ∘ g) ∘ f.

composeIdLeft

Section titled “composeIdLeft”

The identity function is a left unit for composition: id ∘ f = f.

composeIdRight

Section titled “composeIdRight”

The identity function is a right unit for composition: f ∘ id = f.

flipApply

Section titled “flipApply”

Flip swaps the two arguments: flip f b a = f a b.

flipFlip

Section titled “flipFlip”

Flipping a function twice gives back the original function.

constApply

Section titled “constApply”

A constant function ignores its argument: const a b = a.

constComposeLeft

Section titled “constComposeLeft”

Composing a constant function after any f is still constant: (fun _ => c) ∘ f = fun _ => c.

constComposeRight

Section titled “constComposeRight”

Composing g after a constant function is constant at g b: g ∘ (fun _ => b) = fun _ => g b.

applyFn

Section titled “applyFn”

Function application via apply agrees with direct application: apply f x = f x.

applyId

Section titled “applyId”

Applying the identity function through apply returns the argument: apply id x = x.

isInjective

Section titled “isInjective”

The proposition that f is injective: equal images imply equal inputs.

isSurjective

Section titled “isSurjective”

The type saying f is surjective: every b in the codomain has a chosen preimage a with f a = b.

isBijective

Section titled “isBijective”

The type saying f is bijective: both injective and surjective.

hasSection

Section titled “hasSection”

A section (right inverse) of f: a map s with f (s b) = b for all b.

hasRetraction

Section titled “hasRetraction”

A retraction (left inverse) of f: a map r with r (f a) = a for all a.

isIso

Section titled “isIso”

A two-sided inverse of f: a map g with f (g b) = b and g (f a) = a.

idInjective

Section titled “idInjective”

The identity function is injective.

idSurjective

Section titled “idSurjective”

The identity function is surjective.

idBijective

Section titled “idBijective”

The identity function is bijective.

idHasSection

Section titled “idHasSection”

The identity function is its own section.

idHasRetraction

Section titled “idHasRetraction”

The identity function is its own retraction.

idIsIso

Section titled “idIsIso”

The identity function is an isomorphism, with itself as inverse.

funExtImpl

Section titled “funExtImpl”

Function extensionality: functions that agree pointwise are equal as paths.

happlyImpl

Section titled “happlyImpl”

Turns a path between functions into pointwise paths: f = g implies f x = g x.

happlyDep

Section titled “happlyDep”

Pointwise paths from a path between dependent functions: f = g implies f x = g x.

compose_injective

Section titled “compose_injective”

The composite of two injective functions is injective.

compose_surjective

Section titled “compose_surjective”

The composite of two surjective functions is surjective.

compose_bijective

Section titled “compose_bijective”

The composite of two bijective functions is bijective.

fibIdCenter

Section titled “fibIdCenter”

The canonical element of the fiber of the identity function over b, namely b itself.

fibConstElem

Section titled “fibConstElem”

Every x gives an element of the fiber of the constant function at a over a.

precomp

Section titled “precomp”

Precomposition with f: sends g to g ∘ f.

postcomp

Section titled “postcomp”

Postcomposition with g: sends f to g ∘ f.

precompIdApply

Section titled “precompIdApply”

Precomposing with the identity leaves a function unchanged at every point.

postcompIdApply

Section titled “postcompIdApply”

Postcomposing with the identity leaves a function unchanged at every point.

curryApplyNd

Section titled “curryApplyNd”

Currying computes as expected on non-dependent pairs: curry f a b = f (a, b).

uncurryApplyNd

Section titled “uncurryApplyNd”

Uncurrying computes as expected: uncurry f (a, b) = f a b.

curryUncurryNd

Section titled “curryUncurryNd”

Currying after uncurrying gives back the original two-argument function.

constEq

Section titled “constEq”

A constant function returns the same value for any two arguments.

constFunExt

Section titled “constFunExt”

The function fun b => const a b equals the constant function fun _ => a.

flipConstFn

Section titled “flipConstFn”

Flipping the first projection gives the second projection: flip (fun a b => a) = fun b a => a.

section_to_surjective

Section titled “section_to_surjective”

A function with a section is surjective.

retraction_to_injective

Section titled “retraction_to_injective”

A function with a retraction is injective.

iso_to_bijective

Section titled “iso_to_bijective”

A function with a two-sided inverse is bijective.

hasSection_compose

Section titled “hasSection_compose”

Sections compose: if g and f have sections, so does g ∘ f.

hasRetraction_compose

Section titled “hasRetraction_compose”

Retractions compose: if g and f have retractions, so does g ∘ f.

depApply

Section titled “depApply”

Pointwise application of a dependent family of functions g to a dependent function f: x maps to g x (f x).

depConst

Section titled “depConst”

The identity on dependent functions: returns f unchanged.

congIdFn

Section titled “congIdFn”

Applying the identity function to a path with cong gives back the same path.

compose3

Section titled “compose3”

Composition of three functions: h ∘ g ∘ f.

compose4

Section titled “compose4”

Composition of four functions: k ∘ h ∘ g ∘ f.

compose3Assoc

Section titled “compose3Assoc”

The triple composite equals the left-associated composite: compose3 h g f = (h ∘ g) ∘ f.

onApply

Section titled “onApply”

The on combinator unfolds: on f g x y = f (g x) (g y).

onId

Section titled “onId”

Using on with the identity function gives back the binary function: on f id = f.

funPathSym

Section titled “funPathSym”

Pointwise paths of an inverted function path are the inverses of its pointwise paths.

succ_injective

Section titled “succ_injective”

The successor function on natural numbers is injective.

not_injective

Section titled “not_injective”

Boolean negation is injective.

not_surjective

Section titled “not_surjective”

Boolean negation is surjective.

not_bijective

Section titled “not_bijective”

Boolean negation is bijective.

not_hasSection

Section titled “not_hasSection”

Boolean negation is its own section.

not_hasRetraction

Section titled “not_hasRetraction”

Boolean negation is its own retraction.

not_isIso

Section titled “not_isIso”

Boolean negation is an isomorphism, with itself as inverse.

pointwiseEq

Section titled “pointwiseEq”

Builds a path f = g from pointwise paths f x = g x (function extensionality).

pointwiseRefl

Section titled “pointwiseRefl”

Pointwise reflexivity: f x = f x for every x.

pointwiseSym

Section titled “pointwiseSym”

Pointwise symmetry: from f x = g x for all x, get g x = f x for all x.

pointwiseTrans

Section titled “pointwiseTrans”

Pointwise transitivity: from f x = g x and g x = h x for all x, get f x = h x for all x.

funSpaceRefl

Section titled “funSpaceRefl”

The reflexivity path on a function.

funSpaceSym

Section titled “funSpaceSym”

Inverts a path between functions: f = g gives g = f.

funSpaceCong

Section titled “funSpaceCong”

Postcomposition respects paths: f = g implies h ∘ f = h ∘ g.

funSpaceCongDomain

Section titled “funSpaceCongDomain”

Precomposition respects paths: f = g implies f ∘ h = g ∘ h.

isEmbedding

Section titled “isEmbedding”

The type saying f is an embedding, here stated as injectivity: f a1 = f a2 implies a1 = a2.

embedding_is_injective

Section titled “embedding_is_injective”

An embedding is injective.

Retract

Section titled “Retract”

The type of retractions of A onto B: maps s and r with r (s a) = a, exhibiting A as a retract of B.

retract_id

Section titled “retract_id”

Every type is a retract of itself via the identity maps.

retract_compose

Section titled “retract_compose”

Retracts compose: if A is a retract of B and B of C, then A is a retract of C.

iterateZero

Section titled “iterateZero”

Iterating f zero times is the identity: iterate 0 f x = x.

iterateOne

Section titled “iterateOne”

Iterating f once is applying f: iterate 1 f x = f x.

iterateSucc

Section titled “iterateSucc”

One more iteration applies f once more: iterate (n + 1) f x = f (iterate n f x).

iterateId

Section titled “iterateId”

Iterating the identity function any number of times returns the input.

isInvolution

Section titled “isInvolution”

The type saying f is an involution: f (f x) = x for every x.

involution_is_iso

Section titled “involution_is_iso”

An involution is an isomorphism, with itself as inverse.

involution_injective

Section titled “involution_injective”

An involution is injective.

involution_surjective

Section titled “involution_surjective”

An involution is surjective.

involution_bijective

Section titled “involution_bijective”

An involution is bijective.

not_involution

Section titled “not_involution”

Boolean negation is an involution.

isFixedPoint

Section titled “isFixedPoint”

The type saying x is a fixed point of f: f x = x.

hasFixedPoint

Section titled “hasFixedPoint”

The type of fixed points of f: some x together with a path f x = x.

idAllFixed

Section titled “idAllFixed”

Every point is a fixed point of the identity function.

constFixed

Section titled “constFixed”

The value a is a fixed point of the constant function at a.

isIdempotent

Section titled “isIdempotent”

The type saying f is idempotent: f (f x) = f x for every x.

constIdempotent

Section titled “constIdempotent”

Every constant function is idempotent.

idIdempotentFn

Section titled “idIdempotentFn”

The identity function is idempotent.

isCommutative

Section titled “isCommutative”

The type saying a binary function is commutative: f x y = f y x.

isAssociative

Section titled “isAssociative”

The type saying a binary operation is associative: f (f x y) z = f x (f y z).

isLeftIdentity

Section titled “isLeftIdentity”

The type saying e is a left identity for f: f e x = x.

isRightIdentity

Section titled “isRightIdentity”

The type saying e is a right identity for f: f x e = x.

add_commutative

Section titled “add_commutative”

Natural-number addition is commutative.

add_associative

Section titled “add_associative”

Natural-number addition is associative.

add_left_identity

Section titled “add_left_identity”

Zero is a left identity for natural-number addition.

add_right_identity

Section titled “add_right_identity”

Zero is a right identity for natural-number addition.

and_commutative

Section titled “and_commutative”

Boolean conjunction is commutative.

or_commutative

Section titled “or_commutative”

Boolean disjunction is commutative.

isLeftCancellable

Section titled “isLeftCancellable”

The type saying f can be cancelled at a: f a = f b implies a = b for every b.

injective_implies_cancellable

Section titled “injective_implies_cancellable”

An injective function is left cancellable at every point.

FnGraph

Section titled “FnGraph”

The graph of f as a type: points a paired with the trivial path f a = f a.

graph_elem

Section titled “graph_elem”

The element of the graph of f determined by a point a.

graph_fst

Section titled “graph_fst”

Projects a point of the graph of f to its domain coordinate.

compose_injective_implies_f

Section titled “compose_injective_implies_f”

If g ∘ f is injective, then f is injective.

surjective_compose_left

Section titled “surjective_compose_left”

If g ∘ f is surjective, then g is surjective.

FnRel

Section titled “FnRel”

The type of binary relations between A and B, valued in types.

isFunctional

Section titled “isFunctional”

The type saying a relation is functional: each a is related to at most one b (up to paths).

isTotalRel

Section titled “isTotalRel”

The type saying a relation is total: each a is related to some chosen b.

graphRel

Section titled “graphRel”

The graph relation of f: a is related to b when f a = b.

graphRel_functional

Section titled “graphRel_functional”

The graph relation of a function is functional.

graphRel_total

Section titled “graphRel_total”

The graph relation of a function is total.

Pred

Section titled “Pred”

The type of type-valued predicates on A.

preimage_pred

Section titled “preimage_pred”

The preimage of a predicate P on B along f: holds at a when P (f a) holds.

preimageIdPred

Section titled “preimageIdPred”

Pulling back a predicate along the identity function gives the same predicate.

preimageComposePred

Section titled “preimageComposePred”

Pulling back along g ∘ f is pulling back along g and then along f.

endo_compose

Section titled “endo_compose”

Composition of two endomorphisms of A.

endoComposeAssoc

Section titled “endoComposeAssoc”

Composition of endomorphisms is associative.

endoComposeIdLeft

Section titled “endoComposeIdLeft”

The identity is a left unit for endomorphism composition.

endoComposeIdRight

Section titled “endoComposeIdRight”

The identity is a right unit for endomorphism composition.

endo_power

Section titled “endo_power”

The n-th power of an endomorphism: f composed with itself n times.

endoPowerZero

Section titled “endoPowerZero”

The zeroth power of an endomorphism is the identity: f^0 x = x.

endoPowerOne

Section titled “endoPowerOne”

The first power of an endomorphism is the endomorphism itself: f^1 x = f x.

endoPowerSucc

Section titled “endoPowerSucc”

The successor power applies f once more: f^(n + 1) x = f (f^n x).

depFunExtSym

Section titled “depFunExtSym”

Inverts a path between dependent functions: f = g gives g = f.

depFunExtTrans

Section titled “depFunExtTrans”

Concatenates paths between dependent functions: f = g and g = h give f = h.

self_compose

Section titled “self_compose”

Composes an endomorphism with itself: f ∘ f.

selfComposeApply

Section titled “selfComposeApply”

Self-composition unfolds: (f ∘ f) x = f (f x).

involutionSelfCompose

Section titled “involutionSelfCompose”

An involution composed with itself is the identity function.

fixedPointIterate

Section titled “fixedPointIterate”

Iterating f from a fixed point stays there: iterate n f x = x whenever f x = x.

pred_retraction_succ

Section titled “pred_retraction_succ”

The predecessor function is a retraction of the successor: pred (succ n) = n.

mapComposeFn

Section titled “mapComposeFn”

Mapping over a list respects composition: map f (map g xs) = map (f ∘ g) xs.

CommSquare

Section titled “CommSquare”

The type saying a square of functions commutes: k (f a) = g (h a) for every a.

idCommute

Section titled “idCommute”

The square with f on two opposite sides and identities on the other two commutes.

flipCommutative

Section titled “flipCommutative”

For a commutative binary function, flipping does not change the result: flip f x y = f x y.

pointwiseCompose

Section titled “pointwiseCompose”

Postcomposing preserves pointwise paths: f x = g x for all x gives h (f x) = h (g x).

pointwisePrecompose

Section titled “pointwisePrecompose”

Precomposing preserves pointwise paths: f x = g x for all x gives f (h x) = g (h x).

doubleEq

Section titled “doubleEq”

Doubling a natural number is adding it to itself: n + n = double n.

mulTwoEq

Section titled “mulTwoEq”
